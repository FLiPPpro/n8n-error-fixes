n8n Aggregate node returns 'invalid input'

Error: Error: invalid input · Node: Aggregate

What this error actually means

The "invalid input" error in n8n's Aggregate node is a generic error message that doesn't provide much context. However, it usually indicates that the node is unable to process the input data due to a formatting or structure issue. This can happen when the data doesn't match the expected format, or when there's a mismatch between the data types.

The three most common causes

Based on our experience, the three most common causes of the "invalid input" error in the Aggregate node are:

  1. Data type mismatch: When the data type of the input data doesn't match the expected data type, the Aggregate node may throw an "invalid input" error.
  2. Missing or extra fields: When the input data is missing required fields or has extra fields that aren't expected, the Aggregate node may fail to process the data.
  3. Incorrect JSON structure: When the input data is in a JSON format, but the structure doesn't match the expected format, the Aggregate node may throw an "invalid input" error.

Step-by-step fix

To fix the "invalid input" error, follow these steps:

  1. Check the input data: Verify that the input data is in the correct format and has the expected fields. Use the console.log() function in a Code node to inspect the input data.
  2. Check the node settings: Ensure that the node is configured to process the correct data type and fields. Check the node's Settings tab for any configuration errors.
  3. Use a Code node to preprocess the data: If the input data needs to be transformed or converted to a different format, use a Code node to preprocess the data before passing it to the Aggregate node.

Here's an example of how you can use a Code node to preprocess the data:

const data = [
  { id: 1, name: 'John', age: 30 },
  { id: 2, name: 'Jane', age: 25 }
];

const transformedData = data.map(item => ({
  id: item.id,
  name: item.name,
  age: item.age,
  // Add any other required fields here
}));

return transformedData;

This code transforms the input data by adding any required fields and passing it to the Aggregate node.

  1. Use a JSONata expression to validate the data: If the input data is in a JSON format, use a JSONata expression to validate the data and ensure it matches the expected format.
$.data[0].id // Check if the first item has an id field
$.data[0].name // Check if the first item has a name field

This JSONata expression checks if the first item in the input data has an id and name field.
