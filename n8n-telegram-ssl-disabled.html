n8n Telegram node returns SSL disabled error

Error: SSL connection is required · Node: Telegram

What this error actually means

When you encounter the "SSL connection is required" error in n8n while trying to connect to Telegram, it means that the Telegram node is unable to establish a secure connection with the Telegram API. This is because the Telegram API requires all connections to be made over a secure SSL/TLS connection.

The three most common causes

There are three common reasons why this error occurs:

  1. SSL/TLS not enabled on the Telegram node: By default, the Telegram node in n8n is not configured to use SSL/TLS. This means that when you try to connect to the Telegram API, it will throw an error because it expects a secure connection.
  2. Incorrect Telegram API URL: If you've entered the wrong URL for the Telegram API, it may not be able to establish a secure connection. Make sure you've entered the correct URL, which should start with https://.
  3. n8n configuration issue: There may be a configuration issue in n8n that's preventing the Telegram node from using SSL/TLS.

Step-by-step fix

To fix this error, follow these steps:

  1. Enable SSL/TLS on the Telegram node:

* Open the Telegram node in your workflow. * Click on the "Settings" tab. * Scroll down to the "SSL/TLS" section. * Select the "Enable SSL/TLS" checkbox.

  1. Verify the Telegram API URL:

* Double-check that you've entered the correct URL for the Telegram API. * Make sure it starts with https://.

  1. Configure the Telegram node to use the correct SSL/TLS settings:

* In the "Settings" tab of the Telegram node, scroll down to the "SSL/TLS" section. * Select the "Use custom SSL/TLS settings" checkbox. * Enter the following JSON configuration:

{
  "ssl": {
    "verify": true,
    "rejectUnauthorized": true
  }
}

This configuration tells the Telegram node to verify the SSL/TLS certificate of the Telegram API and reject any unauthorized connections.

Prevent it from coming back

To prevent this error from occurring in the future, make sure to:

  • Regularly review your n8n configuration to ensure that all nodes are properly configured.
  • Verify that the Telegram API URL is correct and starts with https://.
  • Keep your n8n installation up-to-date to ensure that you have the latest security patches.

When to escalate

If you've tried the above steps and are still experiencing issues, it may be time to escalate the problem. This could involve:

  • Checking the n8n logs for any errors or warnings related to the Telegram node.
  • Consulting the n8n documentation or community forums for more information on configuring the Telegram node.
  • Reaching out to the n8n support team for further assistance.
