n8n Telegram node type mismatch error message

Error: value is not of expected type · Node: Telegram

What this error actually means

The "value is not of expected type" error in n8n's Telegram node occurs when the node is unable to set a field value due to a mismatch between the expected data type and the actual data type of the value being set. This error can be frustrating, especially when you're trying to integrate Telegram with other services using n8n.

The three most common causes

After working with numerous n8n users who have encountered this error, we've identified three common causes:

  1. Data type mismatch in the Telegram node's settings: Make sure that the data type of the field value matches the expected data type specified in the Telegram node's settings. For example, if you're trying to set a text field, ensure that the value is a string, not a number or an object.
  2. Incorrectly formatted value in the Code node: If you're using a Code node to generate the field value, double-check that the value is correctly formatted and matches the expected data type.
  3. Missing or incorrect field configuration: Verify that the field you're trying to set is properly configured in the Telegram node's settings. Ensure that the field name, data type, and other settings match the requirements of the Telegram API.

Step-by-step fix

To fix the "value is not of expected type" error, follow these steps:

  1. Check the Telegram node's settings: Open the Telegram node's settings and verify that the field name, data type, and other settings match the requirements of the Telegram API.
  2. Inspect the field value: Check the field value being set and ensure that it matches the expected data type. If the value is being generated by a Code node, inspect the code and verify that it's producing the correct value.
  3. Use the {{ }} syntax to format the value: If the value is being generated by a Code node, use the {{ }} syntax to format the value as a string. For example:
{
  "text": "{{ new Date().toISOString() }}"
}

This will ensure that the value is correctly formatted as a string.

  1. Use a Code node to generate the value: If you're trying to generate the field value using a Code node, use a JavaScript or Python Code node to produce the correct value. For example:
const value = new Date().toISOString();
return { text: value };
  1. Verify the field configuration: Double-check that the field you're trying to set is properly configured in the Telegram node's settings.

Prevent it from coming back

To prevent the "value is not of expected type" error from occurring in the future, follow these best practices:

  1. Use the {{ }} syntax to format values: Always use the {{ }} syntax to format values as strings, especially when working with dates and times.
  2. Verify field configurations: Regularly verify that field configurations match the requirements of the Telegram API.
  3. Use Code nodes to generate values: Use Code nodes to generate values, especially when working with complex data types.

When to escalate

If you've tried the above steps and the "value is not of expected type" error persists, it's likely a more complex issue that requires further investigation. In this case, escalate the issue to the n8n community or support team, providing as much detail as possible about the error, including:

  • The exact error message

  • A detailed description of the workflow and node configurations
