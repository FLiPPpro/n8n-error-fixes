HTML Extract node reports parser is broken in n8n

Error: Parser is broken · Node: HTML Extract

What this error actually means

The "Parser is broken" error in n8n's HTML Extract node is a generic error message that doesn't provide much context about the actual issue. However, it usually indicates that the HTML Extract node is unable to parse the HTML content, which can be due to various reasons such as malformed HTML, incorrect encoding, or unsupported HTML features.

The three most common causes

Based on our experience and user reports, the three most common causes of the "Parser is broken" error in the HTML Extract node are:

  1. Malformed HTML: If the HTML content contains errors, such as missing or mismatched tags, the parser will fail to parse it correctly.
  2. Incorrect encoding: If the HTML content is not encoded correctly, the parser may not be able to read it properly.
  3. Unsupported HTML features: If the HTML content uses features that are not supported by the parser, such as certain HTML5 elements or attributes, the parser will fail to parse it correctly.

Step-by-step fix

To fix the "Parser is broken" error, follow these steps:

  1. Check the HTML content: Verify that the HTML content is correct and free of errors. You can use an HTML validator tool to check for errors.
  2. Check the encoding: Ensure that the HTML content is encoded correctly. You can use the Content-Type header in the HTTP request to specify the encoding.
  3. Use a more robust parser: If the issue persists, try using a more robust HTML parser, such as htmlparser2. You can install it via npm by running npm install htmlparser2 and then use it in your Code node by importing it and using its parse function.

Here's an example Code node that uses htmlparser2 to parse the HTML content:

const htmlparser2 = require('htmlparser2');

const html = 'your_html_content_here';

const parser = new htmlparser2.Parser({
  onopentag: (name, attribs) => {
    console.log(`Opening tag: ${name}`);
  },
  ontext: (text) => {
    console.log(`Text: ${text}`);
  },
  onclosetag: (name) => {
    console.log(`Closing tag: ${name}`);
  }
});

parser.write(html);
parser.end();
  1. Retry the HTML Extract node: If the issue persists, try retrying the HTML Extract node with the same settings. You can do this by configuring the node's Settings tab to retry the operation with a certain number of attempts and a delay between attempts.

Prevent it from coming back

To prevent the "Parser is broken" error from coming back, make sure to:

  • Regularly check the HTML content for errors and fix any issues.
  • Use a robust HTML parser, such as htmlparser2, to parse the HTML content.
  • Configure the HTML Extract node to retry the operation with a certain number of attempts and a delay between attempts.

When to escalate

If you've tried the above steps and the issue persists, it's likely that the problem is more complex and requires further investigation. In this case, you should escalate the issue to the n8n support team, providing them with as much detail as possible about the issue, including the HTML content, the node settings, and any error messages you've encountered.
