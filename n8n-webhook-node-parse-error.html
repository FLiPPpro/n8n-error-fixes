Webhook node in n8n not parsing JSON data correctly

Error: Error parsing JSON data: Unexpected token · Node: Webhook

What this error actually means

The "Error parsing JSON data: Unexpected token" error in n8n's Webhook node is a common issue that occurs when the node is unable to parse the incoming JSON data as expected. This error typically happens when the JSON data is malformed or not in the expected format.

In this article, we will walk you through the three most common causes of this error and provide a step-by-step fix to resolve it.

The three most common causes

1. Malformed JSON data

The most common cause of this error is malformed JSON data being sent to the Webhook node. This can happen when the sending application is not properly encoding the JSON data or when there are issues with the network connection.

2. Incorrect JSON parsing settings

Another common cause of this error is incorrect JSON parsing settings in the Webhook node. If the node is configured to parse JSON data in a specific format, but the incoming data does not match that format, the node will throw an error.

3. Unexpected token in the JSON data

The third common cause of this error is an unexpected token in the JSON data. This can happen when the JSON data contains special characters or syntax that is not expected by the Webhook node.

Step-by-step fix

To resolve the "Error parsing JSON data: Unexpected token" error in the Webhook node, follow these steps:

  1. Verify the JSON data: Check the incoming JSON data to ensure it is properly formatted and encoded. You can use tools like jq or a JSON validator to inspect the data.
  2. Check the Webhook node settings: Verify that the Webhook node is configured to parse JSON data correctly. Check the "Content-Type" header to ensure it is set to "application/json".
  3. Use a Code node to parse JSON data: If the Webhook node is still throwing an error, try using a Code node to parse the JSON data. You can use the JSON.parse() function in JavaScript to parse the data.
  4. Add error handling: Configure the Webhook node to continue on fail, so that it does not throw an error when it encounters unexpected JSON data. You can also use an Error Trigger to catch and handle the error.

Here is an example Code node that you can use to parse JSON data:

const data = {{json: 'your_json_data_here'}};
const jsonData = JSON.parse(data);
return { json: jsonData };

Replace your_json_data_here with the actual JSON data being sent to the Webhook node.

Prevent it from coming back

To prevent the "Error parsing JSON data: Unexpected token" error from coming back, make sure to:

  • Verify the JSON data being sent to the Webhook node is properly formatted and encoded.
  • Configure the Webhook node to parse JSON data correctly.
  • Use a Code node to parse JSON data if necessary.
  • Add error handling to the Webhook node to catch and handle unexpected JSON data.

When to escalate

If you have tried the above steps and are still experiencing issues with the "Error parsing JSON data: Unexpected token" error in the Webhook node, it may be time to escalate the issue. This could involve:

  • Checking the network connection and ensuring that the data is being sent correctly.
  • Verifying the sending application is properly encoding the JSON data.
  • Consulting with a colleague or seeking additional support from the n8n community.
