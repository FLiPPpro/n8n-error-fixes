n8n Cron node returns SSL disabled error

Error: SSL connection is required · Node: Cron

What this error actually means

When you encounter the "SSL connection is required" error in n8n's Cron node, it means that the Cron node is trying to connect to a remote server using a non-SSL (HTTPS) connection. This is a security feature in n8n that requires all outgoing connections to be encrypted.

The three most common causes

There are three common reasons why you might encounter this error:

  1. Remote server does not support SSL: If the remote server does not have an SSL certificate or does not support SSL connections, the Cron node will throw this error.
  2. Incorrect protocol specified in the Cron node: Make sure that the protocol specified in the Cron node's URL field is set to HTTPS (https://).
  3. SSL is disabled in the Cron node's settings: Ensure that SSL is enabled in the Cron node's settings by checking the "Use SSL" checkbox.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the remote server's SSL configuration: Verify that the remote server has an SSL certificate and supports SSL connections. You can do this by checking the server's documentation or contacting the server administrator.
  2. Specify HTTPS in the Cron node's URL field: Ensure that the protocol specified in the Cron node's URL field is set to HTTPS (https://).
  3. Enable SSL in the Cron node's settings: Go to the Cron node's settings and check the "Use SSL" checkbox.

If you are still encountering the error after checking these steps, you can try adding a "Wait" node to introduce a delay before the Cron node runs. This can help prevent the error from occurring due to timing issues.

Here is an example of how to add a "Wait" node to introduce a delay:

{
  "nodes": [
    {
      "name": "Wait",
      "type": "wait",
      "settings": {
        "duration": 1000 // 1 second
      }
    },
    {
      "name": "Cron",
      "type": "cron",
      "settings": {
        "useSSL": true
      }
    }
  ]
}

This code adds a "Wait" node that introduces a 1-second delay before the Cron node runs. You can adjust the duration to suit your needs.

Prevent it from coming back

To prevent this error from occurring in the future, make sure to:

  • Always specify HTTPS in the Cron node's URL field.
  • Enable SSL in the Cron node's settings.
  • Verify that the remote server supports SSL connections.

When to escalate

If you have tried all the above steps and are still encountering the error, it may be necessary to escalate the issue to the n8n support team or the server administrator. Provide as much detail as possible about the error, including any relevant logs or error messages.
