n8n HTML Extract node returns empty response

Error: Unexpected end of JSON input · Node: HTML Extract

What this error actually means

The "Unexpected end of JSON input" error in n8n's HTML Extract node is a common issue that can be frustrating to resolve. This error occurs when the HTML Extract node is unable to parse the HTML response from the target URL, resulting in an empty response. In this article, we will explore the possible causes of this error and provide a step-by-step guide to fix it.

The three most common causes

There are three common causes of the "Unexpected end of JSON input" error in the HTML Extract node:

  1. Invalid HTML response: The target URL returns HTML that is not in the expected format, causing the HTML Extract node to fail.
  2. Missing or incorrect HTML selector: The HTML selector used in the HTML Extract node is not correctly configured, resulting in an empty response.
  3. Network issues: Network connectivity issues or proxy settings can prevent the HTML Extract node from receiving the HTML response.

Step-by-step fix

To fix the "Unexpected end of JSON input" error in the HTML Extract node, follow these steps:

  1. Check the HTML response: Verify that the target URL returns the expected HTML response. You can do this by using a tool like curl or a web browser to inspect the HTML response.
  2. Configure the HTML selector: Ensure that the HTML selector used in the HTML Extract node is correctly configured. You can use the Inspect feature in n8n to verify the HTML structure and select the correct element.
  3. Add a retry mechanism: Configure the HTML Extract node to retry the request in case of a network issue. You can do this by setting the "Retry On Fail" option to "true" and configuring the "Max Tries" and "Wait Between Tries (ms)" options.
  4. Use a Code node to inspect the HTML response: Add a Code node to inspect the HTML response and verify that it is in the expected format. You can use the following JavaScript code to log the HTML response:
console.log( workflow.getVariable('htmlResponse') );

This code logs the HTML response to the console, allowing you to inspect the HTML structure and identify any issues.

Prevent it from coming back

To prevent the "Unexpected end of JSON input" error from occurring in the future, follow these best practices:

  1. Verify the HTML response: Regularly verify that the target URL returns the expected HTML response.
  2. Test the HTML selector: Test the HTML selector used in the HTML Extract node to ensure it is correctly configured.
  3. Monitor network issues: Monitor network connectivity issues and proxy settings to prevent network-related errors.

When to escalate

If you have followed the steps outlined above and the issue persists, it may be necessary to escalate the issue to the n8n support team. Provide the following information to assist with troubleshooting:

  • The exact error message
  • The n8n version and node version
  • The target URL and HTML selector used in the HTML Extract node
  • Any relevant logs or console output

By following these steps and best practices, you should be able to resolve the "Unexpected end of JSON input" error in the HTML Extract node and ensure that your workflow is running smoothly.
