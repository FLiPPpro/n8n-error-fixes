n8n Slack node returns SSL disabled error

Error: SSL connection is required · Node: Slack

What this error actually means

The error "SSL connection is required" when trying to connect to Slack in n8n indicates that the node is unable to establish a secure connection to the Slack API. This is a common issue when the SSL/TLS settings on the Slack node are not properly configured.

The three most common causes

  1. SSL/TLS settings not configured: The most common cause of this error is that the SSL/TLS settings on the Slack node are not properly configured. This can be due to the node being created with default settings or the settings being changed incorrectly.
  2. Incorrect Slack API endpoint: Another common cause of this error is using an incorrect Slack API endpoint. Make sure you are using the correct endpoint for the Slack API.
  3. Missing or incorrect SSL/TLS certificates: In some cases, the error can be caused by missing or incorrect SSL/TLS certificates. This can be due to a misconfiguration of the SSL/TLS settings on the node.

Step-by-step fix

To fix the issue, follow these steps:

  1. Check the SSL/TLS settings: Go to the Slack node's Settings tab and check the SSL/TLS settings. Make sure the "Use SSL" option is enabled.
  2. Configure the SSL/TLS certificates: If you are using a self-signed certificate, you will need to configure the SSL/TLS certificates on the node. You can do this by clicking on the "Configure" button next to the "SSL/TLS Certificates" field.
  3. Use the correct Slack API endpoint: Make sure you are using the correct Slack API endpoint. You can find the correct endpoint in the Slack API documentation.
  4. Verify the SSL/TLS settings: After configuring the SSL/TLS settings, verify that the node is able to establish a secure connection to the Slack API.

Here is an example of how to configure the SSL/TLS certificates using a Code node:

const ssl = {
  "cert": "-----BEGIN CERTIFICATE-----\n... certificate contents ...",
  "key": "-----BEGIN RSA PRIVATE KEY-----\n... private key contents ..."
};

// Set the SSL/TLS certificates on the node
n8n.setNodeOption("ssl", ssl);

Replace the certificate contents and private key contents with the actual contents of your SSL/TLS certificates.

Prevent it from coming back

To prevent this issue from coming back, make sure to:

  • Regularly check the SSL/TLS settings on the node
  • Verify that the SSL/TLS certificates are up-to-date and properly configured
  • Use the correct Slack API endpoint

When to escalate

If you have followed the steps above and the issue persists, it may be necessary to escalate the issue to the n8n support team. Provide as much detail as possible about the issue, including the error message, the node configuration, and any relevant logs.
