Code Node Execution Failed Error in n8n Workflow

Error: Execution of the code failed: invalid syntax · Node: Code

What this error actually means

When you see the error message "Execution of the code failed: invalid syntax" in n8n, it means that the code you've written in the Code node is not being executed correctly due to a syntax error. This error is not specific to n8n and is a common issue in programming languages.

The three most common causes

There are several reasons why you might encounter this error. Here are the most common causes:

  • Typo or syntax error: A simple typo or syntax error in your code can cause the execution to fail. Make sure to check your code for any errors.
  • Unsupported syntax: n8n's Code node supports JavaScript and Python syntax. If you're using a different syntax, it will not work.
  • Incorrect code formatting: Make sure your code is properly formatted and indented. n8n's Code node uses a specific formatting style to execute the code.

Step-by-step fix

To fix the error, follow these steps:

  1. Check your code: Go through your code and check for any typos or syntax errors. Make sure you're using the correct syntax (JavaScript or Python).
  2. Use the correct syntax: If you're using JavaScript, make sure to use the console.log() function to output any results. If you're using Python, make sure to use the print() function.
  3. Format your code: Make sure your code is properly formatted and indented. You can use an IDE or a code editor to format your code.
  4. Test your code: Test your code by running it in a Code node. If it still fails, try to isolate the issue by breaking down your code into smaller chunks.

Here's an example of a JavaScript code block that you can use to test the Code node:

console.log("Hello, World!");

Paste this code into a Code node and run it. If it executes successfully, you can try adding more complex code.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Test your code: Before deploying your workflow, test your code by running it in a Code node.
  • Use version control: Use version control to track changes to your code and prevent typos or syntax errors.
  • Keep your code up-to-date: Make sure your code is up-to-date and uses the latest syntax.

When to escalate

If you've tried the above steps and still encounter the error, it's time to escalate the issue. Reach out to the n8n community or the support team for further assistance. Provide as much detail as possible about the error, including the code you're using and the exact error message. This will help the support team to diagnose and fix the issue.
