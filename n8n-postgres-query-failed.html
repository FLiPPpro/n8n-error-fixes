Postgres Node Query Failed Error in n8n Workflow

Error: Query failed: no results · Node: Postgres

What this error actually means

When you see the error message "Query failed: no results" in n8n, it means that the Postgres node was unable to execute the query you specified and return any results. This can be due to a variety of reasons, including but not limited to:

  • The query itself is invalid or incomplete
  • The database connection is not established correctly
  • The database does not contain the expected data

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Incorrect query syntax: Make sure that the query you're running is syntactically correct. Check for missing or extra brackets, semicolons, or other characters that can cause the query to fail.
  2. Database connection issues: Ensure that the Postgres node is connected to the correct database and that the credentials are correct. Check the database logs for any errors related to the connection.
  3. Data not found: Verify that the data you're trying to retrieve exists in the database. If the data is not present, the query will fail and return no results.

Step-by-step fix

To fix this issue, follow these steps:

  1. Check the query syntax: Review the query you're running and ensure it's correct. You can use tools like psql or a database client to test the query directly on the database.
  2. Verify database connection: Check the Postgres node's settings to ensure it's connected to the correct database and that the credentials are correct.
  3. Test the query with a Code node: Create a new Code node and use the pg library to connect to the database and run the query. This will help you isolate the issue and ensure it's not related to the Postgres node.
  4. Use a SELECT statement: Make sure the query is a SELECT statement, which is used to retrieve data from the database. If you're trying to insert, update, or delete data, use the corresponding INSERT, UPDATE, or DELETE statement.

Here's an example of how you can use a Code node to test the query:

const pg = require('pg');

const db = new pg.Client({
  user: 'your_username',
  host: 'your_host',
  database: 'your_database',
  password: 'your_password',
  port: 5432
});

db.connect((err) => {
  if (err) {
    console.error(err);
    return;
  }
  const query = 'SELECT * FROM your_table';
  db.query(query, (err, result) => {
    if (err) {
      console.error(err);
    } else {
      console.log(result.rows);
    }
  });
});

Replace the placeholders with your actual database credentials and table name.

Prevent it from coming back

To prevent this issue from occurring in the future, make sure to:

  • Test your queries thoroughly before running them in n8n
  • Verify the database connection and credentials
  • Use a SELECT statement to retrieve data
  • Use a Code node to test the query and isolate the issue

When to escalate

If you've followed the steps above and the issue persists, it's likely that there's a more complex problem at play. In this case, it's recommended to:

  • Check the database logs for any errors related to the connection or query
  • Reach out to your database administrator for assistance
  • Consider seeking help from the n8n community or a professional developer
