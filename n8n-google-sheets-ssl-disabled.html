n8n Google Sheets node returns SSL disabled error

Error: SSL connection is required · Node: Google Sheets

What this error actually means

The error message "SSL connection is required" indicates that the Google Sheets node in n8n is trying to connect to Google Sheets using a non-SSL connection. This is a security requirement for Google Sheets API, and n8n is unable to establish a secure connection.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Incorrect Google Sheets API credentials: Make sure you have entered the correct credentials in the Google Sheets node. Check that the API key, client ID, and client secret are correct.
  2. SSL disabled on the node: Double-check that the SSL option is enabled on the Google Sheets node. This is usually found in the node's Settings tab.
  3. n8n version issues: Ensure that your n8n version is up-to-date. Older versions of n8n may not support SSL connections.

Step-by-step fix

To fix this issue, follow these steps:

  1. Enable SSL on the Google Sheets node:

* Go to the Google Sheets node and click on the Settings tab. * Scroll down to the "Advanced" section and look for the "Use SSL" option. * Check the box next to "Use SSL" to enable it.

  1. Update your Google Sheets API credentials:

* Go to the Google Cloud Console and create a new project or select an existing one. * Create a new OAuth client ID and copy the client ID and client secret. * Go back to the Google Sheets node and update the API key, client ID, and client secret with the new credentials.

  1. Add a retry mechanism:

* Create a new "HTTP Request" node and configure it to retry the request if it fails. * Set the "Retry On Fail" option to "true" and set the "Max Tries" to a reasonable number (e.g., 3). * Set the "Wait Between Tries (ms)" to a reasonable delay (e.g., 5000). * Use the "Continue On Fail" option to branch to an error handling workflow if the request fails after the maximum number of retries.

Here's an example code block that you can paste into a Code node to implement the retry mechanism:

{
  "name": "Retry Google Sheets",
  "nodes": [
    {
      "name": "HTTP Request",
      "type": "http-request",
      "settings": {
        "method": "GET",
        "url": "https://sheets.googleapis.com/v4/spreadsheets/{spreadsheetId}/values/{range}",
        "retryOnFail": true,
        "maxTries": 3,
        "waitBetweenTriesMs": 5000
      }
    }
  ]
}

Prevent it from coming back

To prevent this issue from coming back, make sure to:

  • Regularly update your n8n version to ensure you have the latest security patches.
  • Monitor your workflow logs for any errors related to SSL connections.
  • Test your workflow regularly to catch any issues before they become major problems.

When to escalate

If you've tried all the above steps and the issue persists, it's time to escalate the problem. Reach out to the n8n community or support team for further assistance.
