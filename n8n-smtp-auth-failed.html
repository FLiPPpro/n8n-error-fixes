n8n Send Email SMTP Authentication Failed — Fix

Error: Invalid login: 535 Authentication failed · Node: Send Email

What this error actually means

The error message "Invalid login: 535 Authentication failed" is a generic error that can occur when sending emails via n8n's Send Email node. It's not a specific error that points directly to the cause, but rather a symptom of a more underlying issue. In this case, the error is related to authentication failure, which can be caused by various factors.

The three most common causes

There are three common causes for this error:

  1. Using account password instead of App Password or OAuth2: Gmail and Outlook require App Password or OAuth2 for authentication, not account passwords. If you're using an account password, you'll encounter this error.
  2. Two-Factor Authentication (2FA) blocking SMTP: If 2FA is enabled on your email account, it may block SMTP connections, resulting in authentication failure.
  3. Incorrect SMTP settings: Incorrect SMTP settings, such as the wrong server, port, or authentication details, can also cause this error.

Step-by-step fix

To fix this error, follow these steps:

  1. Switch to App Password or OAuth2: If you're using Gmail or Outlook, switch to using an App Password or OAuth2 for authentication. You can do this by creating a new App Password in your email account settings or generating an OAuth2 token.
  2. Disable 2FA: If 2FA is enabled on your email account, disable it temporarily to test if it resolves the issue.
  3. Verify SMTP settings: Double-check your SMTP settings to ensure they're correct. You can do this by checking your email account settings or consulting with your email provider.

To automate the process of retrying the email sending, you can use the following code in a Code node:

const retryOptions = {
  maxTries: 3,
  waitBetweenTries: 10000 // 10 seconds
};

// Set the retry options on the Send Email node
n8n.nodes.SendEmail.settings.retryOnFail = true;
n8n.nodes.SendEmail.settings.maxTries = retryOptions.maxTries;
n8n.nodes.SendEmail.settings.waitBetweenTries = retryOptions.waitBetweenTries;

This code sets the retry options on the Send Email node to retry up to 3 times with a 10-second wait between retries.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Use App Password or OAuth2 for authentication
  • Disable 2FA if necessary
  • Verify SMTP settings regularly
  • Monitor your email account settings for any changes that may affect SMTP connections

When to escalate

If you've tried the above steps and the error persists, it may be necessary to escalate the issue to your email provider's support team or n8n's support team. Provide them with the error message and any relevant logs or configurations to help them troubleshoot the issue.
