n8n Merge node type incorrect error message

Error: value is not of expected type · Node: Merge

What this error actually means

The "value is not of expected type" error in n8n's Merge node is a common issue that can be frustrating to resolve. This error occurs when the Merge node is trying to merge two or more data sets, but the data types of the values being merged do not match. This can happen when the data types of the values are not explicitly set in the node's settings or when the data types are not compatible with the merge operation.

The three most common causes

Based on our experience and support requests, the three most common causes of this error are:

  1. Incorrect data type: When the data types of the values being merged do not match, the Merge node will throw an error. This can happen when the data types are not explicitly set in the node's settings or when the data types are not compatible with the merge operation.
  2. Missing or incomplete data: When the data sets being merged are missing or incomplete, the Merge node will throw an error. This can happen when the data sets are not properly configured or when there are issues with the data flow.
  3. Node configuration issues: When the Merge node is not properly configured, it can throw errors. This can happen when the node's settings are not correctly set or when there are issues with the node's connections.

Step-by-step fix

To fix the "value is not of expected type" error in the Merge node, follow these steps:

  1. Check the data types: Verify that the data types of the values being merged match. You can do this by checking the data types in the node's settings or by using a Code node to log the data types.
  2. Set explicit data types: If the data types are not explicitly set, set them in the node's settings. You can do this by clicking on the "Settings" tab and selecting the correct data type for each field.
  3. Use a Code node to validate data: Use a Code node to validate the data being merged. You can use JavaScript or Python to check the data types and ensure that they match.
  4. Use a JSONata expression: Use a JSONata expression to convert the data types if necessary. You can use a Code node to write a JSONata expression that converts the data types.

Prevent it from coming back

To prevent the "value is not of expected type" error from coming back, follow these best practices:
