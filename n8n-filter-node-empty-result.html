Filter Node Empty Result Error in n8n Workflow

Error: No items found · Node: Filter

What this error actually means

The "No items found" error in n8n's Filter node is a common issue that can be frustrating to resolve. However, it's essential to understand that this error doesn't necessarily mean that the filter is not working as expected. Instead, it indicates that the Filter node is unable to find any matching items in the input data.

When you encounter this error, it's crucial to investigate the input data and the filter conditions to determine why the Filter node is not returning any results.

The three most common causes

Based on our experience, the three most common causes of the "No items found" error in the Filter node are:

  1. Incorrect filter conditions: Make sure that the filter conditions are correctly set up and that the criteria are being met. Double-check that the field names, data types, and operator selections are correct.
  2. Empty input data: Verify that the input data is not empty or null. If the input data is empty, the Filter node will not be able to find any matching items.
  3. Data type mismatch: Ensure that the data type of the field being filtered matches the expected data type. For example, if you're filtering on a date field, make sure that the data is in the correct format (e.g., YYYY-MM-DD).

Step-by-step fix

To resolve the "No items found" error, follow these steps:

  1. Verify input data: Check the input data to ensure that it's not empty or null. You can do this by adding a Debug node before the Filter node to inspect the input data.
  2. Check filter conditions: Review the filter conditions and ensure that they're correctly set up. You can use a Code node to print out the filter conditions and verify that they're being applied correctly.
  3. Add a Wait node: If you suspect that the issue is due to a data type mismatch or a timing issue, add a Wait node before the Filter node to introduce a delay. This can help ensure that the data is properly formatted before being filtered.
  4. Use a Code node to debug: If you're still having trouble, use a Code node to print out the input data and the filter conditions. This can help you identify any issues with the data or the filter conditions.

Here's an example code block you can use in a Code node to print out the input data and filter conditions:

{
  "nodes": [
    {
      "name": "Code",
      "type": "n8n-nodes-base.code",
      "function": "print",
      "parameters": {
        "value": "={{ $node[\"Filter\"].data }}\n{{ $node[\"Filter\"].filter }}"
      },
      "notes": {}
    }
  ]
}

This code will print out the input data and filter conditions to the console, which can help you identify any issues.

Prevent it from coming back

To prevent the "No items found" error from coming back in the future, make sure to:

  • Regularly review and update your filter conditions to ensure they're still accurate and relevant.
  • Verify that the input data is properly formatted and free of errors.
  • Use a Wait node to introduce a delay if necessary to ensure that the data is properly formatted before being filtered.

When to escalate

If you've tried the steps above and are still experiencing issues with the "No items found" error, it may be time to escalate the issue to a n8n support specialist. Be sure to provide as much detail as possible about the issue, including the filter conditions, input data, and any error messages you're seeing. This will help the support specialist to quickly identify and resolve the issue.
