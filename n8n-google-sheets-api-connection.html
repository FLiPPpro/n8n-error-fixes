Google Sheets API Node Connection Failed with Error

Error: Error: Connection timed out: Connection to Google Sheets API failed · Node: Google Sheets

What this error actually means

When you see the error "Error: Connection timed out: Connection to Google Sheets API failed" in n8n, it means that the Google Sheets node is unable to establish a connection to the Google Sheets API. This can happen for a variety of reasons, including network issues, API key problems, or incorrect configuration.

The three most common causes

Based on our experience with n8n, the three most common causes of this error are:

  1. Incorrect API key or credentials: Make sure you have entered the correct API key and credentials in the Google Sheets node's Settings tab. Double-check that the API key is enabled and has the necessary permissions.
  2. Network issues: Check your network connection and ensure that you have a stable internet connection. You can try running the workflow on a different network or device to isolate the issue.
  3. API rate limits: If you're making a large number of requests to the Google Sheets API, you may be hitting the rate limits. Check the Google Sheets API documentation to see if you're exceeding the limits.

Step-by-step fix

To fix the error, follow these steps:

  1. Check your API key and credentials: Go to the Google Sheets node's Settings tab and verify that you have entered the correct API key and credentials. Make sure the API key is enabled and has the necessary permissions.
  2. Add retries to the Google Sheets node: Go to the Google Sheets node's Settings tab and enable retries. Set the "Max Tries" to a higher value (e.g. 5) and the "Wait Between Tries (ms)" to a reasonable value (e.g. 5000).
  3. Add a delay before the Google Sheets node: Add a "Wait" node before the Google Sheets node to introduce a delay. This can help prevent the connection timeout error.
  4. Verify the API endpoint: Make sure you have entered the correct API endpoint in the Google Sheets node's Settings tab. The endpoint should be in the format https://sheets.googleapis.com/v4/spreadsheets/{spreadsheetId}/values/{range}.

Here's an example code block that you can use to add retries to the Google Sheets node:

{
  "name": "Google Sheets",
  "settings": {
    "retryOnFail": true,
    "maxTries": 5,
    "waitBetweenTriesMs": 5000
  }
}

You can paste this code into the Google Sheets node's Settings tab to enable retries.

Prevent it from coming back

To prevent the error from coming back, make sure to:

  • Regularly check your API key and credentials to ensure they are correct.
  • Monitor your network connection to ensure it is stable.
  • Check the Google Sheets API documentation to ensure you are not exceeding the rate limits.
  • Consider implementing a more robust error handling mechanism, such as using the "Error Trigger" to branch on errors.

When to escalate

If you've tried the above steps and the error persists, it's time to escalate the issue. Contact our support team and provide the following information:

  • The exact error message
  • The n8n version you're running
  • The Google Sheets API version you're using
  • Any relevant logs or debug information

We'll work with you to troubleshoot the issue and provide a solution.
