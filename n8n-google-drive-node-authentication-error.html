Google Drive node in n8n authentication issue with OAuth

Error: Error authenticating: OAuth error · Node: Google Drive

What this error actually means

When you encounter the "OAuth error" message while setting up the Google Drive node in n8n, it means that the node is unable to authenticate with the Google Drive API. This can be due to a variety of reasons, including incorrect client ID or secret, expired access tokens, or issues with the OAuth flow.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Incorrect client ID or secret: Make sure that you have entered the correct client ID and secret for your Google Drive API project in the Google Drive node's settings.
  2. Expired access tokens: If your access tokens have expired, the Google Drive node will not be able to authenticate. You can check the expiration time of your tokens in the Google Cloud Console.
  3. Issues with the OAuth flow: The OAuth flow can sometimes get stuck or timed out, causing the authentication to fail.

Step-by-step fix

To fix the OAuth error, follow these steps:

  1. Check your client ID and secret: Open the Google Cloud Console and navigate to the API library. Select the Google Drive API and click on the "Enable" button. Then, click on the "Create credentials" button and select "OAuth client ID". Make sure that you have entered the correct client ID and secret in the Google Drive node's settings.
  2. Check your access tokens: Open the Google Cloud Console and navigate to the API library. Select the Google Drive API and click on the "Enable" button. Then, click on the "APIs & Services" tab and select "Credentials". Make sure that your access tokens have not expired.
  3. Check the OAuth flow: If you have checked your client ID and secret and access tokens, and the issue persists, try resetting the OAuth flow. You can do this by deleting the credentials in the Google Cloud Console and re-creating them.

Here is an example of how to reset the OAuth flow using the Google Cloud Console:

{
  "credentials": {
    "client_id": "YOUR_CLIENT_ID",
    "client_secret": "YOUR_CLIENT_SECRET",
    "redirect_uri": "YOUR_REDIRECT_URI"
  }
}

To reset the OAuth flow, delete the credentials in the Google Cloud Console and re-create them using the above JSON object.

Prevent it from coming back

To prevent the OAuth error from coming back, make sure to:

  • Regularly check your access tokens to ensure they have not expired.
  • Keep your client ID and secret secure and do not share them with anyone.
  • Use the "Retry On Fail" setting on the Google Drive node to retry the authentication after a certain number of attempts.

When to escalate

If you have tried the above steps and the issue persists, it may be necessary to escalate the issue to the n8n support team. Please provide as much detail as possible about the issue, including any error messages or logs. Additionally, make sure to provide the following information:

  • Your n8n version and build number.
  • Your Google Drive API project ID and credentials.
  • The exact error message and any relevant logs.
