MongoDB node throws 'OAuth2 refresh token revoked' error

Error: OAuth2 refresh token revoked · Node: MongoDB

What this error actually means

When you see the error message "OAuth2 refresh token revoked" in n8n, it means that the OAuth2 refresh token used by the MongoDB node to authenticate with the MongoDB instance has been revoked. This can happen due to various reasons such as token expiration, user revocation, or a change in the OAuth2 configuration.

The three most common causes

There are three common causes for this error:

  1. Token expiration: The OAuth2 refresh token has expired, and the MongoDB node is unable to obtain a new token.
  2. User revocation: The user who granted the OAuth2 token has revoked it, causing the token to become invalid.
  3. OAuth2 configuration change: There has been a change in the OAuth2 configuration, such as a change in the token expiration time or the revocation policy.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the token expiration: Verify that the OAuth2 refresh token has not expired. You can do this by checking the token expiration time in the MongoDB node's settings. If the token has expired, obtain a new token from the OAuth2 provider.
  2. Verify user revocation: Check if the user who granted the OAuth2 token has revoked it. If the token has been revoked, obtain a new token from the OAuth2 provider.
  3. Check OAuth2 configuration: Verify that there have been no changes to the OAuth2 configuration that could have caused the token to become invalid.
  4. Use a retry mechanism: To handle this error, you can configure the MongoDB node to retry the authentication process. To do this, go to the MongoDB node's settings and configure the "Retry On Fail" option to "true". Set the "Max Tries" to a value greater than 1 and the "Wait Between Tries (ms)" to a value that allows the node to retry the authentication process after a short delay.

Here is an example of how you can configure the retry mechanism in a Code node:

{
  "name": "Retry Mechanism",
  "type": "Code",
  "function": "function() {\n  // Set the retry configuration\n  n8n.config.set('retryOnFail', true);\n  n8n.config.set('maxTries', 3);\n  n8n.config.set('waitBetweenTries', 5000);\n}\n"
}
  1. Add a delay: To add a delay between retries, you can use the "Wait" node. This will allow the node to wait for a short period of time before retrying the authentication process.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Regularly check the OAuth2 token expiration time and obtain a new token when necessary.
  • Verify that the user who granted the OAuth2 token has not revoked it.
  • Monitor the OAuth2 configuration for any changes that could cause the token to become invalid.

When to escalate

If you have followed the steps above and the error persists, it may be necessary to escalate the issue to the n8n support team. Provide as much information as possible about the error, including the error message, the node configuration, and any relevant logs.
