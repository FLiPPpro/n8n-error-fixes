Filter Node Error - Invalid Condition

Error: Filter condition is invalid · Node: Filter

What this error actually means

The "Filter condition is invalid" error in n8n's Filter node is a common issue that can be frustrating to resolve. However, understanding what this error actually means is key to fixing it. In essence, this error occurs when the Filter node's condition is not properly formatted or is invalid.

When you set up a Filter node, you specify a condition that determines whether the node should pass or fail. This condition is usually a JSON expression that checks for a specific value or property in the input data. If the condition is not valid, the Filter node will throw an error, and this error is what you're seeing.

The three most common causes

There are three common causes of the "Filter condition is invalid" error:

  1. Invalid JSON syntax: The condition you've specified in the Filter node is not valid JSON. This can be due to missing quotes, mismatched brackets, or other syntax errors.
  2. Missing or incorrect property: The condition is trying to access a property that doesn't exist in the input data. Make sure you're referencing the correct property or variable.
  3. Invalid comparison operator: You're using an invalid comparison operator in your condition. For example, you might be using != instead of !== or == instead of ===.

Step-by-step fix

To fix the "Filter condition is invalid" error, follow these steps:

  1. Check the condition syntax: Ensure that the condition you've specified in the Filter node is valid JSON. You can use an online JSON validator to check the syntax.
  2. Verify the property: Make sure you're referencing the correct property or variable in the condition.
  3. Use the correct comparison operator: Use the correct comparison operator for your condition. For example, use !== for "not equal to" and === for "equal to".
  4. Test the condition: Test the condition by pasting it into a Code node and running it. If the condition is valid, the Code node should return true or false.

Here's an example of a valid condition in a Filter node:

{
  "jsonata": "data.item === 'example'"
}

This condition checks if the item property of the input data is equal to 'example'.

If you're still having trouble, try using a simpler condition to see if the issue is with the specific property or variable.

Prevent it from coming back

To prevent the "Filter condition is invalid" error from coming back, make sure to:

  1. Regularly test your workflows: Test your workflows regularly to catch any issues before they cause problems.
  2. Use a Code node for complex conditions: If you have complex conditions, consider using a Code node to test them. This can help you catch any syntax errors or invalid conditions.
  3. Keep your n8n instance up to date: Make sure your n8n instance is up to date with the latest version. This can help fix any known issues with the Filter node.

When to escalate

If you've tried the steps above and are still experiencing issues with the "Filter condition is invalid" error, it may be time to escalate the issue. Reach out to the n8n community or support team for further assistance. Provide as much detail as possible about the issue, including the condition you're using and any error messages you're seeing. This will help the support team provide a more accurate solution to your problem.
