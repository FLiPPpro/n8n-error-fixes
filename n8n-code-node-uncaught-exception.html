Uncaught Exception in n8n Code Node due to require is not defined

Error: Uncaught Exception: require is not defined · Node: Code

What this error actually means

The error message "Uncaught Exception: require is not defined" indicates that the n8n Code node is attempting to use the require function, which is a part of the Node.js API, but this function is not available in the current context. This is likely because the Code node is not configured to use a Node.js environment.

The three most common causes

There are three common causes for this error:

  1. Missing Node.js environment: The Code node is not configured to use a Node.js environment, which is required for the require function to work.
  2. Incorrect Node.js version: The Code node is configured to use a Node.js version that does not support the require function.
  3. Missing or incorrect node field: The node field in the Code node is not set to a valid Node.js module, or it is set to a module that does not exist.

Step-by-step fix

To fix this error, follow these steps:

  1. Open the Code node and navigate to the Settings tab.
  2. In the Settings tab, make sure that Node.js is selected as the Environment.
  3. If you are using a custom Node.js version, make sure it is a version that supports the require function. You can check the Node.js version by running node -v in the Code node's Console tab.
  4. In the Code field, make sure that the node field is set to a valid Node.js module. If you are using a custom module, make sure it is installed and available in the Node.js environment.

Here is an example of how to set the node field to a valid Node.js module:

{
  "node": "path/to/module.js"
}

Replace path/to/module.js with the actual path to the Node.js module you want to use.

If you are using a custom module, you can also use the require function to load the module:

const myModule = require('path/to/module.js');

Make sure to replace path/to/module.js with the actual path to the Node.js module you want to use.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Always select Node.js as the Environment in the Code node's Settings tab.
  • Use a valid Node.js version that supports the require function.
  • Set the node field to a valid Node.js module.
  • Use the require function to load custom modules.

When to escalate

If you have tried the above steps and the error persists, it may be worth escalating the issue to the n8n support team. Provide them with the following information:

  • The exact error message.
  • The n8n version you are using.
  • The Code node's configuration, including the Settings tab and the Code field.
  • Any custom modules you are using.

This will help the support team to better understand the issue and provide a more accurate solution.
