n8n Webhook node returns SSL disabled error

Error: SSL connection is required · Node: Webhook

What this error actually means

When you encounter the "SSL connection is required" error in n8n while setting up a Webhook, it means that the node is unable to establish a secure connection with the target URL. This is because the Webhook node in n8n requires a secure connection (HTTPS) to function properly.

The three most common causes

There are several reasons why you might encounter this error. Here are the three most common causes:

  1. Target URL is not using HTTPS: Make sure that the target URL you're trying to connect to is using HTTPS (e.g., https://example.com). If it's not, you'll need to update the URL to use HTTPS.
  2. SSL/TLS not enabled on the node: Ensure that SSL/TLS is enabled on the Webhook node. You can do this by checking the node's Settings tab and looking for the "SSL/TLS" option.
  3. Incorrect SSL/TLS configuration: If you're using a self-signed certificate or a custom SSL/TLS configuration, ensure that it's correctly set up and configured on the node.

Step-by-step fix

To fix the "SSL connection is required" error, follow these steps:

  1. Check the target URL: Ensure that the target URL is using HTTPS (e.g., https://example.com).
  2. Update the node configuration:
{
  "name": "Webhook",
  "settings": {
    "url": "https://example.com",
    "method": "POST",
    "headers": {
      "Content-Type": "application/json"
    },
    "body": {
      "username": "your_username",
      "password": "your_password"
    }
  }
}

In the above code, update the url field to use HTTPS.

  1. Enable SSL/TLS on the node:

* Go to the node's Settings tab. * Look for the "SSL/TLS" option. * Enable SSL/TLS by selecting the correct certificate or configuration.

  1. Verify the connection:

* Save the node configuration. * Run a test workflow to verify that the Webhook node is able to connect to the target URL using HTTPS.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Regularly update your target URLs to use HTTPS.
  • Ensure that your SSL/TLS configuration is correctly set up and configured on the node.
  • Test your workflows regularly to catch any potential issues.

When to escalate

If you've followed the steps above and are still encountering the "SSL connection is required" error, it's likely that there's a more complex issue at play. In this case, it's recommended to:

  • Check your n8n logs for any error messages related to the Webhook node.
  • Consult the n8n documentation and community forums for further assistance.
  • Reach out to the n8n support team for help resolving the issue.
