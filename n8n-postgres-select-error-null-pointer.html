Postgres Select Node Error: TypeError: Cannot read properties of null

Error: TypeError: Cannot read properties of null (reading 'X') · Node: Postgres

What this error actually means

The TypeError: Cannot read properties of null (reading 'X') error in n8n is caused by attempting to access a property of a null object. In the context of the Postgres node, this error occurs when the node tries to select data from a Postgres table, but the column specified in the query is null.

When a column is null, the Postgres node attempts to access its properties, resulting in the error. This error is not specific to n8n or Postgres, but rather a common issue that can occur when working with databases.

The three most common causes

There are three common causes of this error:

  1. Incorrect column selection: Make sure you are selecting the correct column from the Postgres table. Double-check the column name and its data type.
  2. Null column: If the column is intentionally null, you may need to adjust your query to handle this case. For example, you can use the COALESCE function to return a default value if the column is null.
  3. Postgres node configuration: Ensure that the Postgres node is configured correctly. Check the node's settings, such as the database connection, table name, and column selection.

Step-by-step fix

To fix the error, follow these steps:

  1. Check the column selection: Verify that you are selecting the correct column from the Postgres table. If the column is intentionally null, you may need to adjust your query to handle this case.
  2. Use COALESCE function: If the column is null, you can use the COALESCE function to return a default value. For example, if you want to return an empty string if the column is null, use the following SQL query:
SELECT COALESCE(column_name, '') AS column_name
FROM table_name;
  1. Configure Postgres node: Ensure that the Postgres node is configured correctly. Check the node's settings, such as the database connection, table name, and column selection.
  2. Use a Code node: If you need to perform complex logic to handle null columns, consider using a Code node. You can write JavaScript or Python code to handle the null columns and return a default value.

Here is an example of how you can use a Code node to handle null columns:

const result = [];
const query = "SELECT column_name FROM table_name";
const rows = await db.query(query);
rows.forEach((row) => {
  const columnName = row.column_name;
  if (columnName === null) {
    result.push({ column_name: '' });
  } else {
    result.push({ column_name: columnName });
  }
});
return result;

Prevent it from coming back

To prevent this error from occurring in the future, follow these best practices:

  1. Test your queries: Before running your queries in n8n, test them in a SQL client or IDE to ensure they are correct.
  2. Use COALESCE function: When selecting columns that may be null, use the COALESCE function to return a default value.
  3. Configure Postgres node correctly: Ensure that the Postgres node is configured correctly, including the database connection, table name, and column selection.
