Slack node reports API token has expired in n8n

Error: API token has expired · Node: Slack

What this error actually means

When you see the error "API token has expired" in n8n, it means that the Slack API token you're using in your workflow has reached its expiration date. This token is used to authenticate your workflow with the Slack API, and without a valid token, your workflow will not be able to interact with Slack.

The three most common causes

There are three common causes for this error:

  1. Token expiration: The most common cause is that the token has simply expired. This can happen if you've set a short expiration time for your token or if you've forgotten to renew it.
  2. Token not properly set up: Another common cause is that the token is not properly set up in your n8n workflow. Make sure that you've entered the token correctly and that it's set as the Authorization header in the HTTP Request node.
  3. Token not renewed: If you've set up a token with a renewal process, but haven't properly implemented it, the token may expire and not be renewed.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the token expiration: Go to the Slack API dashboard and check the token expiration date. If it's expired, renew the token and update the token in your n8n workflow.
  2. Check the token setup: Go to the HTTP Request node in your n8n workflow and check that the token is set as the Authorization header. Make sure that the token is entered correctly and that it's set to the correct scope.
  3. Implement token renewal: If you've set up a token with a renewal process, implement it correctly. You can do this by using a Code node to call the Slack API and renew the token.

  1. Update the token: Once you've renewed the token, update it in your n8n workflow.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Set a reminder to renew the token before it expires
  • Implement a token renewal process using a Code node
  • Use a longer token expiration time to give yourself more time to renew the token

When to escalate

If you've followed these steps and the error still persists, it may be time to escalate the issue. This could be due to a more complex issue with your n8n workflow or with the Slack API. In this case, reach out to the n8n support team or a Slack API expert for further assistance.
