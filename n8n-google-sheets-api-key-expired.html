Google Sheets node reports API key has expired in n8n

Error: API key has expired · Node: Google Sheets

What this error actually means

The "API key has expired" error in n8n is a common issue when working with Google Sheets. This error occurs when the API key used to authenticate your workflow has reached its expiration date. This can happen due to various reasons such as the key being set to expire after a certain period or being manually revoked.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. API key expiration: The most common cause is when the API key is set to expire after a certain period. This can be due to the key being created with a limited lifespan or being manually revoked.
  2. Incorrect API key configuration: Sometimes, the API key is not properly configured in the n8n workflow, leading to authentication issues.
  3. Google Sheets API changes: Google may make changes to their API, which can cause issues with your workflow.

Step-by-step fix

To fix the "API key has expired" error, follow these steps:

  1. Check the API key expiration date: Go to the Google Cloud Console and check the API key's expiration date. If it has expired, create a new key with a longer lifespan or update the existing key.
  2. Update the API key in n8n: Go to your n8n workflow and update the API key in the Google Sheets node. Make sure to select the correct key from the dropdown list.
  3. Configure retry settings: Configure the retry settings on the HTTP Request node or the Google Sheets node to retry the request with the new API key. You can set the number of retries, wait time between retries, and other options as needed.

Here's an example of how to configure the retry settings in a Code node:

{
  "name": "Get Google Sheets Data",
  "parameters": {
    "url": "https://sheets.googleapis.com/v4/spreadsheets/{spreadsheetId}/values/{range}",
    "options": {
      "method": "GET",
      "headers": {
        "Authorization": "Bearer {{newApiKey}}"
      },
      "retryOnFail": true,
      "maxTries": 3,
      "waitBetweenTries": 5000 // 5 seconds
    }
  }
}

In this example, we're using a Code node to update the API key in the Google Sheets node. We're setting the retryOnFail option to true and configuring the number of retries and wait time between retries.

  1. Test the workflow: Once you've updated the API key and configured the retry settings, test the workflow to ensure it's working as expected.

Prevent it from coming back

To prevent the "API key has expired" error from coming back, make sure to:

  • Regularly check the API key expiration date and update it as needed.
  • Configure the retry settings to handle temporary authentication issues.
  • Monitor your workflow's logs to catch any authentication issues early.

When to escalate

If you've tried the above steps and the error persists, it may be time to escalate the issue. Reach out to your Google Cloud support team or n8n support team for further assistance. Provide them with the workflow logs and any relevant information to help them troubleshoot the issue.
