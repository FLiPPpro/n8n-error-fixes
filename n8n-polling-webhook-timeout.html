Webhook Node Times Out When Polling API

Error: Timeout · Node: Webhook

What this error actually means

The "Timeout" error in n8n is a straightforward issue: the Webhook node is taking too long to receive a response from the API you're polling. This can happen for a variety of reasons, including slow API responses, network congestion, or even misconfigured node settings.

The three most common causes

Based on our experience, the three most common causes of the "Timeout" error in n8n are:

  1. Insufficient timeout settings: If you haven't configured the Webhook node's timeout settings, it will default to a very short timeout period, causing the node to fail.
  2. API response time: If the API you're polling is taking too long to respond, the Webhook node will timeout.
  3. Network issues: If there are network issues or congestion between your n8n instance and the API, the Webhook node may timeout.

Step-by-step fix

To fix the "Timeout" error, follow these steps:

  1. Check the Webhook node's timeout settings: Go to the Webhook node's Settings tab and check the "Timeout (ms)" setting. If it's set to a very short value (e.g. 1000ms), increase it to a more reasonable value (e.g. 30000ms).
  2. Configure retries: Go to the Webhook node's Settings tab and enable "Retry On Fail". Set "Max Tries" to a reasonable value (e.g. 5) and "Wait Between Tries (ms)" to a value that makes sense for your use case (e.g. 1000ms).
  3. Add a delay: If you suspect that the API response time is the issue, you can add a delay using the "Wait" node. Create a new "Wait" node and set the "Time (ms)" field to a value that's slightly longer than the expected API response time.
  4. Use a Code node to add a timeout: If you need more control over the timeout settings, you can use a Code node to add a timeout. Create a new Code node and paste the following JavaScript code:
const timeout = 30000; // 30 seconds
const timeoutError = new Error('Timeout');
this.on('data', () => {
  setTimeout(() => {
    throw timeoutError;
  }, timeout);
});

This code will throw a timeout error after 30 seconds if no data is received.

Prevent it from coming back

To prevent the "Timeout" error from coming back, make sure to:

  • Monitor your API response times and adjust the Webhook node's timeout settings accordingly.
  • Regularly review your n8n logs to identify any issues with the Webhook node.
  • Consider implementing a more robust retry strategy using the "Retry On Fail" setting.

When to escalate

If you've followed the steps above and the "Timeout" error persists, it's likely that there's an underlying issue with your n8n instance or the API you're polling. In this case, it's time to escalate the issue to your n8n support team or a qualified developer who can help you troubleshoot the issue. Make sure to provide as much detail as possible about the error, including the error message, node settings, and any relevant logs.
