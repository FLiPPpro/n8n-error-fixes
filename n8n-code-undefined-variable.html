n8n Code node throws 'undefined is not an object'

Error: ReferenceError: Variable is not defined · Node: Code

What this error actually means

The "ReferenceError: Variable is not defined" error in n8n's Code node is a common issue that occurs when you try to use a variable that has not been declared or initialized. This error is thrown by the JavaScript engine when it encounters a variable that is not defined in the current scope.

In the context of the Code node, this error typically means that you are trying to access a variable that is not defined within the code block itself. This can happen when you are trying to use a variable that is defined in an external scope, such as a workflow parameter or a previous node's output.

The three most common causes

There are three common causes of this error:

  1. Variable not defined in the code block: Make sure that the variable you are trying to use is defined within the code block. Check that the variable is declared and initialized before it is used.
  2. Scope issues: Ensure that the variable is in scope within the code block. If the variable is defined in an external scope, you may need to use a different approach to access it.
  3. Typo or naming conflict: Check that the variable name is correct and not conflicting with any other variable or function name.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the variable declaration: Make sure that the variable is declared and initialized before it is used. Check the code block for any typos or naming conflicts.
  2. Use the {{ }} syntax: If the variable is defined in an external scope, you can use the {{ }} syntax to access it. For example:
{{#each items}}
  {{#if item.status === 'active'}}
    // do something
  {{/if}}
{{/each}}

In this example, items is an array of objects that is defined in an external scope. The {{#each }} syntax is used to iterate over the array, and the {{#if }} syntax is used to check the status of each item.

  1. Use a Code node to declare the variable: If the variable is not defined in an external scope, you can declare it in a Code node. For example:
// declare a variable
var myVariable = 'hello';

// use the variable
console.log(myVariable);

In this example, the variable myVariable is declared in the Code node, and then used in the same node.

  1. Check the node's settings: Make sure that the node's settings are correct. Check the "Retry On Fail", "Max Tries", and "Wait Between Tries (ms)" settings to ensure that they are not causing the error.

Prevent it from coming back

To prevent this error from coming back, follow these best practices:

  1. Declare variables carefully: Make sure that variables are declared and initialized before they are used.
  2. Use the {{ }} syntax carefully: Use the {{ }} syntax to access variables defined in external scopes, but be careful not to introduce naming conflicts.
  3. Test your code: Test your code thoroughly to ensure that it works as expected.
  4. Use a Code node to declare variables: Consider declaring variables in a Code node to avoid scope issues.

When to escalate

If you have followed the steps above and the error still persists, it may be time to escalate the issue to the n8n community or support team. Provide as much detail as possible about the error, including the error message, the code block, and any relevant settings. This will help the community or support team to provide a more accurate and timely solution.
