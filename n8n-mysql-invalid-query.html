Invalid Query in MySQL Node n8n Error

Error: Error: Invalid query · Node: MySQL

What this error actually means

When you encounter the "Error: Invalid query" error in n8n's MySQL node, it means that the query you're trying to execute is not valid SQL. This can happen for a variety of reasons, such as a typo in the query, a missing or extra semicolon, or an invalid SQL syntax.

The three most common causes

Based on our experience and user reports, the three most common causes of the "Error: Invalid query" error in the MySQL node are:

  1. Typo in the query: A simple typo in the query can cause the error. Make sure to double-check the query for any spelling mistakes.
  2. Missing or extra semicolon: A semicolon is required at the end of a SQL query. If you're missing a semicolon or have an extra one, it can cause the error.
  3. Invalid SQL syntax: SQL has specific syntax rules that must be followed. If you're using an invalid syntax, such as a missing or extra bracket, it can cause the error.

Step-by-step fix

To fix the error, follow these steps:

  1. Check the query: Double-check the query for any typos or spelling mistakes. Make sure to review the query carefully, as a small mistake can cause the error.
  2. Verify the semicolon: Ensure that the query has a semicolon at the end. If you're using a semicolon in the middle of the query, remove it.
  3. Check the SQL syntax: Verify that the SQL syntax is correct. Check for any missing or extra brackets, and ensure that the query is formatted correctly.

Here's an example of a query that might cause the error:

SELECT * FROM users WHERE name = 'John Doe'

To fix this query, you might need to add a semicolon at the end:

SELECT * FROM users WHERE name = 'John Doe';

Alternatively, you might need to remove the semicolon in the middle of the query:

SELECT * FROM users WHERE name = 'John Doe'
  1. Run the query in a Code node: If you're still having trouble, try running the query in a Code node. This will allow you to see the exact error message and debug the query further.

Prevent it from coming back

To prevent the error from coming back, make sure to:

  1. Test the query: Before running the query in n8n, test it in a MySQL client or a Code node to ensure it's valid.
  2. Use a Code node: If you're unsure about the query, run it in a Code node to see the exact error message.
  3. Configure retries: Configure retries on the MySQL node to retry the query in case of an error.

When to escalate

If you've tried the above steps and are still experiencing issues, it's time to escalate the problem. Reach out to the n8n community or support team for further assistance. Provide as much detail as possible about the error, including the exact error message and any relevant logs. This will help the support team to better understand the issue and provide a more accurate solution.
