n8n MongoDB node explicit cast error

Error: needs explicit cast. · Node: MongoDB

What this error actually means

When you encounter the "needs explicit cast" error in n8n's MongoDB node, it means that the node is unable to automatically convert the field value to the expected data type. This error typically occurs when the field value is of a different data type than what is specified in the node's settings.

The three most common causes

There are three common causes of this error:

  1. Data type mismatch: The field value is of a different data type than what is specified in the node's settings. For example, if you're trying to set a field value to a string, but the field is defined as an integer.
  2. Invalid field value: The field value is invalid or contains special characters that are not allowed in the specified data type.
  3. Node settings not properly configured: The node's settings, such as the data type or field name, are not properly configured.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the field value: Verify that the field value is valid and does not contain any special characters. If the value is invalid, you'll need to correct it before proceeding.
  2. Check the data type: Verify that the field value is of the correct data type. If it's not, you'll need to update the field value or change the data type in the node's settings.
  3. Use an explicit cast: If the field value is of a different data type than what is specified in the node's settings, you'll need to use an explicit cast to convert the value to the correct data type. You can do this using the JSON.parse() function in a Code node.

Here's an example of how to use an explicit cast in a Code node:

{
  "name": "Set Field Value",
  "parameters": {
    "value": "{\"field\": {{=json.parse(\"'123'\")}}}"
  }
}

In this example, the json.parse() function is used to convert the string '123' to an integer.

  1. Update the node settings: Once you've verified the field value and data type, update the node settings to reflect the correct data type.

Prevent it from coming back

To prevent this error from coming back in the future, follow these best practices:

  • Verify field values: Always verify that field values are valid and do not contain any special characters.
  • Use explicit casts: Use explicit casts to convert field values to the correct data type when necessary.
  • Update node settings: Regularly review and update node settings to ensure they are properly configured.

When to escalate

If you've tried the above steps and are still experiencing issues, it's likely that the problem is more complex and requires further investigation. In this case, you should escalate the issue to the n8n support team for further assistance. Provide as much detail as possible about the error, including any relevant node settings and field values.
