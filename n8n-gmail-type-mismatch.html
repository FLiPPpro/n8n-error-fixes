n8n Gmail node type mismatch error message

Error: value is not of expected type · Node: Gmail

What this error actually means

When you see the error message "value is not of expected type" in n8n, it means that the data type of the value you're trying to set in a field does not match the expected data type for that field. This can happen when you're trying to set a value for a field that expects a specific data type, such as a string, number, or boolean.

For example, if you have a field that expects a string value, but you're trying to set it to a number, you'll see this error message.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Data type mismatch: This is the most common cause of this error. It happens when you're trying to set a value to a field that expects a different data type.
  2. Incorrect field type: This happens when you've set the field type to the wrong data type in the node's settings.
  3. Invalid value: This happens when you're trying to set a value that is not valid for the field's data type.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the field type: Go to the node's settings and check the field type. Make sure it matches the data type of the value you're trying to set.
  2. Check the data type of the value: Check the data type of the value you're trying to set. Make sure it matches the field type.
  3. Use the correct data type: If the value is not of the correct data type, convert it to the correct data type. For example, if you're trying to set a string value to a field that expects a number, you can use the toString() function to convert the value to a string.

Here's an example of how you can convert a value to the correct data type using a Code node:

function convertValue(value) {
  if (typeof value === 'number') {
    return value.toString();
  } else {
    return value;
  }
}

// Set the value to the field
value = convertValue(value);

In this example, we're using a JavaScript function to convert the value to a string if it's a number. You can modify this function to suit your needs.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Double-check the field type and data type of the value.
  • Use the correct data type for the value.
  • Test the workflow with different data types and values.

When to escalate

If you've tried the above steps and the error still persists, it may be worth escalating the issue to our support team. Provide them with the following information:

  • The error message
  • The node and field that's causing the error
  • The data type of the value you're trying to set
  • The expected data type of the field
  • Any relevant code or workflow settings

This will help our support team to better understand the issue and provide a more accurate solution.
