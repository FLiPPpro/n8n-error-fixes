n8n Postgres "SSL connection is required" — Fix

Error: no pg_hba.conf entry / SSL connection is required · Node: Postgres

What this error actually means

When you see the error message "no pg_hba.conf entry / SSL connection is required" in n8n, it means that the Postgres node is trying to connect to your Postgres database without using SSL encryption. This is a security requirement for many managed Postgres services like Supabase, Neon, and RDS, which is why you're seeing this error.

The three most common causes

There are three common reasons why this error occurs:

  1. Postgres credential has SSL disabled: When you create a Postgres credential in n8n, you need to make sure that the "Use SSL" option is enabled. If it's not, the Postgres node will try to connect without SSL, resulting in this error.
  2. Incorrect Postgres connection URL: If you're using a managed Postgres service, the connection URL might require SSL encryption. Make sure you're using the correct connection URL and that it includes the SSL parameters.
  3. Postgres node configuration: The Postgres node in n8n has a "Use SSL" option that needs to be enabled. If this option is disabled, the node will try to connect without SSL.

Step-by-step fix

To fix this error, follow these steps:

  1. Go to the Postgres credential in n8n and make sure that the "Use SSL" option is enabled.
  2. If you're using a managed Postgres service, check the connection URL to make sure it includes the SSL parameters. For example, if you're using Supabase, the connection URL should look like this: postgresql://user:password@supabase-host:5432/database?sslmode=require
  3. If you're using a self-hosted Postgres instance, make sure that the pg_hba.conf file is configured to allow SSL connections. You can do this by adding the following line to the pg_hba.conf file: hostssl all all 0.0.0.0/0 trust
  4. Go to the Postgres node in your workflow and make sure that the "Use SSL" option is enabled.

Here's an example of how you can modify the Postgres connection URL to include the SSL parameters using a Code node:

{
  "connectionUrl": "postgresql://user:password@supabase-host:5432/database?sslmode=require",
  "useSsl": true
}

You can paste this code into a Code node and then use the connectionUrl and useSsl variables in the Postgres node.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Enable the "Use SSL" option in the Postgres credential.
  • Use the correct connection URL that includes the SSL parameters.
  • Regularly check the pg_hba.conf file to make sure it's configured correctly.

When to escalate

If you've tried the above steps and the error still persists, it's time to escalate the issue. Reach out to your n8n support team or the support team of your managed Postgres service for further assistance. Provide them with the error message and the steps you've taken to troubleshoot the issue.
