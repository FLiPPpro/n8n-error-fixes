Slack webhook not registered in n8n error

Error: The requested webhook is not registered · Node: Slack

What this error actually means

When you encounter the "The requested webhook is not registered" error in n8n while trying to test your Slack webhook after a workflow stopped listening, it means that the Slack webhook URL you're trying to use is not properly registered in your Slack workspace. This error is not related to n8n itself, but rather to the Slack API.

The three most common causes

There are three common causes for this error:

  1. Webhook URL not registered: The most common cause is that the Slack webhook URL you're trying to use is not registered in your Slack workspace. Make sure that the webhook URL is created and registered in your Slack settings.
  2. Webhook URL expired: Another possible cause is that the webhook URL has expired. Check the expiration date of your webhook URL in your Slack settings and recreate it if necessary.
  3. Incorrect webhook URL: You might have entered the incorrect webhook URL in your n8n workflow. Double-check the URL to ensure it matches the one registered in your Slack workspace.

Step-by-step fix

To fix this issue, follow these steps:

  1. Check your Slack webhook URL: Go to your Slack workspace settings and check the webhook URL. Make sure it's created and registered correctly.
  2. Recreate the webhook URL: If the webhook URL has expired, recreate it in your Slack settings.
  3. Update your n8n workflow: Update the webhook URL in your n8n workflow to match the new one created in your Slack settings.

Here's an example of how to update the webhook URL in your n8n workflow using a Code node:

{
  "name": "Update Webhook URL",
  "parameters": {
    "functionCode": "function() {\n  // Update the webhook URL to the new one created in Slack settings\n  return {\n    webhookUrl: 'https://example.com/webhook'\n  };\n}"
  },
  "type": "n8n-nodes-base.code"
}

Replace https://example.com/webhook with the new webhook URL created in your Slack settings.

  1. Test your workflow: After updating the webhook URL, test your workflow again to ensure it's working correctly.

Prevent it from coming back

To prevent this issue from coming back, make sure to:

  • Regularly check your Slack webhook URL to ensure it's not expired.
  • Update your n8n workflow with the new webhook URL if it changes.
  • Use a Code node to update the webhook URL dynamically if it changes.

When to escalate

If you've tried the above steps and the issue persists, it's likely a more complex issue that requires further investigation. In this case, it's recommended to:

  • Reach out to the n8n community for further assistance.
  • Check the n8n documentation for any updates or changes that may be causing the issue.
  • If you're still unable to resolve the issue, consider reaching out to the n8n support team for further assistance.
