n8n Code node execution error on Linux server

Error: Error executing code: Command not found · Node: Code

What this error actually means

When you encounter the "Error executing code: Command not found" error in n8n, it means that the code you've written in a Code node is attempting to execute a command that doesn't exist on your system. This can happen when you're trying to run a custom command or script that relies on specific dependencies or executables.

The three most common causes

  1. Missing dependencies: The code in your Code node is trying to execute a command that requires a specific dependency or executable, but it's not installed on your system.
  2. Typo in command: You've entered the command incorrectly, and it's not recognized by your system.
  3. Incorrect path: The command or executable is installed, but it's not in the system's PATH, so the Code node can't find it.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the command: Double-check the command you've entered in the Code node. Make sure it's correct and matches the command you're trying to execute.
  2. Verify dependencies: Ensure that all dependencies required by the command are installed on your system. You can do this by checking the command's documentation or running apt-get install (on Ubuntu-based systems) or yum install (on Red Hat-based systems) to install the necessary packages.
  3. Specify the full path: If the command or executable is installed but not in the system's PATH, specify the full path to the executable in the Code node. For example, if you have a Python script in a directory like /home/user/bin, you can use the full path in the Code node like this: python /home/user/bin/script.py
  4. Use a Code node with a specific interpreter: If you're trying to execute a script that requires a specific interpreter (like Python or Node.js), make sure to select the correct interpreter in the Code node's settings.

Here's an example code block that demonstrates how to specify the full path to an executable in a Code node:

{
  "name": "Execute custom script",
  "parameters": {
    "command": "/home/user/bin/script.sh",
    "type": "script"
  }
}

In this example, the Code node is trying to execute a shell script located at /home/user/bin/script.sh. Make sure to replace the path with the actual location of your script.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Double-check the command and dependencies before executing the code.
  • Use the full path to the executable if it's not in the system's PATH.
  • Test the code in a Code node with a specific interpreter if required.

When to escalate

If you've tried the above steps and the error persists, it's likely that there's an underlying issue with your system or the n8n configuration. In this case, it's best to:

  • Check the n8n logs for any errors or warnings related to the Code node.
  • Verify that the system's PATH is correctly set and includes all necessary directories.
  • Reach out to the n8n community or support team for further assistance.
