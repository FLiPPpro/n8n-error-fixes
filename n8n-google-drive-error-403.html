Google Drive Node Returns Error 403 Forbidden

Error: 403 Forbidden · Node: Google Drive

What this error actually means

A 403 Forbidden error from the Google Drive node in n8n indicates that the node is unable to authenticate with the Google Drive API. This can happen due to various reasons such as incorrect API credentials, expired tokens, or insufficient permissions.

The three most common causes

Here are the three most common causes of a 403 Forbidden error from the Google Drive node:

  1. Incorrect API credentials: Make sure you have entered the correct Client ID and Client secret in the Google Drive node's Settings tab. If you are using a service account, ensure that the service account email address is correct.
  2. Expired tokens: If your tokens have expired, the Google Drive node will not be able to authenticate. Check the expiration time of your tokens and refresh them if necessary.
  3. Insufficient permissions: Ensure that the credentials you are using have the necessary permissions to access the Google Drive API. Check the Google Cloud Console to verify the permissions of your project.

Step-by-step fix

To fix the 403 Forbidden error, follow these steps:

  1. Check the API credentials: Verify that the Client ID and Client secret in the Google Drive node's Settings tab are correct. If you are using a service account, ensure that the service account email address is correct.
  2. Refresh tokens: If your tokens have expired, refresh them by clicking on the "Refresh" button in the Google Drive node's Settings tab.
  3. Check permissions: Verify that the credentials you are using have the necessary permissions to access the Google Drive API. Check the Google Cloud Console to verify the permissions of your project.

Here's an example code block that you can use to refresh tokens using a Code node:

{
  "name": "Refresh Tokens",
  "parameters": {
    "credentials": {
      "type": "string",
      "value": "your_client_secret"
    },
    "refreshToken": {
      "type": "string",
      "value": "your_refresh_token"
    }
  },
  "function": "refreshToken"
}

function refreshToken(credentials, refreshToken) {
  const { google } = require('googleapis');
  const auth = new google.auth.GoogleAuth({
    client_id: credentials.client_id,
    client_secret: credentials.client_secret,
    redirect_uri: credentials.redirect_uri
  });
  const token = await auth.getAccessToken(refreshToken);
  return token;
}

Replace your_client_secret and your_refresh_token with your actual client secret and refresh token.

Prevent it from coming back

To prevent the 403 Forbidden error from coming back, make sure to:

  • Regularly refresh your tokens to ensure they don't expire.
  • Verify that your API credentials are correct and up-to-date.
  • Ensure that your credentials have the necessary permissions to access the Google Drive API.

When to escalate

If you have tried the above steps and the issue persists, it may be necessary to escalate the issue to the n8n support team. Provide them with the following information:

  • The exact error message and any relevant logs.
  • The configuration of your Google Drive node, including API credentials and permissions.
  • Any custom code or workflows you have created to interact with the Google Drive API.
