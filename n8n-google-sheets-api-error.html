n8n Google Sheets API error on spreadsheet

Error: API error: ... ( error message ) · Node: Google Sheets

What this error actually means

When you encounter the API error "... (error message)" while accessing Google Sheets in n8n, it means that the request to Google Sheets failed due to an issue with the API itself. This error is not related to n8n's configuration or setup, but rather a problem with the Google Sheets API.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Insufficient permissions: Make sure you have the necessary permissions to access the Google Sheets API. You can check the permissions in the Google Cloud Console.
  2. API key or credentials issue: Ensure that your API key or credentials are correct and up-to-date. You can check the API key or credentials in the Google Cloud Console or in the n8n workflow.
  3. Rate limiting or quota exceeded: Google Sheets API has rate limits and quotas. If you exceed these limits, you will encounter this error. You can check the usage in the Google Cloud Console.

Step-by-step fix

To fix this error, follow these steps:

  1. Check permissions: Go to the Google Cloud Console and check if you have the necessary permissions to access the Google Sheets API. If not, add the necessary permissions.
  2. Verify API key or credentials: Ensure that your API key or credentials are correct and up-to-date. If not, update them in the Google Cloud Console or in the n8n workflow.
  3. Check rate limiting or quota: Check the usage in the Google Cloud Console. If you have exceeded the rate limits or quotas, reduce the frequency of requests or increase the quotas.

If you are still encountering the error after checking the above, you can add a retry mechanism to your workflow. To do this, follow these steps:

  1. Add a Wait node: Add a Wait node to your workflow with a delay of 5-10 seconds. This will pause the workflow for a short period of time.
  2. Add a HTTP Request node: Add a HTTP Request node to your workflow with the same settings as before. This will retry the request to Google Sheets.
  3. Configure retry options: In the HTTP Request node, configure the retry options:

* Retry On Fail: Enable this option to retry the request if it fails. * Max Tries: Set the maximum number of retries to 3-5. * Wait Between Tries (ms): Set the delay between retries to 5-10 seconds.

Here is a concrete code block that you can paste into a Code node:

// Set the retry options
const retryOptions = {
  retryOnFail: true,
  maxTries: 3,
  waitBetweenTries: 5000 // 5 seconds
};

// Set the HTTP request options
const httpRequestOptions = {
  method: 'GET',
  url: 'https://sheets.googleapis.com/v4/spreadsheets/{spreadsheetId}/values/{range}',
  headers: {
    'Authorization': 'Bearer {apiKey}',
    'Content-Type': 'application/json'
  },
  body: {
    spreadsheetId: '{spreadsheetId}',
    range: '{range}'
  }
};

// Make the HTTP request with retry options
n8n.nodes.httpRequest.request({
  ...httpRequestOptions,
  retryOptions
});

This code sets the retry options and HTTP request options, and makes the HTTP request with the retry options.

Prevent it from coming back

To prevent this error from coming back, follow these best practices:

  1. Monitor API usage: Regularly check the API usage in the Google Cloud Console to ensure you are not exceeding the rate limits or quotas.
  2. Implement rate limiting: Implement rate limiting in your workflow to prevent excessive requests to the Google Sheets API.
  3. Keep API keys and credentials up-to-date: Regularly update your API keys and credentials to ensure they are correct and up-to-date.

When to escalate

If you have followed the above steps and are still encountering the error, it may be necessary to escalate the issue to the n8n support team or the Google Cloud Support team. Provide them with the error message, API usage, and any other relevant information to help them troubleshoot the issue.
