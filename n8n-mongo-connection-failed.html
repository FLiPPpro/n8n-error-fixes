MongoDB Node Connection Failed Error in n8n Workflow

Error: MongoDB connection failed · Node: MongoDB

What this error actually means

The "MongoDB connection failed" error is a generic error message that doesn't provide much information about the actual cause of the issue. However, it's a clear indication that n8n is unable to establish a connection to your MongoDB database.

When this error occurs, it means that n8n has attempted to connect to your MongoDB database using the credentials and settings you provided in the MongoDB node, but the connection was unsuccessful.

The three most common causes

After analyzing various scenarios, we've identified the three most common causes of the "MongoDB connection failed" error:

  1. Incorrect MongoDB credentials: Double-check that you've entered the correct MongoDB username, password, and host in the MongoDB node's Settings tab.
  2. MongoDB server not running or not accessible: Ensure that your MongoDB server is running and accessible from the n8n environment. You can use a tool like telnet or curl to test the connection to your MongoDB server.
  3. Incorrect MongoDB database name or collection: Verify that you've entered the correct MongoDB database name and collection in the MongoDB node's Settings tab.

Step-by-step fix

To resolve the "MongoDB connection failed" error, follow these steps:

  1. Check your MongoDB credentials: Go to the MongoDB node's Settings tab and verify that you've entered the correct MongoDB username, password, and host.
  2. Test your MongoDB connection: Use a tool like telnet or curl to test the connection to your MongoDB server. For example, you can use the following curl command to test the connection:
curl -u "your_username:your_password" "mongodb://your_host:27017/"
  1. Verify your MongoDB database name and collection: Ensure that you've entered the correct MongoDB database name and collection in the MongoDB node's Settings tab.
  2. Configure retries: If you're confident that your MongoDB credentials and settings are correct, you can configure retries in the MongoDB node's Settings tab. Set the "Retry On Fail" option to true, and adjust the "Max Tries" and "Wait Between Tries (ms)" options as needed.

Here's an example code block that you can use to test your MongoDB connection using a Code node:

const MongoClient = require('mongodb').MongoClient;

const url = 'mongodb://your_host:27017/';
const dbName = 'your_database_name';
const collectionName = 'your_collection_name';

MongoClient.connect(url, function(err, client) {
  if (err) {
    console.error(err);
  } else {
    const db = client.db(dbName);
    const collection = db.collection(collectionName);
    console.log('Connected to MongoDB!');
  }
});

Paste this code into a Code node, and adjust the url, dbName, and collectionName variables to match your MongoDB credentials and settings.

Prevent it from coming back

To prevent the "MongoDB connection failed" error from occurring in the future, make sure to:

  • Regularly test your MongoDB connection using a tool like telnet or curl.
  • Verify that your MongoDB credentials and settings are up-to-date.
  • Configure retries in the MongoDB node's Settings tab to handle temporary connection issues.

When to escalate

If you've followed the steps above and still encounter the "MongoDB connection failed" error, it's likely that there's a more serious issue with your MongoDB server or configuration. In this case, you should:

  • Check your MongoDB server logs for any error messages or warnings.
  • Verify that your MongoDB server is running and accessible from the n8n environment.
  • Consult with your MongoDB administrator or a MongoDB expert to resolve the issue.

If you're still unable to resolve the issue, you may need to escalate the problem to the n8n support team for further assistance.
