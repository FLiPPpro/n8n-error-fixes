HTTP Request Node Returns 401 Unauthorized Error

Error: 401 Unauthorized · Node: HTTP Request

What this error actually means

When you encounter a 401 Unauthorized error in n8n, it means that the HTTP Request node is unable to authenticate with the API you're trying to call. This can happen for a variety of reasons, including:

  • Incorrect API credentials
  • Missing or invalid API keys
  • Insufficient permissions or scopes

The three most common causes

Based on our experience, the three most common causes of 401 Unauthorized errors in n8n are:

  1. Incorrect API credentials: Double-check that you've entered the correct API key, username, and password in the HTTP Request node's Settings tab.
  2. Missing or invalid API keys: Ensure that you've obtained the correct API key from the API provider and entered it in the correct field in the HTTP Request node.
  3. Insufficient permissions or scopes: Verify that the API credentials you're using have the necessary permissions and scopes to access the API endpoint you're trying to call.

Step-by-step fix

To fix the 401 Unauthorized error, follow these steps:

  1. Check the API credentials: Go to the HTTP Request node's Settings tab and verify that the API key, username, and password are correct.
  2. Add retry options: In the HTTP Request node's Settings tab, enable the "Retry On Fail" option and set the "Max Tries" to a higher value (e.g. 5). This will allow the node to retry the API call up to 5 times if it fails initially.
  3. Add a delay: If you suspect that the API is rate-limiting your requests, add a delay between retries using the "Wait" node. For example:
{
  "nodes": [
    {
      "name": "HTTP Request",
      "settings": {
        "retryOnFail": true,
        "maxTries": 5,
        "waitBetweenTries": 5000 // 5-second delay
      },
      "type": "n8n-nodes-base.httpRequest",
      "typeVersion": 1,
      "position": [
        300,
        300
      ]
    },
    {
      "name": "Wait",
      "settings": {
        "milliseconds": 5000 // 5-second delay
      },
      "type": "n8n-nodes-base.wait",
      "typeVersion": 1,
      "position": [
        400,
        300
      ]
    }
  ]
}
  1. Verify the API response: Use the "Code" node to log the API response and verify that it's not being rate-limited or blocked.

Prevent it from coming back

To prevent the 401 Unauthorized error from coming back, make sure to:

  • Regularly review and update your API credentials to ensure they're valid and up-to-date.
  • Monitor your API usage and adjust your retry options accordingly.
  • Consider implementing rate limiting or throttling on your API calls to prevent excessive requests.

When to escalate

If you've tried the above steps and the 401 Unauthorized error persists, it may be time to escalate the issue to the API provider or your organization's IT department. Be sure to provide detailed information about the error, including any relevant logs or debug output.
