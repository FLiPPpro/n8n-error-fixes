n8n Switch node type mismatch error message

Error: value is not of expected type · Node: Switch

What this error actually means

When you encounter the "value is not of expected type" error in n8n, it means that the data type of the value being set in a field does not match the expected data type specified in the field's settings. This can happen when you're using a Switch node, for example, and trying to set a field value to a string, but the field is expecting a number.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Data type mismatch: When you're setting a field value to a string, but the field is expecting a number, or vice versa.
  2. Incorrect field settings: When the field settings are not properly configured to match the data type of the value being set.
  3. Expression errors: When the expression used to set the field value is incorrect or not properly formatted.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the field settings: Go to the Switch node's Settings tab and verify that the field settings match the data type of the value being set. If the field is expecting a string, make sure the value being set is a string. If the field is expecting a number, make sure the value being set is a number.
  2. Use the correct expression: If you're using an expression to set the field value, make sure it's properly formatted and returns the correct data type. You can use the {{ }} syntax to write inline expressions or create a Code node to write JavaScript or Python code.
  3. Use a Code node to convert data types: If you're setting a field value to a string, but the field is expecting a number, you can use a Code node to convert the value to the correct data type. For example, if you want to convert a string to a number, you can use the following JavaScript code in a Code node:
const value = "123";
const numberValue = parseInt(value);
return { numberValue };

This code will convert the string "123" to a number and return it as the output.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Double-check the field settings to ensure they match the data type of the value being set.
  • Use the correct expression to set the field value.
  • Use a Code node to convert data types if necessary.
  • Test your workflow thoroughly to catch any potential errors.

When to escalate

If you've tried the above steps and the error persists, it's time to escalate the issue. Reach out to the n8n community or contact our support team for further assistance. Provide as much detail as possible about the error, including the node configuration, expression code, and any relevant logs. This will help us to better understand the issue and provide a more accurate solution.
