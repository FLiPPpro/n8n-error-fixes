Cron Trigger Node Error: TypeError: Cannot read properties of undefined

Error: TypeError: Cannot read properties of undefined (reading 'expression') · Node: Cron

What this error actually means

The error message "TypeError: Cannot read properties of undefined (reading 'expression')" is a common issue when working with the Cron node in n8n. This error occurs when the Cron node tries to access the expression field of a non-existent or undefined object. In this case, the error is related to the Cron node's trigger configuration.

The three most common causes

After analyzing the error, we can identify three common causes:

  1. Incorrect Cron expression: The Cron node requires a valid Cron expression to trigger. If the expression is incorrect or missing, the node will throw an error.
  2. Missing or incorrect trigger configuration: The Cron node needs to be configured with a trigger to execute. If the trigger is missing or incorrectly configured, the node will throw an error.
  3. Non-existent or undefined expression: As mentioned earlier, the error occurs when the Cron node tries to access the expression field of a non-existent or undefined object.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the Cron expression: Ensure that the Cron expression is correct and valid. You can use online tools like [Cron Expression Evaluator](https://crontab.guru/) to test your expression.
  2. Configure the trigger: Make sure that the Cron node is configured with a trigger to execute. You can do this by navigating to the node's Settings tab and selecting the trigger type (e.g., "Schedule").
  3. Verify the expression field: Ensure that the expression field is correctly configured and populated with a valid value.

Here's an example code block that you can use to test the Cron expression:

{
  "name": "Test Cron",
  "nodes": [
    {
      "name": "Cron",
      "parameters": {
        "expression": "0 0 * * * *" // Test Cron expression
      },
      "type": "n8n-nodes-base.cron"
    }
  ]
}

Paste this code into a new workflow or a Code node to test the Cron expression.

Prevent it from coming back

To prevent this error from occurring in the future, follow these best practices:

  • Double-check the Cron expression for validity and correctness.
  • Ensure that the trigger is correctly configured and populated with a valid value.
  • Use the Continue On Fail setting on the node to handle errors and prevent the workflow from crashing.

When to escalate

If you've followed the steps above and the error persists, it may be necessary to escalate the issue to the n8n support team. Provide the following information to help them troubleshoot the issue:

  • The exact error message and node configuration.
  • The n8n version and node version.
  • Any relevant workflow or node configurations.

By following these steps and best practices, you should be able to resolve the "TypeError: Cannot read properties of undefined (reading 'expression')" error in the Cron node.
