Code node syntax error in n8n workflow

Error: Error: Syntax error occurred in Code node: Unexpected token · Node: Code

What this error actually means

The "Unexpected token" error in the Code node is a syntax error in the code you've written. This error occurs when the Code node tries to execute the code and encounters a syntax that it doesn't understand. This can be due to a variety of reasons such as missing or extra brackets, semicolons, or other syntax-related issues.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Missing or extra brackets: Make sure that you've used the correct number of brackets to enclose your code. If you're using JavaScript, ensure that you've closed all the brackets, parentheses, and curly brackets correctly.
  2. Incorrect syntax: Double-check that your code is syntactically correct. If you're using a programming language like JavaScript, make sure that you've used the correct syntax for variables, functions, and control structures.
  3. Unescaped special characters: If you're using special characters like {{ }} to enclose your code, ensure that they're properly escaped. For example, if you're using a string literal, you may need to escape the {{ }} characters using {{ { { }} }}.

Step-by-step fix

To fix the "Unexpected token" error, follow these steps:

  1. Check your code: Review your code carefully to ensure that it's syntactically correct. Look for missing or extra brackets, semicolons, or other syntax-related issues.
  2. Use a Code node with JavaScript or Python: Make sure that you're using a Code node with JavaScript or Python as the programming language. These languages are more forgiving than others and can help you catch syntax errors.
  3. Write your code in a Code node: Instead of writing your code inline in a field using {{ }} syntax, write it in a Code node. This will give you more flexibility to write complex code and make it easier to debug.
  4. Use a try-catch block: Wrap your code in a try-catch block to catch any syntax errors. Here's an example of a try-catch block in JavaScript:
try {
  // Your code here
} catch (error) {
  // Handle the error
  console.error(error);
}
  1. Check the error message: If you're still getting the "Unexpected token" error, check the error message to see if it's pointing to a specific line or character in your code. This can help you identify the exact issue.

Prevent it from coming back

To prevent this error from coming back, follow these best practices:

  1. Use a linter: Use a linter like ESLint to catch syntax errors in your code.
  2. Write unit tests: Write unit tests to ensure that your code is working as expected.
  3. Use a code editor with syntax highlighting: Use a code editor with syntax highlighting to make it easier to spot syntax errors.
  4. Review your code regularly: Regularly review your code to ensure that it's syntactically correct.

When to escalate

If you've tried the above steps and are still getting the "Unexpected token" error, it may be time to escalate the issue to our support team. Provide them with the following information:

  • The exact error message
  • The code that's causing the error

  • Any troubleshooting steps you've taken so far
