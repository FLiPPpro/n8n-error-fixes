MySQL node reports syntax error in query in n8n

Error: You have an error in your SQL syntax · Node: MySQL

What this error actually means

When you encounter the "You have an error in your SQL syntax" error in n8n's MySQL node, it's not a generic error message. It's a specific error that indicates the SQL query you're trying to execute has a syntax error. This error is not related to the data being inserted or updated, but rather with the structure of the query itself.

The three most common causes

After analyzing numerous reports and troubleshooting sessions, we've identified the three most common causes of this error:

  1. Missing or extra parentheses: SQL queries rely heavily on parentheses to group conditions and ensure the correct order of operations. A missing or extra pair of parentheses can lead to a syntax error.
  2. Incorrect table or column names: Make sure you're using the correct table and column names in your SQL query. A single typo or incorrect casing can cause the error.
  3. Unsupported SQL syntax: n8n's MySQL node supports a subset of SQL syntax. If you're using a feature or syntax that's not supported, you'll encounter this error.

Step-by-step fix

To fix the error, follow these steps:

  1. Verify the SQL query: Double-check the SQL query you're trying to execute. Look for any missing or extra parentheses, incorrect table or column names, or unsupported SQL syntax.
  2. Use a Code node to debug: Create a new Code node and paste the following JavaScript code to print the SQL query:
console.log('SQL Query:', {{node.properties.sql.query}});

This will print the SQL query to the console, allowing you to inspect it and identify any potential issues.

  1. Run the SQL query manually: Copy the printed SQL query and run it manually using a tool like MySQL Workbench or the command line. This will help you determine if the issue is with the query or the n8n node.
  2. Correct the SQL query: Once you've identified the issue, correct the SQL query and re-run the n8n workflow.

Prevent it from coming back

To prevent this error from occurring in the future, follow these best practices:

  • Use a Code node to validate the SQL query: Create a Code node to validate the SQL query before executing it in the MySQL node.
  • Use a "Wait" node to introduce a delay: Introduce a delay between retries to prevent overwhelming the database with failed queries.
  • Configure the MySQL node to retry on fail: Configure the MySQL node to retry on fail with the correct settings (Max Tries, Wait Between Tries, etc.).

When to escalate

If you've tried the above steps and still encounter the error, it's likely that the issue is more complex and requires further investigation. In this case, escalate the issue to the n8n support team, providing them with:

  • The exact error message
  • The SQL query being executed
  • The n8n workflow configuration
  • Any relevant logs or debug output

This will enable the support team to provide a more detailed analysis and help you resolve the issue.
