n8n Code Node "Cannot read property of undefined" — Fix

Error: TypeError: Cannot read properties of undefined · Node: Code

What this error actually means

The error TypeError: Cannot read properties of undefined is a common issue in n8n workflows, especially when working with JSON data. This error occurs when you're trying to access a property of an object that doesn't exist. In this case, the property is $json.X, where X is a placeholder for the actual property name.

When you try to access a non-existent property, n8n throws this error, indicating that the object is undefined. This can happen when you're trying to access a property that doesn't exist in the JSON data or when the data is missing altogether.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Missing or incorrect property name: You've entered the wrong property name or the property doesn't exist in the JSON data.
  2. Data is missing or empty: The JSON data is missing or empty, causing the object to be undefined.
  3. Incorrect data type: You're trying to access a property on an object that's not an object, such as a string or a number.

Step-by-step fix

To fix this error, you need to add some defensive coding to ensure that you're not trying to access a non-existent property. Here's a step-by-step guide:

  1. Use optional chaining: You can use optional chaining (?.) to access properties in a safe way. This will prevent the error from occurring if the property doesn't exist.
  2. Check if the property exists: Before accessing the property, check if it exists using the in operator. If it doesn't exist, you can either skip the property or throw a custom error.
  3. Use the hasOwnProperty() method: If you're working with objects, you can use the hasOwnProperty() method to check if the property exists.

Here's an example code block that demonstrates how to use optional chaining and defensive access:

const json = {
  "name": "John",
  "age": 30,
  "address": {
    "street": "123 Main St",
    "city": "Anytown",
    "state": "CA"
  }
};

// Using optional chaining
const name = json?.name; // "John"
const address = json?.address?.street; // "123 Main St"

// Using hasOwnProperty()
const hasAge = Object.prototype.hasOwnProperty.call(json, "age"); // true
const hasNonExistentProperty = Object.prototype.hasOwnProperty.call(json, "nonExistentProperty"); // false

In your n8n workflow, you can use the Code node to write the above code. Make sure to replace the json object with your actual JSON data.

Prevent it from coming back

To prevent this error from occurring in the future, make sure to:

  • Double-check the property names and ensure they exist in the JSON data.
  • Use optional chaining and defensive access to prevent errors.
  • Verify that the JSON data is not missing or empty.
