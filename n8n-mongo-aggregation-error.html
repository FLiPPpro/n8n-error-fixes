n8n MongoDB node fails with aggregation pipeline error

Error: Aggregation pipeline failed · Node: MongoDB

What this error actually means

The "Aggregation pipeline failed" error in n8n's MongoDB node is a generic error message that doesn't provide much information about the root cause of the issue. However, it usually indicates that there's a problem with the aggregation pipeline you've defined in the node's settings.

When you encounter this error, it's essential to understand that it's not a problem with your MongoDB instance or the data itself but rather with the way you've configured the aggregation pipeline.

The three most common causes

After analyzing numerous reports of this error, we've identified three common causes:

  1. Invalid pipeline syntax: This is the most common cause of the "Aggregation pipeline failed" error. It's often due to a typo or a missing comma in the pipeline definition.
  2. Incorrect pipeline order: When you define multiple stages in the pipeline, the order of execution matters. If you've placed a stage that relies on the output of another stage, but the latter stage is executed first, it can lead to incorrect results or errors.
  3. Missing or incorrect field references: If you're using field references in your pipeline, ensure that they match the actual field names in your MongoDB collection. A mismatch can cause the pipeline to fail.

Step-by-step fix

To resolve the "Aggregation pipeline failed" error, follow these steps:

  1. Verify pipeline syntax: Double-check the pipeline definition for any syntax errors. Make sure to use the correct field names, stage names, and operator syntax.
  2. Review pipeline order: If you have multiple stages, ensure that they're executed in the correct order. You can use the $pipeline stage to reorder the pipeline stages if needed.
  3. Check field references: Verify that the field references in your pipeline match the actual field names in your MongoDB collection.

Here's an example of a corrected pipeline definition:

[
  {
    "$match": {
      "name": {
        "$regex": "^A"
      }
    }
  },
  {
    "$group": {
      "_id": "$category",
      "count": {
        "$sum": 1
      }
    }
  }
]

In this example, we've corrected the field reference in the $match stage to use the correct field name (name) and also added a $regex operator to match the field value.

  1. Test the pipeline: Once you've corrected the pipeline definition, test it by running a single execution of the MongoDB node. If the pipeline fails again, review the error message for more information about the issue.

Prevent it from coming back

To prevent the "Aggregation pipeline failed" error from recurring, follow these best practices:

  • Regularly review and test your pipeline: Schedule regular tests of your pipeline to catch any syntax errors or incorrect field references before they cause issues.
  • Use a version control system: Store your pipeline definitions in a version control system like Git to track changes and collaborate with team members.
  • Document your pipeline: Keep a record of your pipeline definition, including any changes or modifications made over time.

When to escalate

If you've followed the steps above and still encounter the "Aggregation pipeline failed" error, it's likely that the issue is more complex and requires further investigation. In this case, consider the following:

  • Consult the MongoDB documentation: Review the official MongoDB documentation for guidance on aggregation pipelines and troubleshooting.
  • Reach out to the n8n community: Post your question on the n8n community forum or seek help from a senior n8n engineer.
  • Escalate to support: If you're still unable to resolve the issue, contact n8n support for further assistance.
