Error Unable to Parse Cron Expression in n8n Cron Node

Error: Invalid cron expression: * * * * * · Node: Cron

What this error actually means

The error message "Invalid cron expression: * * * * *" indicates that the cron expression you've entered in the Cron node is not valid. This can happen when you're trying to schedule a workflow to run at a specific time, but the cron expression doesn't match the expected format.

Cron expressions are used to specify when a workflow should run. They consist of five fields, separated by spaces, that represent the minute, hour, day of the month, month, and day of the week. For example, 0 0 * * * would run the workflow at midnight every day.

The three most common causes

Here are the most common reasons why you might be seeing this error:

  1. Incorrect cron expression format: Make sure you've entered the cron expression in the correct format, with five fields separated by spaces.
  2. Invalid minute or hour value: Check that the minute and hour values you've entered are valid. For example, you can't enter a value greater than 59 for the minute field.
  3. Missing or extra fields: Ensure that you've entered the correct number of fields. If you're missing a field, you'll get an error. If you've entered extra fields, they'll be ignored.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the cron expression: Review the cron expression you've entered in the Cron node to ensure it's in the correct format.
  2. Use a valid cron expression: Replace the invalid cron expression with a valid one. For example, you could use 0 0 * * * to run the workflow at midnight every day.
  3. Test the workflow: Save the changes and test the workflow to ensure it runs correctly.

Here's an example of a valid cron expression in a Code node:

{
  "cron": "0 0 * * *"
}

You can paste this code into a Code node to test the Cron node.

Prevent it from coming back

To prevent this error from happening again, make sure to:

  1. Double-check the cron expression: Before saving the changes, review the cron expression to ensure it's valid.
  2. Use a cron expression generator: If you're not familiar with cron expressions, use a generator tool to help you create a valid one.
  3. Test the workflow regularly: Regularly test the workflow to ensure it's running correctly and catch any errors before they become a problem.

When to escalate

If you've tried the above steps and the error persists, it may be time to escalate the issue. This could involve:

  1. Checking the n8n logs: Review the n8n logs to see if there are any errors or warnings related to the Cron node.
  2. Seeking help from the n8n community: Reach out to the n8n community for help and advice. You can post on the n8n forum or seek help from a n8n expert.
  3. Contacting n8n support: If you're still having trouble, contact n8n support for further assistance.
