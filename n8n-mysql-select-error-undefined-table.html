MySQL Select Node Error: TypeError: Cannot read properties of undefined

Error: TypeError: Cannot read properties of undefined (reading 'X') · Node: MySQL

What this error actually means

When you encounter the error TypeError: Cannot read properties of undefined (reading 'X') in n8n, it means that the node you're using (in this case, the MySQL node) is trying to access a property or attribute of an object that doesn't exist. This is a common error when working with databases, especially when trying to select from a table that doesn't exist.

The three most common causes

  1. Non-existent table: This is the most likely cause of this error. If you're trying to select from a table that doesn't exist in your MySQL database, the node will throw this error.
  2. Incorrect table or column name: If you've misspelled the table or column name in your SQL query, the node will throw this error.
  3. Missing database connection: If the MySQL node can't connect to the database, it will throw this error.

Step-by-step fix

To fix this error, follow these steps:

  1. Verify the table exists: Make sure the table you're trying to select from actually exists in your MySQL database. You can do this by running a SHOW TABLES query in the MySQL node's SQL field.
  2. Check the table and column names: Double-check that the table and column names in your SQL query are correct. Use the SHOW TABLES query to get a list of tables and their columns.
  3. Use a Try-Catch block: If you're using a Code node to execute the SQL query, wrap the query in a Try-Catch block to catch any errors that might occur. Here's an example in JavaScript:
try {
  const query = "SELECT * FROM non_existent_table";
  const result = await db.query(query);
  // do something with the result
} catch (error) {
  // handle the error
  console.error(error);
}
  1. Configure the MySQL node: Make sure the MySQL node is configured correctly. Check the database connection settings, table name, and column names.
  2. Use a SELECT statement: If you're trying to select data from a table, use a SELECT statement instead of trying to access a property of an object.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Verify the table exists before trying to select from it.
  • Double-check the table and column names in your SQL query.
  • Use a Try-Catch block to catch any errors that might occur.
  • Configure the MySQL node correctly.

When to escalate

If you've tried the above steps and still can't resolve the issue, it's time to escalate. Reach out to the n8n community or the n8n support team for further assistance. Provide as much detail as possible about the error, including the error message, the SQL query, and the node configuration.
