Error Trigger node reports condition not met in n8n

Error: Condition not met · Node: Error Trigger

What this error actually means

The "Condition not met" error in n8n's Error Trigger node is a straightforward message that indicates the condition you've set for the error trigger has not been met. This means that the Error Trigger node is not firing as expected, and the workflow is continuing without the desired error handling.

The three most common causes

After analyzing various scenarios, I've identified the three most common causes of this error:

  1. Incorrect condition: The condition you've set for the error trigger is not being met due to incorrect syntax, logic, or data.
  2. Missing or incomplete data: The data required for the condition to be met is missing or incomplete, causing the condition to fail.
  3. Node configuration issues: The Error Trigger node or the preceding nodes are not configured correctly, leading to the condition not being met.

Step-by-step fix

To resolve the "Condition not met" error, follow these steps:

1. Review the condition

Check the condition you've set for the error trigger and verify that it's correct. Make sure the syntax is correct, and the logic is sound.

{
  "condition": "={{ $node[\"My Node\"].json[\"error\"] === true }}"
}

In this example, the condition checks if the error field in the output of the "My Node" node is true.

2. Check the data

Verify that the data required for the condition to be met is present and complete. You can use the Debug node to inspect the data flowing through the workflow.

3. Configure the nodes correctly

Ensure that the Error Trigger node and the preceding nodes are configured correctly. Check the Settings tab for each node to ensure that the correct options are selected.

4. Test the workflow

Run the workflow with sample data to test the condition and ensure it's met.

Prevent it from coming back

To prevent this error from occurring in the future, follow these best practices:

  • Double-check the condition and data before setting up the error trigger.
  • Use the Debug node to inspect the data flowing through the workflow.
  • Configure the nodes correctly, and test the workflow with sample data.

When to escalate

If you've followed the steps above and the issue persists, it may be worth escalating the issue to the n8n community or support team. Provide as much detail as possible about the workflow, nodes, and data involved. This will help the community or support team to identify the root cause of the issue and provide a more accurate solution.
