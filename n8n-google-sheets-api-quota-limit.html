Google Sheets API quota limit exceeded in n8n workflow

Error: quotaExceeded: Quota limit exceeded · Node: Google Sheets

What this error actually means

The quotaExceeded error is a common issue when working with Google Sheets in n8n. This error occurs when you've exceeded the quota limit for your Google Sheets API project. The quota limit is the maximum number of requests you can make to the Google Sheets API within a certain time frame.

In this case, the quota limit has been exceeded, and you're unable to update your Google Sheets data.

The three most common causes

There are three common causes for this error:

  1. High volume of requests: If you're making a large number of requests to the Google Sheets API, you may exceed the quota limit.
  2. Infrequent updates: If you're updating your Google Sheets data infrequently, you may not be aware of the quota limit being exceeded.
  3. Multiple workflows: If you have multiple workflows that are updating the same Google Sheets data, you may be exceeding the quota limit.

Step-by-step fix

To fix this issue, you'll need to adjust your workflow to handle the quota limit. Here's a step-by-step guide:

  1. Check your quota usage: Before making any changes, check your quota usage in the Google Cloud Console. You can do this by going to the Google Cloud Console, navigating to the API Library, and clicking on the Google Sheets API.
  2. Adjust your workflow: If you're making a high volume of requests, you can adjust your workflow to make fewer requests. One way to do this is to use a Wait node to introduce a delay between requests.
  3. Implement retry logic: You can implement retry logic using the HTTP Request node's retry options. Set the Retry On Fail setting to true, and adjust the Max Tries and Wait Between Tries (ms) settings as needed.
  4. Use a Code node to handle errors: You can use a Code node to handle errors and implement retry logic programmatically. Here's an example code block in JavaScript:
const maxTries = 3;
const waitBetweenTries = 5000; // 5 seconds

  const retryCount = {{=flow.get('retryCount', 0)}};

  }
  const waitTime = waitBetweenTries * retryCount;
  {{=flow.set('retryCount', retryCount + 1)}}
  {{=flow.set('waitTime', waitTime)}}
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      resolve();
    }, waitTime);
  });
}

Prevent it from coming back

To prevent this issue from coming back, you can take the following steps:

  • Monitor your quota usage: Regularly check your quota usage to ensure you're not exceeding the limit.
  • Adjust your workflow: If you notice you're exceeding the quota limit, adjust your workflow to make fewer requests.
  • Implement rate limiting: You can implement rate limiting using the Wait node to introduce a delay between requests.

When to escalate

If you've tried the steps above and are still experiencing issues, it may be time to escalate the issue. This could involve:

  • Checking the Google Sheets API documentation: Ensure you're following the correct guidelines for making requests to the Google Sheets API.
  • Contacting Google support: Reach out to Google support for assistance with your quota limit.
  • Reviewing your workflow: Review your workflow to ensure it's configured correctly and not causing the issue.
