Cron Node Schedule Mismatch Error in n8n Workflow

Error: Cron expression does not match any of the given dates · Node: Cron

What this error actually means

The "Cron expression does not match any of the given dates" error in n8n indicates that the Cron node's schedule is not correctly configured. This means that the Cron node is not triggering as expected, and it's not because of a problem with the node itself, but rather with the way it's being used.

When you set up a Cron node, you're specifying a schedule for it to run. This schedule is defined by a Cron expression, which is a string that follows a specific format. The Cron expression defines when the node should run, and if it doesn't match any of the given dates, the node won't trigger.

The three most common causes

There are three common reasons why you might be seeing this error:

  1. Incorrect Cron expression: The most common cause is that the Cron expression is not correctly formatted. Make sure you've followed the correct format for the Cron expression, which is second minute hour day month day_of_week.
  2. Schedule mismatch: Another common cause is that the schedule you've set up doesn't match the actual schedule you want to use. For example, if you've set up a Cron expression to run every minute, but you only want it to run every hour, the node won't trigger.
  3. Time zone issues: n8n uses the system's time zone by default. If your system's time zone is not set correctly, it can cause issues with the Cron expression. Make sure your system's time zone is set correctly.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the Cron expression: Make sure the Cron expression is correctly formatted and matches the schedule you want to use.
  2. Verify the schedule: Double-check that the schedule you've set up matches the actual schedule you want to use.
  3. Check the time zone: Make sure your system's time zone is set correctly.

Here's an example of how to set up a Cron expression in a Code node:

{
  "name": "Cron Expression",
  "type": "code",
  "parameters": {
    "script": "cronExpression = '0 0 * * *'; // Run every day at midnight"
  }
}

You can then use the cronExpression variable in the Cron node's schedule field.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Double-check the Cron expression and schedule every time you make a change.
  • Use a consistent time zone across your system.
  • Test the Cron node regularly to ensure it's working as expected.

When to escalate

If you've tried the above steps and the error still persists, it's time to escalate the issue. Reach out to the n8n community or support team for further assistance. Provide as much detail as possible about the error, including the Cron expression, schedule, and any relevant logs. This will help the support team to better understand the issue and provide a solution.
