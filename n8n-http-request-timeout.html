n8n HTTP Request node timeout error

Error: Timeout: Request took too long to complete · Node: HTTP Request

What this error actually means

The "Timeout: Request took too long to complete" error in n8n indicates that the HTTP Request node has timed out while waiting for a response from the external server. This can happen when the server is slow to respond, the network connection is slow, or the request itself is taking too long to process.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Server-side issues: The external server is taking too long to respond, causing the HTTP Request node to timeout.
  2. Network connectivity issues: The network connection between n8n and the external server is slow or unreliable, causing the request to timeout.
  3. Request complexity: The request itself is taking too long to process, causing the HTTP Request node to timeout.

Step-by-step fix

To fix this issue, follow these steps:

  1. Check the server-side: Verify that the external server is responding quickly and correctly. You can do this by using a tool like curl or a web browser to test the request directly.
  2. Configure retry options: Go to the HTTP Request node's Settings tab and configure the retry options:

* Set "Retry On Fail" to true. * Set "Max Tries" to a higher value (e.g. 5). * Set "Wait Between Tries (ms)" to a higher value (e.g. 5000).

  1. Add a delay: If the request is taking too long to process, you can add a delay using the "Wait" node. This will give the request more time to complete before timing out.
  2. Use a more efficient request: If the request is taking too long to process, try to optimize it by reducing the amount of data being transferred or by using a more efficient request method (e.g. using a caching proxy).

Here is an example of how you can use the "Wait" node to add a delay:

{
  "nodes": [
    {
      "name": "HTTP Request",
      "params": {
        "url": "https://example.com/api/endpoint",
        "method": "GET",
        "retryOnFail": true,
        "maxTries": 5,
        "waitBetweenTries": 5000
      }
    },
    {
      "name": "Wait",
      "params": {
        "timeoutSeconds": 30
      }
    }
  ]
}

This code adds a 30-second delay after the HTTP request is sent, giving it more time to complete before timing out.

Prevent it from coming back

To prevent this issue from coming back, make sure to:

  • Regularly monitor the performance of the external server and the network connection between n8n and the server.
  • Optimize the request by reducing the amount of data being transferred or by using a more efficient request method.
  • Configure the retry options to a higher value to give the request more time to complete.

When to escalate

If you have tried the above steps and the issue persists, it may be necessary to escalate the issue to the n8n support team or to the developers of the external server. Provide as much detail as possible about the issue, including any error messages or logs that may be relevant.
