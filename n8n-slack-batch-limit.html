Slack Web API chat.postMessage batch limit exceeded

Error: rate_limited: You have exceeded the batch limit · Node: Slack

What this error actually means

The rate_limited: You have exceeded the batch limit error message in n8n indicates that the Slack API has blocked your requests due to exceeding the allowed rate limit. This is a common issue when trying to send multiple Slack messages in a short time.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Insufficient delay between requests: When sending multiple Slack messages in quick succession, you may accidentally exceed the allowed rate limit.
  2. Incorrect Slack API configuration: If your Slack API credentials are not properly configured, you may be sending requests with an incorrect rate limit.
  3. Unintended loop or recursion: If your workflow has an unintended loop or recursion, it may send multiple requests to Slack in a short time, exceeding the rate limit.

Step-by-step fix

To resolve this issue, follow these steps:

  1. Check your Slack API configuration: Ensure that your Slack API credentials are properly configured in n8n. You can do this by checking the "Settings" tab of the Slack node.
  2. Add a delay between requests: Use the "Wait" node to introduce a delay between requests to Slack. This will give the API time to process the previous request and prevent you from exceeding the rate limit.

Here's an example code block that you can use in a "Code" node to add a delay of 2 seconds between requests:

const delay = 2000; // 2 seconds
return new Promise(resolve => setTimeout(resolve, delay));

You can also use the "Wait" node's "Delay (ms)" field to set a fixed delay.

  1. Configure retry options: Ensure that the retry options are properly configured on the Slack node. You can do this by checking the "Settings" tab of the Slack node. Set the "Max Tries" to a suitable value, and the "Wait Between Tries (ms)" to a value that allows the API to process the previous request.

Prevent it from coming back

To prevent this issue from recurring, make sure to:

  • Monitor your workflow's performance: Keep an eye on your workflow's performance and adjust the delay or retry options as needed.
  • Use a more efficient workflow design: Review your workflow design and see if there are any opportunities to improve it. For example, you can use a more efficient data processing approach or reduce the number of requests to Slack.
  • Configure rate limiting on the Slack node: You can configure rate limiting on the Slack node by setting the "Rate Limit" field to a suitable value.

When to escalate

If you've tried the above steps and the issue persists, it's likely that there's a more complex issue at play. In this case, it's time to escalate the issue to our support team.
