MongoDB Node Returns No Documents

Error: MongoDB query returned no documents · Node: MongoDB

What this error actually means

When you see the error "MongoDB query returned no documents" in n8n, it means that the MongoDB node has executed the query you specified, but it has not returned any documents that match the query. This can happen for a variety of reasons, including incorrect query syntax, incorrect database or collection names, or data that simply doesn't exist.

The three most common causes

  1. Incorrect query syntax: Double-check that your query is correctly formatted and uses the correct MongoDB query operators. A simple typo or misplaced bracket can cause the query to return no documents.
  2. Incorrect database or collection names: Make sure that you have specified the correct database and collection names in the MongoDB node's settings. If you're using a dynamic database or collection name, ensure that it's correctly resolved before the query is executed.
  3. Data doesn't exist: If the data you're querying for doesn't exist in the MongoDB database, the query will naturally return no documents.

Step-by-step fix

To fix the issue, follow these steps:

  1. Verify the query syntax: Check the query syntax in the MongoDB node's settings. Ensure that it's correctly formatted and uses the correct MongoDB query operators. You can use the MongoDB Node documentation to help with this.
  2. Check database and collection names: Verify that the database and collection names are correct in the MongoDB node's settings. If you're using a dynamic database or collection name, ensure that it's correctly resolved before the query is executed.
  3. Use the find method with a filter: If you're using the find method, try adding a filter to the query. This can help narrow down the results and return the correct documents. For example:
{
  "query": {
    "filter": {
      "name": "John",
      "age": {
        "$gt": 18
      }
    }
  }
}

This will return all documents where the name field is "John" and the age field is greater than 18.

  1. Use the find method with a projection: If you're using the find method, try adding a projection to the query. This can help reduce the amount of data returned and improve performance. For example:
{
  "query": {
    "projection": {
      "name": 1,
      "age": 1
    }
  }
}

This will return only the name and age fields for each document.

  1. Use the aggregate method: If you're trying to perform a complex query, consider using the aggregate method instead of the find method. This can help you perform more complex queries and return the correct documents. For example:
{
  "query": {
    "pipeline": [
      {
        "$match": {
          "name": "John"
        }
      },
      {
        "$project": {
          "name": 1,
          "age": 1
        }
      }
    ]
  }
}

This will return all documents where the name field is "John" and project only the name and age fields.

Prevent it from coming back

To prevent this issue from coming back, make sure to:

  • Regularly test your workflows to ensure they're working as expected.
  • Monitor your MongoDB database for any issues or errors.
  • Keep your MongoDB node settings up-to-date and ensure they're correctly configured.
  • Consider using a more robust error handling mechanism, such as the Error Trigger workflow trigger.

When to escalate

If you've tried the above steps and the issue persists, it may be time to escalate the issue to n8n support. Provide as much detail as possible about the issue, including the error message, your workflow configuration, and any relevant logs or debugging information. This will help the support team to better understand the issue and provide a more effective solution.
