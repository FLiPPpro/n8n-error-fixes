n8n MongoDB query error on collection

Error: Query failed · Node: MongoDB

What this error actually means

The "Query failed" error message in n8n is a generic error that can occur due to various reasons. It's essential to understand that this error doesn't provide specific details about the cause of the failure. To troubleshoot this issue, you'll need to analyze the error message, the node's settings, and the workflow's configuration.

The three most common causes

Based on n8n's documentation and community feedback, the three most common causes of the "Query failed" error are:

  1. Incorrect MongoDB Connection: Ensure that the MongoDB connection settings are correct, including the username, password, host, and port. Verify that the connection string is properly formatted.
  2. Invalid Query: Review the MongoDB query syntax and ensure that it's correct. Check for any typos, missing fields, or incorrect field types.
  3. Insufficient Permissions: Verify that the MongoDB user account has the necessary permissions to execute the query. Ensure that the user has the correct roles and privileges assigned.
