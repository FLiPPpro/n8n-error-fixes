n8n Filter node returns 'invalid condition'

Error: Error: invalid condition · Node: Filter

What this error actually means

The "invalid condition" error in n8n's Filter node is a generic error message that doesn't provide much information about what's going wrong. However, it's usually related to an issue with the condition you're trying to filter on. This condition is the criteria that determines which items will pass through the Filter node and which will be discarded.

In n8n, the Filter node uses a simple syntax to define conditions. It's similar to the syntax used in other programming languages, such as JavaScript or SQL. The condition is usually a combination of a property name, an operator, and a value. For example, {{ $item.data.name }} == "John".

The three most common causes

Based on our experience, the three most common causes of the "invalid condition" error are:

  1. Typo in the condition: This is the most common cause of the error. A small typo in the condition can make it invalid. For example, {{ $item.data.name }} = "John" instead of {{ $item.data.name }} == "John".
  2. Invalid operator: The operator used in the condition is not valid. For example, using != instead of !== or = instead of ==.
  3. Missing or incorrect property name: The property name used in the condition is not valid or is missing. For example, trying to access a property that doesn't exist in the item's data.

Step-by-step fix

To fix the "invalid condition" error, follow these steps:

  1. Check the condition syntax: Make sure the condition syntax is correct. Check for any typos or invalid operators.
  2. Verify the property name: Make sure the property name used in the condition is correct and exists in the item's data.
  3. Use the correct operator: Use the correct operator for the comparison. For example, === for exact comparison and !== for not equal to.
  4. Use the {{ }} syntax correctly: Make sure to use the {{ }} syntax correctly to access the item's data.

Here's an example of a valid condition in JSON:

{
  "condition": "{{$item.data.name}} == 'John'"
}

And here's an example of a valid condition in a Code node (JavaScript):

const condition = `{{$item.data.name}} === 'John'`;
  1. Test the condition: Test the condition by running a single item through the Filter node. If the condition is valid, the item should pass through. If not, the error will be triggered.

Prevent it from coming back

To prevent the "invalid condition" error from coming back, make sure to:

  • Double-check the condition syntax and property names.
  • Use the correct operator for the comparison.
  • Test the condition regularly to ensure it's working as expected.

When to escalate

If you've tried the above steps and the "invalid condition" error persists, it's likely that there's a more complex issue at play. In this case, it's best to escalate the issue to the n8n community or support team for further assistance. Provide as much information as possible about the error, including the condition syntax, property names, and any relevant logs or error messages.
