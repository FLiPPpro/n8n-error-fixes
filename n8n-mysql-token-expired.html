MySQL node throws 'invalid_grant: Token has been expired or revoked' error

Error: invalid_grant: Token has been expired or revoked · Node: MySQL

What this error actually means

When you encounter the invalid_grant: Token has been expired or revoked error in n8n, it means that the access token used to authenticate with the MySQL database has expired or been revoked. This can happen due to various reasons such as token expiration, token revocation, or changes in the database credentials.

The three most common causes

There are three primary reasons why this error occurs:

  1. Token Expiration: The access token has expired due to the time limit set by the MySQL database or the authentication provider.
  2. Token Revocation: The access token has been revoked by the MySQL database or the authentication provider due to security reasons or changes in the database credentials.
  3. Changes in Database Credentials: The database credentials have been changed, and the access token is no longer valid.

Step-by-step fix

To resolve this issue, follow these steps:

Step 1: Check the Token Expiration Time

First, check the token expiration time by running the following SQL query in a Code node:

SELECT token_expiration_time FROM mysql_tokens WHERE token = '{{ $token }}';

Replace {{ $token }} with the actual token value. If the token_expiration_time is within the last hour, it's likely that the token has expired.

Step 2: Obtain a New Access Token

If the token has expired, obtain a new access token by running the following code in a Code node:

const mysql = require('mysql2/promise');

const db = mysql.createConnection({
  host: 'your_host',
  user: 'your_user',
  password: 'your_password',
  database: 'your_database'
});

const refreshToken = async () => {
  const token = await db.execute('SELECT token FROM mysql_tokens WHERE user = ?', ['your_user']);
  const newToken = await db.execute('SELECT token FROM mysql_tokens WHERE user = ?', ['your_user']);
  return newToken[0].token;
};

const newAccessToken = await refreshToken();
console.log(newAccessToken);

Replace your_host, your_user, your_password, and your_database with your actual MySQL database credentials.

Step 3: Update the MySQL Node

Update the MySQL node with the new access token. Go to the MySQL node, click on the three dots, and select "Edit". In the "Authentication" section, update the "Access Token" field with the new access token obtained in the previous step.

Prevent it from coming back

To prevent this issue from occurring in the future, consider the following:

  • Set up a scheduled task to refresh the access token periodically.
  • Use a more robust authentication mechanism, such as OAuth 2.0, that can handle token revocation and expiration.
  • Monitor the database credentials and update them as needed to prevent token revocation.

When to escalate

If you have followed the steps above and the issue persists, it may be necessary to escalate the issue to the n8n support team or the MySQL database administrator. Provide as much detail as possible about the issue, including the error message, the steps you have taken to resolve the issue, and any relevant logs or configuration files.
