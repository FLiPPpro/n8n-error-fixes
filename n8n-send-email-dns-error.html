n8n Send Email node DNS error

Error: Error: DNS lookup failed for email server · Node: Send Email

What this error actually means

When you encounter the "Error: DNS lookup failed for email server" error in n8n, it means that the email server you're trying to connect to is not responding to DNS queries. This could be due to a variety of reasons such as the email server being down, the DNS server being down, or there being a network issue between your n8n instance and the email server.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Email server down: If the email server you're trying to connect to is down, you'll encounter this error. This could be due to maintenance, upgrades, or other issues.
  2. DNS server down: If the DNS server responsible for resolving the email server's domain is down, you'll encounter this error.
  3. Network issue: If there's a network issue between your n8n instance and the email server, you'll encounter this error.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the email server status: Check the status of the email server you're trying to connect to. If it's down, wait for it to come back up or contact the email server administrator.
  2. Verify DNS server: Verify that the DNS server responsible for resolving the email server's domain is up and running.
  3. Check network connectivity: Check that there are no network issues between your n8n instance and the email server.
  4. Configure the email node: Make sure the email node is configured correctly. Check the SMTP server, port, and authentication settings.
  5. Add retries: Add retries to the email node to handle temporary failures. You can do this by going to the email node's Settings tab and configuring the "Retry On Fail", "Max Tries", and "Wait Between Tries (ms)" options.

Here's an example of how you can configure retries in the email node:

{
  "retryOnFail": true,
  "maxTries": 3,
  "waitBetweenTries": 5000
}

This will retry the email node up to 3 times with a 5-second wait between retries.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  1. Monitor the email server status: Regularly monitor the status of the email server you're trying to connect to.
  2. Verify DNS server: Regularly verify that the DNS server responsible for resolving the email server's domain is up and running.
  3. Check network connectivity: Regularly check that there are no network issues between your n8n instance and the email server.
  4. Configure the email node correctly: Make sure the email node is configured correctly, including the SMTP server, port, and authentication settings.

When to escalate

If you've tried the above steps and the error persists, it's time to escalate the issue. Contact the email server administrator to see if there's an issue on their end. If the issue is on your end, contact your network administrator to see if there's a network issue. If you're still unable to resolve the issue, contact n8n support for further assistance.
