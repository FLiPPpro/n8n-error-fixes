n8n Google Drive node auth error

Error: Error: Authentication with Google Drive failed · Node: Google Drive

What this error actually means

When you see the error message "Error: Authentication with Google Drive failed" in n8n, it means that the Google Drive node was unable to authenticate with the Google Drive API. This can happen for a variety of reasons, including incorrect credentials, issues with the Google Drive API, or problems with the n8n configuration.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Incorrect credentials: Make sure that the Client ID and Client secret are correctly entered in the Google Drive node's Settings tab. You can also try re-generating the credentials in the Google Cloud Console.
  2. Google Drive API issues: Check the Google Drive API status page to see if there are any known issues or maintenance scheduled for the API. You can also try refreshing the credentials or re-authenticating with the API.
  3. n8n configuration issues: Check the n8n workflow and configuration to ensure that the Google Drive node is correctly configured and that the API endpoint is correct.

Step-by-step fix

To fix the error, follow these steps:

  1. Check the Google Drive node's Settings tab to ensure that the Client ID and Client secret are correctly entered.
  2. Try re-generating the credentials in the Google Cloud Console.
  3. Check the Google Drive API status page to ensure that there are no known issues or maintenance scheduled for the API.
  4. If none of the above steps resolve the issue, try adding a delay to the workflow using the "Wait" node. This can help prevent the workflow from timing out while trying to authenticate with the Google Drive API.

Here is an example of how to add a delay using the "Wait" node:

{
  "name": "Wait for 10 seconds",
  "type": "Wait",
  "settings": {
    "milliseconds": 10000
  }
}

This will add a 10-second delay to the workflow, which can help prevent the workflow from timing out while trying to authenticate with the Google Drive API.

  1. If the above steps do not resolve the issue, try using a "Code" node to authenticate with the Google Drive API manually. Here is an example of how to do this using JavaScript:
const { google } = require('googleapis');

const auth = new google.auth.GoogleAuth({
  // Scopes: 'https://www.googleapis.com/auth/drive'
});

const drive = google.drive('v3');

drive.files.list({
  auth: auth,
  fields: 'files(id, name)',
}, (err, res) => {
  if (err) {
    console.error(err);
  } else {
    console.log(res.data.files);
  }
});

This code uses the google-auth-library to authenticate with the Google Drive API and then uses the google-api-library to list the files in the user's Google Drive account.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Regularly check the Google Drive API status page to ensure that there are no known issues or maintenance scheduled for the API.
  • Keep the n8n workflow and configuration up to date to ensure that the Google Drive node is correctly configured and that the API endpoint is correct.
  • Monitor the n8n logs to ensure that the workflow is running correctly and that there are no errors.

When to escalate

If none of the above steps resolve the issue, it may be necessary to escalate the issue to the n8n support team or to a Google Cloud Support specialist. Be sure to provide as much information as possible about the issue, including any error messages, workflow configurations, and n8n logs.
