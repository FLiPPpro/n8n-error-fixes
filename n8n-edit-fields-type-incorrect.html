n8n Edit Fields node type incorrect error message

Error: value is not of expected type · Node: Edit Fields

What this error actually means

The "value is not of expected type" error in n8n's Edit Fields node is a common issue that occurs when the data type of the value being edited does not match the expected data type of the field. This error can be frustrating, especially when working with complex workflows. To troubleshoot this issue, it's essential to understand the root cause.

The three most common causes

After analyzing numerous reports of this error, we've identified three primary causes:

  1. Incorrect data type: The most common cause is when the data type of the value being edited does not match the expected data type of the field. For example, trying to edit a string field with a numeric value.
  2. Missing or incorrect field type: Sometimes, the field type is not set correctly in the Edit Fields node, leading to the error.
  3. Nested data structure: When working with nested data structures, the error can occur if the data type of the nested field does not match the expected data type.

Step-by-step fix

To fix the "value is not of expected type" error, follow these steps:

  1. Check the field type: Ensure that the field type is set correctly in the Edit Fields node. You can do this by checking the "Field Type" dropdown menu and selecting the correct data type.
  2. Verify the data type: Check the data type of the value being edited and ensure it matches the expected data type of the field.
  3. Use a Code node to convert data type: If the data type of the value being edited does not match the expected data type, you can use a Code node to convert the data type. For example, if you're trying to edit a string field with a numeric value, you can use the following JavaScript code in a Code node:
const value = {{value}};
const editedValue = parseInt(value);
return editedValue;

This code converts the value to an integer using the parseInt() function. You can then use the editedValue variable in the Edit Fields node.

  1. Check for nested data structures: If you're working with nested data structures, ensure that the data type of the nested field matches the expected data type.

Prevent it from coming back

To prevent this error from occurring in the future, follow these best practices:

  1. Use the correct field type: Ensure that the field type is set correctly in the Edit Fields node.
  2. Verify data types: Double-check the data type of the value being edited and ensure it matches the expected data type.
  3. Use Code nodes to convert data types: If necessary, use Code nodes to convert the data type of the value being edited.
  4. Test your workflow: Thoroughly test your workflow to ensure that it's working as expected.

When to escalate

If you've tried the above steps and the error persists, it's likely that the issue is more complex and requires further assistance. In this case, you should:

  1. Check the n8n documentation: Ensure that you're using the latest version of n8n and that you're familiar with the latest features and best practices.
  2. Reach out to the n8n community: Join the n8n community forums and ask for help from experienced users and developers.
  3. Contact n8n support: If you're still having trouble, contact n8n support for further assistance.
