n8n Schedule Trigger node returns SSL connection required error

Error: SSL connection is required · Node: Schedule Trigger

What this error actually means

When you encounter the error "SSL connection is required" in n8n, it means that the HTTP Request node is trying to connect to a server that requires a secure connection (HTTPS) but the node is not configured to use SSL/TLS. This can happen if you're trying to connect to a server that uses a self-signed certificate or if the certificate is not trusted by the node.

The three most common causes

There are three common causes for this error:

  1. Incorrect protocol: Make sure that the protocol in the URL is set to HTTPS (http://example.com will not work).
  2. Missing SSL/TLS configuration: Ensure that the SSL/TLS settings are configured correctly in the HTTP Request node.
  3. Certificate issues: Verify that the certificate used by the server is trusted by the node.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the URL: Ensure that the protocol in the URL is set to HTTPS. You can do this by checking the URL in the HTTP Request node's Settings tab.
  2. Configure SSL/TLS settings: In the HTTP Request node's Settings tab, ensure that the SSL/TLS settings are configured correctly. You can do this by selecting the correct certificate and key from the dropdown menus.
  3. Verify certificate: If the certificate is self-signed or not trusted by the node, you'll need to add it to the node's certificate store. You can do this by uploading the certificate to the node's Settings tab.
  4. Test the connection: After configuring the SSL/TLS settings, test the connection by running the workflow.

Here's an example of how to configure the SSL/TLS settings in a Code node:

{
  "name": "Configure SSL/TLS",
  "parameters": {
    "useSSL": true,
    "sslKey": "path/to/ssl/key",
    "sslCert": "path/to/ssl/cert"
  }
}

You can paste this code into a Code node and run it to configure the SSL/TLS settings.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Regularly update the certificate and key in the node's Settings tab.
  • Verify that the certificate is trusted by the node.
  • Test the connection regularly to ensure that it's working correctly.

When to escalate

If you've tried the steps above and the error persists, it may be worth escalating the issue to the n8n support team. Provide as much detail as possible about the error, including the error message, the node configuration, and any relevant logs.
