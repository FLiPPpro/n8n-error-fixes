MongoDB node authentication failed error in n8n workflow

Error: Error: Authentication failed for MongoDB node: Invalid credentials · Node: MongoDB

What this error actually means

The "Error: Authentication failed for MongoDB node: Invalid credentials" error message indicates that the MongoDB node in your n8n workflow is unable to authenticate with the MongoDB database due to incorrect or invalid credentials.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Incorrect username or password: Double-check that the username and password you provided in the MongoDB node's settings are correct and match the credentials used to authenticate with the MongoDB database.
  2. MongoDB authentication method not configured correctly: Ensure that the MongoDB node is configured to use the correct authentication method (e.g., username/password, API key, etc.) and that the corresponding settings are correctly filled in.
  3. MongoDB connection string not properly formatted: Verify that the MongoDB connection string is correctly formatted and includes the necessary authentication credentials.

Step-by-step fix

To fix the error, follow these steps:

  1. Check the MongoDB node's settings:

* Open the MongoDB node's settings tab and verify that the username and password fields are correctly filled in. * Ensure that the authentication method is correctly configured (e.g., username/password, API key, etc.).

  1. Verify the MongoDB connection string:

* Check that the MongoDB connection string is correctly formatted and includes the necessary authentication credentials. * If using a username and password, ensure that the username and password fields are correctly filled in.

  1. Use the Code node to test credentials:

* Create a new Code node and add the following JavaScript code:

const MongoClient = require('mongodb').MongoClient;
const url = 'mongodb://localhost:27017'; // replace with your MongoDB connection string
const dbName = 'mydatabase';
const username = 'myusername';
const password = 'mypassword';

MongoClient.connect(url, { useNewUrlParser: true, useUnifiedTopology: true }, (err, client) => {
  if (err) {
    console.error(err);
  } else {
    console.log('Connected to MongoDB');
    const db = client.db(dbName);
    db.collection('mycollection').find().toArray((err, docs) => {
      if (err) {
        console.error(err);
      } else {
        console.log(docs);
      }
    });
  }
});

* Replace the url, dbName, username, and password variables with your actual MongoDB connection string and credentials. * Run the code to test the connection and credentials.

  1. Update the MongoDB node's settings:

* If the code runs successfully, update the MongoDB node's settings with the correct username and password.

Prevent it from coming back

To prevent the error from occurring again, make sure to:

  • Store your MongoDB credentials securely, such as using environment variables or a secrets manager.
  • Regularly review and update your MongoDB node's settings to ensure they are correctly configured.
  • Consider implementing additional security measures, such as enabling authentication and authorization in your MongoDB database.

When to escalate

If you have tried the above steps and are still experiencing issues with the MongoDB node, it may be necessary to escalate the issue to a more advanced support team or a MongoDB expert. Be prepared to provide detailed information about your n8n workflow, MongoDB node settings, and any error messages you are experiencing.
