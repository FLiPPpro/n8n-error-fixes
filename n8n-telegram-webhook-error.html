Telegram Webhook Node Connection Failed with Error

Error: Error: Connection timed out: Connection to Telegram webhook failed · Node: Telegram

What this error actually means

The error "Error: Connection timed out: Connection to Telegram webhook failed" indicates that the Telegram webhook node in your n8n workflow is unable to establish a connection to the Telegram channel. This can be due to various reasons such as incorrect Telegram API token, wrong Telegram channel ID, or issues with the Telegram server.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Incorrect Telegram API token: Make sure you have entered the correct Telegram API token in the Telegram webhook node's settings. You can check the Telegram API token by going to the Telegram BotFather, creating a new bot, and getting the bot's API token.
  2. Wrong Telegram channel ID: Ensure that you have entered the correct Telegram channel ID in the Telegram webhook node's settings. You can find the channel ID by going to the Telegram channel, clicking on the three dots on the top right corner, and selecting "Share" > "Copy Link". The channel ID will be in the URL.
  3. Issues with the Telegram server: Sometimes, the Telegram server may be down or experiencing issues, causing the connection to fail. You can try checking the Telegram status page or contacting Telegram support to see if there are any known issues.

Step-by-step fix

To fix the error, follow these steps:

  1. Check the Telegram API token: Go to the Telegram BotFather, create a new bot, and get the bot's API token. Replace the existing token in the Telegram webhook node's settings with the new token.
  2. Verify the Telegram channel ID: Go to the Telegram channel, click on the three dots on the top right corner, and select "Share" > "Copy Link". Ensure that the channel ID in the URL is correct.
  3. Configure retry options: Go to the Telegram webhook node's settings and configure the retry options. Set "Retry On Fail" to true, "Max Tries" to a reasonable number (e.g., 5), and "Wait Between Tries (ms)" to a suitable delay (e.g., 5000).
  4. Add a delay: If the issue persists, try adding a delay between retries. You can use the "Wait" node to add a delay. Set the "Wait" node to wait for a suitable amount of time (e.g., 30 seconds) before retrying the connection.
  5. Check the Telegram server status: Go to the Telegram status page or contact Telegram support to see if there are any known issues with the Telegram server.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Regularly check the Telegram API token and channel ID to ensure they are correct.
  • Monitor the Telegram server status to ensure there are no known issues.
  • Configure the retry options to a reasonable number and delay.

When to escalate

If you have tried the above steps and the error persists, it may be necessary to escalate the issue to the n8n support team or Telegram support team. Provide as much detail as possible about the error, including the n8n workflow configuration, Telegram API token, and channel ID. This will help the support teams to troubleshoot and resolve the issue more efficiently.
