n8n Google Sheets node type incorrect error message

Error: value is not of expected type · Node: Google Sheets

What this error actually means

The value is not of expected type error in n8n's Google Sheets node is a common issue that occurs when the data type of the value being set does not match the expected data type of the Google Sheets column. This error can be frustrating, especially when you're not sure where to look or how to fix it.

The three most common causes

After analyzing numerous reports of this error, we've identified three common causes:

  1. Incorrect data type: The most common cause of this error is when the data type of the value being set does not match the data type of the Google Sheets column. For example, if you're trying to set a string value in a column that's set to expect a number, you'll get this error.
  2. Missing or incorrect formatting: If the value being set is a date or a number, it's essential to ensure that it's in the correct format. For example, if you're trying to set a date value, make sure it's in the format YYYY-MM-DD.
  3. Formula or function issues: If you're using formulas or functions in your Google Sheets column, it's possible that the error is caused by an issue with the formula or function itself.

Step-by-step fix

To fix the value is not of expected type error, follow these steps:

  1. Check the data type: Verify that the data type of the value being set matches the data type of the Google Sheets column. You can do this by checking the column settings in Google Sheets.
  2. Format the value correctly: If the value being set is a date or a number, ensure that it's in the correct format. For example, if you're trying to set a date value, use the YYYY-MM-DD format.
  3. Check formulas and functions: If you're using formulas or functions in your Google Sheets column, check that they're correct and not causing the error.

Here's an example of how to fix the error using a Code node:

{
  "name": "Fix Data Type",
  "parameters": {
    "function": "fixDataType",
    "value": "={{ $node[\"Google Sheets\"].json[\"data\"] }}"
  },
  "type": "n8n-nodes-base.code"
}

function fixDataType(item, context) {
  const value = item.json.data;
  const dataType = context.getNode("Google Sheets").parameters.dataType;

  if (dataType === "string") {
    return { json: { data: String(value) } };
  } else if (dataType === "number") {
    return { json: { data: Number(value) } };
  } else if (dataType === "date") {
    return { json: { data: new Date(value).toISOString() } };
  } else {
    return { json: { data: value } };
  }
}

In this example, we're using a Code node to fix the data type of the value being set. We're checking the data type of the Google Sheets column and formatting the value accordingly.

Prevent it from coming back

To prevent the value is not of expected type error from coming back, make sure to:

  • Verify the data type of the value being set matches the data type of the Google Sheets column.
  • Ensure that the value is in the correct format (e.g., YYYY-MM-DD for dates).
  • Check formulas and functions in your Google Sheets column to ensure they're correct.
