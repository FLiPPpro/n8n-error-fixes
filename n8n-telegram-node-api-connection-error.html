Telegram node in n8n API connection issue with token

Error: Error connecting to API: Invalid token · Node: Telegram

What this error actually means

When you see the error "Error connecting to API: Invalid token" in n8n, it means that the Telegram node is unable to authenticate with the Telegram API using the provided token. This is a common issue that can occur when setting up the Telegram node for API connection.

The three most common causes

There are three main reasons why you might see this error:

  1. Incorrect token: Make sure that you have entered the correct Telegram API token in the Telegram node's settings. You can find your token in the Telegram BotFather or by creating a new bot and getting the token from the BotFather.
  2. Token expired or invalid: Check that the token has not expired or become invalid. You can do this by checking the Telegram API documentation or by trying to use the token in a different context.
  3. Node configuration issues: Ensure that the Telegram node is properly configured, including setting the correct API endpoint, method, and authentication settings.

Step-by-step fix

To fix the error, follow these steps:

  1. Check the token: Double-check that you have entered the correct Telegram API token in the Telegram node's settings. If you're not sure, try generating a new token from the BotFather.
  2. Configure the node: Ensure that the Telegram node is properly configured, including setting the correct API endpoint, method, and authentication settings. You can do this by checking the node's settings tab.
  3. Use a Code node to validate the token: Create a new Code node and add the following JavaScript code to validate the token:
const token = credentials.telegramToken;
const url = `https://api.telegram.org/bot${token}/getMe`;

const options = {
  method: 'GET',
  url,
  headers: {
    'Content-Type': 'application/json',
  },
};

n8n.utils.request(options)
  .then((response) => {
    if (response.status === 200) {
      // Token is valid
      return { success: true };
    } else {
      // Token is invalid
      return { success: false, error: 'Invalid token' };
    }
  })
  .catch((error) => {
    // Token is invalid
    return { success: false, error: 'Invalid token' };
  });

This code will send a GET request to the Telegram API to validate the token. If the token is valid, it will return true. If the token is invalid, it will return false with an error message.

  1. Add a Wait node to retry: Add a Wait node to retry the connection after a certain amount of time. You can configure the Wait node to retry the connection for a specified number of times and with a specified delay between retries.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Regularly check and update your Telegram API token to ensure it remains valid.
  • Monitor your Telegram node's logs for any errors or issues.
  • Use a Code node to validate the token before using it in your workflow.

When to escalate

If you've tried the above steps and the error persists, it may be worth escalating the issue to the n8n community or support team. This could be due to a bug in the Telegram node or an issue with the Telegram API itself. Be sure to provide as much detail as possible about the error and your workflow configuration to help the community or support team assist you.
