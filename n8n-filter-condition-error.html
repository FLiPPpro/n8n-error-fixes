Filter Condition Error in n8n Workflow

Error: Error: Condition failed · Node: Filter

What this error actually means

The "Error: Condition failed" message in n8n is a generic error that doesn't provide much information about what's causing the issue. However, it's usually related to a condition or filter that's not being met in a Filter node. This error can occur when the filter criteria are not correctly set up, or when the data being processed doesn't match the expected format.

The three most common causes

After working with n8n for a while, we've identified three common causes of the "Error: Condition failed" error:

  1. Incorrect filter criteria: The filter criteria in the Filter node are not correctly set up, leading to the condition failing. This can be due to a typo in the expression, an incorrect data type, or a mismatch between the expected and actual data formats.
  2. Data format mismatch: The data being processed in the Filter node doesn't match the expected format, causing the condition to fail. This can be due to missing or extra fields, incorrect data types, or other formatting issues.
  3. Expression syntax errors: The expression used in the Filter node contains syntax errors, such as missing or extra brackets, incorrect operators, or invalid function calls.

Step-by-step fix

To fix the "Error: Condition failed" error, follow these steps:

  1. Check the filter criteria: Review the filter criteria in the Filter node to ensure they are correct and match the expected format. Use the {{ }} syntax to write expressions, and make sure to use the correct operators and functions.
  2. Verify data format: Check the data being processed in the Filter node to ensure it matches the expected format. Use the console.log() function in a Code node to inspect the data and verify its format.
  3. Use a Code node to test expressions: If you're unsure about the expression syntax, create a Code node with a JavaScript function to test the expression. Use the console.log() function to print the result of the expression, and verify that it returns the expected value.
  4. Use a JSONata expression: If you're using a Filter node with a JSONata expression, ensure that the expression is correctly formatted and doesn't contain any syntax errors. You can use a Code node with a JavaScript function to test the JSONata expression.

Here's an example of a JavaScript function in a Code node that tests a JSONata expression:

function testJsonataExpression(data) {
  const jsonataExpression = "data.*.name == 'John'";
  const result = jsonataExpression.evaluate(data);
  console.log(result);
  return result;
}

This function takes a data object as input, evaluates the JSONata expression, and logs the result to the console.

Prevent it from coming back

To prevent the "Error: Condition failed" error from occurring in the future, follow these best practices:

  1. Use a Code node to test expressions: Always test expressions in a Code node before using them in a Filter node.
  2. Verify data format: Regularly verify the data format in the Filter node to ensure it matches the expected format.
  3. Use a JSONata expression: If you're using a Filter node with a JSONata expression, ensure that the expression is correctly formatted and doesn't contain any syntax errors.

When to escalate

If you've tried the above steps and the "Error: Condition failed" error persists, it's likely due to a more complex issue that requires further investigation. In this case, escalate the issue to your n8n support team or a senior developer for further assistance. Provide as much detail as possible about the workflow, nodes, and data being processed to help the support team identify the root cause of the issue.
