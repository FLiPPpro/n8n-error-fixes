n8n webhook SSL verification failed error

Error: SSL peer verification failed · Node: Webhook

What this error actually means

When you encounter the "SSL peer verification failed" error in n8n, it means that the webhook node is unable to establish a secure connection with the target server. This is because the server's SSL certificate is not trusted by the n8n environment. The error is not a generic "connection failed" error, but rather a specific indication that the SSL verification process has failed.

The three most common causes

There are three common causes for this error:

  1. Incorrect SSL certificate configuration: The SSL certificate configured on the server may not match the expected configuration. This can be due to a mismatch in the certificate's common name, subject alternative name, or even the certificate's expiration date.
  2. Missing or incorrect intermediate certificates: If the server uses intermediate certificates, these may not be properly configured or installed on the n8n environment.
  3. Incompatible SSL protocol version: The n8n environment may be configured to use an SSL protocol version that is not supported by the server.

Step-by-step fix

To fix the "SSL peer verification failed" error, follow these steps:

  1. Verify the SSL certificate configuration: Check the server's SSL certificate configuration to ensure that it matches the expected configuration. Verify the common name, subject alternative name, and certificate expiration date.
  2. Configure intermediate certificates: If the server uses intermediate certificates, ensure that these are properly configured and installed on the n8n environment.
  3. Update the SSL protocol version: If the n8n environment is configured to use an incompatible SSL protocol version, update it to a supported version.

To verify the SSL certificate configuration, you can use the following code in a Code node:

const fs = require('fs');
const https = require('https');

const options = {
  hostname: 'example.com',
  port: 443,
  path: '/',
  method: 'GET',
  rejectUnauthorized: true
};

https.get(options, (res) => {
  console.log(res);
}).on('error', (err) => {
  console.log(err);
});

Replace example.com with the target server's hostname. This code will attempt to establish a secure connection with the server and log any errors that occur.

Prevent it from coming back

To prevent the "SSL peer verification failed" error from occurring in the future, ensure that the SSL certificate configuration is properly maintained and updated. Regularly verify the SSL certificate configuration and intermediate certificates to prevent any potential issues.

When to escalate

If you have tried the above steps and the error persists, it may be necessary to escalate the issue to your organization's IT department or a third-party SSL certificate provider. Additionally, if you are unsure about the SSL certificate configuration or intermediate certificates, it is recommended to seek assistance from a qualified IT professional or a n8n expert.
