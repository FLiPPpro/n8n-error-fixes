n8n Merge Node Dropping Items — Fix

Error: Merge node outputs fewer items than inputs · Node: Merge

What this error actually means

When you encounter the "Merge node outputs fewer items than inputs" error in n8n, it means that the Merge node is not able to combine the data from both input branches as expected. This can happen when the merge mode is not correctly configured or when the data from one or both branches does not match the expected format.

The three most common causes

There are three common causes for this error:

  1. Incorrect merge mode: The Merge node has two main modes: Append and Combine by Key. If you're using the Combine by Key mode, it requires that the key is present in both branches. If the key is missing from one or both branches, the merge will fail.
  2. Missing key in one or both branches: If the key is not present in one or both branches, the Combine by Key mode will fail to merge the data.
  3. Data format mismatch: If the data format in one or both branches does not match the expected format, the merge will fail.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the merge mode: Ensure that the merge mode is set to Combine by Key if you're using this mode. You can do this by clicking on the Merge node and checking the "Merge Mode" setting in the Settings tab.
  2. Verify key presence: Check that the key is present in both branches. You can do this by adding a {{ $json(key) }} expression to both branches to check if the key is present.
  3. Use a JSONata expression: If the key is present in both branches, but the data is not being merged correctly, try using a JSONata expression to merge the data. Here's an example of a JSONata expression that you can use:
{{ $merge({ "key": "commonKey", "data": { "branch1": $json("branch1"), "branch2": $json("branch2") } }) }}

This expression merges the data from both branches based on the common key "commonKey".

  1. Check data format: Ensure that the data format in both branches matches the expected format. You can do this by adding a {{ $json() }} expression to both branches to check the data format.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Use the correct merge mode for your use case.
  • Verify that the key is present in both branches.
  • Use a JSONata expression to merge the data if necessary.
  • Check the data format in both branches.

When to escalate

If you've tried the above steps and the error persists, it may be necessary to escalate the issue. This could involve:

  • Checking the n8n logs for any errors or warnings.
  • Verifying that the data is being sent to the Merge node correctly.
  • Checking the Merge node configuration for any issues.
  • Contacting the n8n support team for further assistance.
