MySQL Node Connection Failed with Authentication Error

Error: Error: Authentication failed: Connection terminated due to connection timeout · Node: MySQL

What this error actually means

The error message "Error: Authentication failed: Connection terminated due to connection timeout" indicates that the MySQL node in n8n is unable to establish a connection to the MySQL database due to authentication issues. This can be caused by incorrect database credentials, a misconfigured MySQL node, or a database connection timeout.

The three most common causes

  1. Incorrect database credentials: Double-check that the username, password, and hostname/IP address are correct in the MySQL node's Settings tab.
  2. Database connection timeout: Ensure that the database connection timeout is set correctly in the MySQL node's Settings tab. A timeout of 0 means the connection will never timeout.
  3. MySQL node configuration: Verify that the MySQL node is properly configured to connect to the database. Check that the port number, database name, and other settings are correct.

Step-by-step fix

To fix the authentication issue, follow these steps:

  1. Check database credentials: Verify that the username, password, and hostname/IP address are correct in the MySQL node's Settings tab.
{
  "username": "your_username",
  "password": "your_password",
  "host": "your_host",
  "port": "3306"
}
  1. Configure database connection timeout: Set the database connection timeout to a reasonable value (e.g., 30 seconds) in the MySQL node's Settings tab.
  2. Verify MySQL node configuration: Ensure that the MySQL node is properly configured to connect to the database. Check that the port number, database name, and other settings are correct.
  3. Use a "Wait" node to add a delay: If the connection timeout is caused by a temporary issue, you can add a delay using a "Wait" node to retry the connection.
const wait = new n8n.nodes.Wait({
  delay: 30000, // 30 seconds
});
  1. Use a "Code" node to execute a SQL query: If the issue is caused by a specific SQL query, you can execute it using a "Code" node to troubleshoot the issue.
const query = "SELECT * FROM your_table";
const db = new n8n.nodes.MySQL({
  username: "your_username",
  password: "your_password",
  host: "your_host",
  port: "3306",
  database: "your_database"
});
db.query(query, (err, results) => {
  if (err) {
    console.error(err);
  } else {
    console.log(results);
  }
});

Prevent it from coming back

To prevent this issue from recurring, consider the following:

  • Regularly update the MySQL node configuration: Ensure that the username, password, and hostname/IP address are up-to-date and correct.
  • Monitor database connection timeouts: Keep an eye on database connection timeouts and adjust the timeout value as needed.
  • Use a "Continue On Fail" setting: Configure the MySQL node to continue executing the workflow even if the connection fails.

When to escalate

If you've tried the above steps and the issue persists, it's likely a more complex problem that requires further investigation. Consider escalating the issue to the n8n community or support team for further assistance.
