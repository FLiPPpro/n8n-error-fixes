Invalid Find Query in MongoDB Node n8n Error

Error: Error: Invalid find query · Node: MongoDB

What this error actually means

The "Invalid find query" error in n8n's MongoDB node occurs when the node attempts to execute a query on the MongoDB database but encounters a problem with the query itself. This can happen for a variety of reasons, including incorrect syntax, missing or extra fields, or invalid query operators. When the node encounters this error, it will stop processing and display the error message.

The three most common causes

The most common causes of the "Invalid find query" error are:

  1. Incorrect query syntax: This can occur when you're using a query operator or function that's not supported by MongoDB or is not used correctly.
  2. Missing or extra fields: If you're trying to query a field that doesn't exist in the collection or include a field that's not relevant to the query, you'll get this error.
  3. Invalid query operator: Using a query operator that's not supported by MongoDB or is not used correctly can also cause this error.

Step-by-step fix

To fix the "Invalid find query" error, follow these steps:

  1. Check the query syntax: Double-check the query syntax to ensure you're using the correct operators and functions.
  2. Verify the fields: Make sure you're querying the correct fields and that they exist in the collection.
  3. Use a Code node to validate the query: If you're still unsure about the query, use a Code node to validate it. You can use the following JavaScript code to validate the query:

To prevent the "Invalid find query" error from coming back, follow these best practices:
