Aggregate Node Error - Invalid Group By

Error: Aggregate group by is invalid · Node: Aggregate

What this error actually means

The "Aggregate group by is invalid" error in n8n's Aggregate node is a common issue that can be frustrating to resolve. But before we dive into the fix, let's understand what this error actually means. In simple terms, the Aggregate node is trying to group your data by one or more fields, but it's unable to do so because the field(s) you've specified are not valid for grouping.

When you try to aggregate data, you need to specify a group by field that can be used to split the data into distinct groups. This field should be a column in your data that contains unique values, such as a customer ID, a product category, or a date range. If the field you've specified is not unique or is not a column in your data, the Aggregate node will throw an error.

The three most common causes

After working with numerous n8n users, we've identified the three most common causes of this error:

  1. Invalid group by field: This is the most common cause of the error. Make sure the field you've specified in the Aggregate node is a valid column in your data and contains unique values.
  2. Missing or empty group by field: If the group by field is missing or empty, the Aggregate node will throw an error. Ensure that the field is present in all records and contains values.
  3. Data type mismatch: If the data type of the group by field is not compatible with the aggregation function you're using, the Aggregate node will throw an error. For example, if you're using the SUM function, the group by field should be a numeric type.

Step-by-step fix

To fix the "Aggregate group by is invalid" error, follow these steps:

  1. Check the group by field: Verify that the field you've specified in the Aggregate node is a valid column in your data and contains unique values.
  2. Use a valid group by field: If the field is not valid, replace it with a different field that meets the requirements.
  3. Use a Code node to preprocess data: If you need to perform complex data transformations or type conversions, use a Code node to preprocess your data before it reaches the Aggregate node.
  4. Example code: If you're using a Code node, you can use the following JavaScript code to convert a string field to lowercase and use it as the group by field:
const data = [
  { id: 1, name: 'John' },
  { id: 2, name: 'Jane' },
  { id: 3, name: 'John' }
];

const groupedData = data.reduce((acc, current) => {
  const key = current.name.toLowerCase();
  if (!acc[key]) {
    acc[key] = [];
  }
  acc[key].push(current);
  return acc;
}, {});

console.log(groupedData);

This code will group the data by the name field, converting it to lowercase before grouping.

To prevent the "Aggregate group by is invalid" error from coming back, follow these best practices:
