Wait Node Error: TypeError: Cannot read properties of null

Error: TypeError: Cannot read properties of null (reading 'X') · Node: Wait

What this error actually means

When you encounter the error TypeError: Cannot read properties of null (reading 'X') in n8n, it means that the Wait node is trying to access a property (X) of a null value. This occurs when the duration field in the Wait node is set to a null value.

In n8n, the Wait node expects a valid duration value, such as a number or a string representing a duration (e.g., "1s", "10m", "1h"). If the duration field is set to null, the node will throw a TypeError when trying to access its properties.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Incorrect duration value: The duration field in the Wait node is set to a null value, which is not a valid duration.
  2. Missing or incorrect data: The node is trying to access a property (X) of a null value, which means that the data being processed is incomplete or missing.
  3. Configuration issue: The Wait node is not properly configured, leading to the error.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the duration field: Verify that the duration field in the Wait node is set to a valid value, such as a number or a string representing a duration.
  2. Check the data: Ensure that the data being processed is complete and not missing any required properties.
  3. Configure the node correctly: Make sure that the Wait node is properly configured, including setting the duration field to a valid value.

To add a check for null duration and wait for a valid duration, you can use a Code node with the following JavaScript code:

const duration = new Date().getTime() + 1000; // wait for 1 second
if (duration === null) {
  // handle error or set default duration
  duration = 1000; // wait for 1 second
}
return { duration };

Prevent it from coming back

To prevent this error from occurring in the future, make sure to:

  • Always validate user input and ensure that the duration field is set to a valid value.
  • Use error handling mechanisms, such as the Error Trigger workflow trigger, to catch and handle errors.
  • Regularly review and update your workflows to ensure that they are properly configured and error-free.
