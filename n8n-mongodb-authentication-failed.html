MongoDB node reports authentication failed error in n8n

Error: Authentication failed · Node: MongoDB

What this error actually means

The error "Authentication failed" is a common issue when setting up the MongoDB node in n8n. This error occurs when the node is unable to authenticate with the MongoDB database using the provided credentials. The most likely cause is that the username, password, or both are incorrect.

The three most common causes

  1. Incorrect credentials: Double-check that the username and password used in the MongoDB node are correct. Make sure to use the correct database and collection names.
  2. Database or collection not found: Ensure that the database and collection specified in the node exist in the MongoDB instance. You can use the MongoDB Compass or the MongoDB CLI to verify this.
  3. Authentication method: Verify that the authentication method used in the node matches the one configured in the MongoDB instance. For example, if you're using a username and password, make sure that the MongoDB instance is configured to use username and password authentication.

Step-by-step fix

To fix the "Authentication failed" error, follow these steps:

  1. Verify credentials: Check the username and password used in the MongoDB node. Make sure to use the correct database and collection names.
  2. Use the correct authentication method: Verify that the authentication method used in the node matches the one configured in the MongoDB instance.
  3. Check database and collection existence: Use the MongoDB Compass or the MongoDB CLI to verify that the database and collection specified in the node exist.
  4. Use a Code node to test credentials: Create a new Code node and use the following JavaScript code to test the credentials:
const MongoClient = require('mongodb').MongoClient;
const url = 'mongodb://localhost:27017';
const dbName = 'mydatabase';
const collectionName = 'mycollection';

MongoClient.connect(url, function(err, client) {
  if (err) {
    console.error(err);
  } else {
    const db = client.db(dbName);
    const collection = db.collection(collectionName);
    collection.find().toArray(function(err, docs) {
      if (err) {
        console.error(err);
      } else {
        console.log(docs);
      }
    });
  }
});

Replace the url, dbName, and collectionName variables with your actual MongoDB instance URL, database name, and collection name.

  1. Configure the MongoDB node: Once you've verified the credentials and database existence, update the MongoDB node with the correct credentials and authentication method.

Prevent it from coming back

To prevent this error from occurring in the future, follow these best practices:

  • Store credentials securely: Store the MongoDB credentials securely using environment variables or a secrets manager.
  • Use a retry mechanism: Configure the MongoDB node to retry failed connections using the "Retry On Fail" setting in the node's Settings tab.
  • Monitor database and collection existence: Regularly verify that the database and collection specified in the node exist in the MongoDB instance.

When to escalate

If you've followed the steps above and still encounter the "Authentication failed" error, it's likely that there's a more complex issue at play. In this case, escalate the issue to your n8n support team or MongoDB support team for further assistance. Provide them with the following information:

  • The error message and stack trace
  • The n8n workflow and node configuration
  • The MongoDB instance URL, database name, and collection name
  • The credentials used in the MongoDB node
