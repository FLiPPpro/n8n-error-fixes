n8n Cron node fails with schedule error message

Error: Schedule error: could not parse cron expression · Node: Cron

What this error actually means

The "Schedule error: could not parse cron expression" error in n8n's Cron node is a common issue that occurs when the cron expression is not properly formatted. This error message is quite straightforward, but it can be tricky to identify the root cause, especially for those new to cron expressions.

A cron expression is a string that defines a schedule for a job to run. It consists of five or six fields separated by spaces, which represent the minute, hour, day of the month, month, and day of the week. The format is as follows:

minute hour day-of-month month day-of-week

For example, 0 0 * * * runs the job at midnight every day.

The three most common causes

Based on our experience and support requests, the three most common causes of this error are:

  1. Incorrect cron expression format: The most common cause is using an invalid or incomplete cron expression. Make sure you've followed the correct format and included all the necessary fields.
  2. Missing or extra spaces: A single misplaced space or extra space in the cron expression can cause the parser to fail. Double-check the cron expression for any unnecessary spaces.
  3. Unsupported cron expression: Some cron expressions, like those with invalid or unsupported characters, can cause the parser to fail. Ensure you're using a valid and supported cron expression.

Step-by-step fix

To fix the issue, follow these steps:

  1. Check the cron expression format: Verify that your cron expression follows the correct format: minute hour day-of-month month day-of-week.
  2. Use a valid cron expression: Make sure you're using a valid and supported cron expression. You can test your cron expression using online tools like [Cron Expression Tester](https://crontab.guru/).
  3. Remove extra spaces: Double-check the cron expression for any unnecessary spaces. Remove any extra spaces to ensure the parser can correctly read the expression.
  4. Use a Code node to validate the cron expression: If you're still unsure about the cron expression, use a Code node to validate it. You can write a simple JavaScript function to parse the cron expression and return an error message if it's invalid.

Here's an example JavaScript code block you can use in a Code node to validate the cron expression:

const cronExpression = "0 0 * * *"; // Replace with your cron expression
const cron = require('cron');

try {
  const schedule = cron.schedule(cronExpression, () => {
    // Job code here
  });
  console.log("Cron expression is valid");
} catch (error) {
  console.error("Cron expression is invalid:", error.message);
}
  1. Update the Cron node: Once you've validated the cron expression, update the Cron node with the correct expression.

Prevent it from coming back

To prevent this issue from occurring in the future, make sure to:

  • Always test your cron expressions using online tools or a Code node.
  • Double-check the cron expression format and remove any extra spaces.
  • Use a valid and supported cron expression.

When to escalate

If you've tried the above steps and still encounter the "Schedule error: could not parse cron expression" error, it's likely due to a more complex issue. In this case, please:

  • Provide the exact cron expression you're using.
  • Share the error message and any relevant logs.
  • Contact our support team for further assistance.
