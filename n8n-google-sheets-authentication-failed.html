Google Sheets Node Authentication Failed Error in n8n Workflow

Error: OAuth2 authentication failed: invalid credentials · Node: Google Sheets

What this error actually means

The error message "OAuth2 authentication failed: invalid credentials" is a generic error that can have multiple causes. In the context of the Google Sheets node in n8n, this error typically indicates that the node is unable to authenticate with your Google account using the provided credentials.

The three most common causes

Based on our experience and the nature of the error, the three most common causes of this issue are:

  1. Incorrect client ID or secret: Make sure that you have entered the correct client ID and secret for your Google Sheets API. You can find these in the Google Cloud Console.
  2. Insufficient permissions: Ensure that the account you are using has the necessary permissions to access the Google Sheets API.
  3. Credentials not properly configured: Verify that the credentials are properly configured in the Google Sheets node, including the correct scope, redirect URI, and authentication method.

Step-by-step fix

To resolve this issue, follow these steps:

  1. Verify your credentials: Double-check that you have entered the correct client ID and secret in the Google Sheets node. Make sure that the credentials are properly formatted and that you have selected the correct scope.
  2. Check your account permissions: Ensure that the account you are using has the necessary permissions to access the Google Sheets API. You can check this in the Google Cloud Console.
  3. Update your credentials: If you have made any changes to your credentials, update them in the Google Sheets node. You can do this by clicking on the "Update Credentials" button in the node's Settings tab.
  4. Test your credentials: To test your credentials, you can use the "Test" button in the Google Sheets node. This will attempt to authenticate with your account using the provided credentials.

Here is an example of how you can use the Code node to test your credentials:

const credentials = {
  "client_id": "YOUR_CLIENT_ID",
  "client_secret": "YOUR_CLIENT_SECRET",
  "redirect_uri": "YOUR_REDIRECT_URI",
  "scope": "https://www.googleapis.com/auth/spreadsheets"
};

const auth = new google.auth.GoogleAuth({
  client_id: credentials.client_id,
  client_secret: credentials.client_secret,
  redirect_uri: credentials.redirect_uri,
  scope: credentials.scope
});

const token = await auth.getAccessToken();

console.log(token);

Replace YOUR_CLIENT_ID, YOUR_CLIENT_SECRET, and YOUR_REDIRECT_URI with your actual credentials.

Prevent it from coming back

To prevent this issue from recurring, make sure to:

  • Regularly update your credentials to ensure that they are still valid.
  • Verify that your account permissions are still correct.
  • Use a secure method to store your client ID and secret, such as an environment variable or a secrets manager.

When to escalate

If you have tried the above steps and are still experiencing issues, it may be necessary to escalate the issue to our support team. Please provide as much detail as possible about the issue, including any error messages you are seeing and any relevant configuration settings.
