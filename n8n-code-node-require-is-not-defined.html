n8n Code Node "require is not defined" — Fix

Error: ReferenceError: require is not defined · Node: Code

What this error actually means

The ReferenceError: require is not defined error in n8n's Code node is a common issue that occurs when trying to use Node.js modules in a sandbox environment without proper configuration. This error is thrown because the require function is not available by default in the Code node's sandbox.

The three most common causes

There are three primary reasons why you might encounter this error:

  1. Missing configuration: The Code node is trying to use a Node.js module without the necessary configuration to allow external modules.
  2. Incorrect module import: The Code node is trying to import a module using the wrong syntax or without the necessary permissions.
  3. Unsupported module: The Code node is trying to use a module that is not supported in the sandbox environment.

Step-by-step fix

To resolve this issue, follow these steps:

  1. Check the Code node's settings: Ensure that the NODE_FUNCTION_ALLOW_EXTERNAL option is enabled in the Code node's settings. This option allows the Code node to use external modules.
  2. Use a supported module: If the module you're trying to use is not supported in the sandbox environment, consider using an alternative module or rewriting the code to use a supported module.
  3. Use a require alternative: If you're trying to use a Node.js module that is not supported, consider using a require alternative like import or require.main (if available).
  4. Use a Code node with a custom function: If you need to use a specific Node.js module, consider creating a custom function in the Code node using the function keyword. This will allow you to use the require function directly.

Here's an example code block that demonstrates how to use a custom function in the Code node:

function myCustomFunction() {
  const myModule = require('my-module');
  // Use myModule here
}

myCustomFunction();

In this example, we define a custom function myCustomFunction that uses the require function to import the my-module module. We then call the custom function to execute the code.

Prevent it from coming back

To prevent this error from occurring in the future, ensure that you:

  • Always enable the NODE_FUNCTION_ALLOW_EXTERNAL option in the Code node's settings.
  • Use supported modules or rewrite the code to use alternative modules.
  • Test your workflows thoroughly to catch any errors before deploying them to production.

When to escalate

If you've tried the above steps and still encounter the ReferenceError: require is not defined error, it may be necessary to escalate the issue to n8n's support team for further assistance. Be sure to provide detailed information about your workflow, including the Code node's settings and the exact error message.
