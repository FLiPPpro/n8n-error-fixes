n8n MongoDB node connection error

Error: Error: Connection to MongoDB database failed · Node: MongoDB

What this error actually means

When you see the error "Error: Connection to MongoDB database failed" in n8n, it means that the node responsible for connecting to your MongoDB database has encountered an issue and cannot establish a connection. This can be due to various reasons such as incorrect database credentials, network issues, or problems with the MongoDB server itself.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Incorrect database credentials: Make sure you have entered the correct MongoDB username, password, and database name in the node's settings.
  2. Network issues: Check if your MongoDB server is reachable from the machine where n8n is running. You can try pinging the MongoDB server from the n8n machine to verify connectivity.
  3. MongoDB server issues: Ensure that the MongoDB server is running and accessible. You can check the MongoDB logs to see if there are any errors or issues.

Step-by-step fix

To fix the error, follow these steps:

  1. Check the node's settings: Go to the node's settings and verify that the database credentials are correct. Make sure you have entered the correct MongoDB username, password, and database name.
  2. Verify network connectivity: Check if your MongoDB server is reachable from the machine where n8n is running. You can try pinging the MongoDB server from the n8n machine to verify connectivity.
  3. Check MongoDB server status: Ensure that the MongoDB server is running and accessible. You can check the MongoDB logs to see if there are any errors or issues.
  4. Use a Code node to test connection: If you're still having issues, create a new Code node and use the following JavaScript code to test the connection:
const MongoClient = require('mongodb').MongoClient;

const url = 'mongodb://localhost:27017';
const dbName = 'mydatabase';

MongoClient.connect(url, function(err, client) {
  if (err) {
    console.error(err);
    return;
  }
  console.log('Connected to MongoDB');
  const db = client.db(dbName);
  // You can now use the db object to perform operations
  client.close();
});

Replace the url and dbName variables with your actual MongoDB connection details. If the connection is successful, you should see a message indicating that you're connected to MongoDB.

Prevent it from coming back

To prevent this error from occurring in the future, make sure to:

  • Regularly check the MongoDB logs for any errors or issues.
  • Monitor the n8n logs to detect any connection issues.
  • Use a retry mechanism on the node itself (Settings → "Retry On Fail", "Max Tries", and "Wait Between Tries (ms)") to automatically retry the connection if it fails.

When to escalate

If you've followed the steps above and are still experiencing issues, it's likely that the problem is more complex and requires further investigation. In this case, you should:

  • Check the n8n documentation and community forums to see if others have experienced similar issues.
  • Reach out to the n8n support team for assistance.
  • Consider seeking help from a MongoDB expert or a system administrator to troubleshoot the issue.
