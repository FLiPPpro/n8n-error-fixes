Telegram node throws 'OAuth2 refresh token revoked' error

Error: OAuth2 refresh token revoked · Node: Telegram

What this error actually means

When you see the error "OAuth2 refresh token revoked" in n8n, it means that the refresh token used to authenticate your Telegram node has been revoked by the Telegram API. This can happen for a variety of reasons, such as:

  • The user who authorized your app has revoked access
  • The refresh token has expired
  • The Telegram API has rate-limited your app

Whatever the reason, the result is the same: your Telegram node can no longer authenticate with the Telegram API, and you'll see this error message.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. User revocation: A user who authorized your app has revoked access, causing the refresh token to be revoked.
  2. Token expiration: The refresh token has expired, which can happen if it's not regularly refreshed.
  3. Telegram API rate limiting: Your app has exceeded the rate limits set by the Telegram API, causing the refresh token to be revoked.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the Telegram node settings: Go to the Telegram node settings and check if the OAuth2 refresh token is still valid. If it's not, you'll need to obtain a new one.
  2. Check the user's authorization: Verify that the user who authorized your app still has access to the Telegram API. If they've revoked access, you'll need to re-authorize the app.
  3. Configure retries: Configure the Telegram node to retry the authentication process. You can do this by setting the "Retry On Fail" setting to "true" and adjusting the "Max Tries" and "Wait Between Tries (ms)" settings to suit your needs.

Here's an example of how you can configure retries for the Telegram node:

{
  "name": "Telegram",
  "settings": {
    "retryOnFail": true,
    "maxTries": 3,
    "waitBetweenTries": 5000
  }
}

This will configure the Telegram node to retry the authentication process up to 3 times, with a 5-second delay between retries.

  1. Use a "Wait" node to add a delay: If you want to add a delay between retries, you can use a "Wait" node to add a delay. For example:
{
  "name": "Wait",
  "settings": {
    "duration": 5000
  }
}

This will add a 5-second delay between retries.

  1. Use an "Error Trigger" to branch on error: If you want to branch on error, you can use an "Error Trigger" to trigger a separate workflow when the Telegram node fails. For example:
{
  "name": "Error Trigger",
  "settings": {
    "error": "OAuth2 refresh token revoked"
  }
}

This will trigger a separate workflow when the Telegram node fails.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Regularly refresh the OAuth2 refresh token to prevent it from expiring
  • Monitor the Telegram API rate limits to prevent your app from exceeding them
  • Verify that the user who authorized your app still has access to the Telegram API

When to escalate

If you've tried the above steps and the error persists, it may be time to escalate the issue. This could involve:

  • Reaching out to the Telegram API support team for assistance
  • Reaching out to the n8n community for assistance
  • Reaching out to a senior n8n engineer for assistance
