MySQL Node Returns Error 1045 Access Denied for User

Error: 1045 Access denied for user · Node: MySQL

What this error actually means

The error message "1045 Access denied for user" is a MySQL error code that indicates the username or password provided to connect to the MySQL database is incorrect or does not have the necessary permissions to perform the requested action.

In the context of n8n, this error occurs when the MySQL node attempts to connect to the database using the credentials provided in the node's settings. If the credentials are incorrect or do not have the necessary permissions, the node will return this error.

The three most common causes

Based on our experience with n8n and MySQL, the three most common causes of this error are:

  1. Incorrect username or password: Double-check that the username and password provided in the MySQL node's settings are correct. Make sure to use the correct case (e.g., "myuser" vs. "MyUser").
  2. Insufficient database permissions: Ensure that the username has the necessary permissions to perform the requested action on the database. You can check the database user's permissions by running a SQL query like SHOW GRANTS FOR 'myuser'@'%'.
  3. Incorrect database host or port: Verify that the database host and port are correct. If you're using a remote database, ensure that the host and port are correctly specified in the node's settings.

Step-by-step fix

To fix the error, follow these steps:

  1. Verify the username and password: Double-check that the username and password provided in the MySQL node's settings are correct. Make sure to use the correct case (e.g., "myuser" vs. "MyUser").
  2. Check database permissions: Run a SQL query like SHOW GRANTS FOR 'myuser'@'%' to check the database user's permissions. If the user does not have the necessary permissions, update the user's permissions using a query like GRANT ALL PRIVILEGES ON *.* TO 'myuser'@'%'.
  3. Update the node's settings: Once you've verified the username, password, and database permissions, update the MySQL node's settings with the correct values.

Here's an example of how to update the node's settings using a Code node:

{
  "credentials": {
    "username": "myuser",
    "password": "mypassword",
    "host": "localhost",
    "port": 3306
  }
}

You can paste this code into a Code node and update the credentials object with the correct values.

Prevent it from coming back

To prevent this error from occurring in the future, follow these best practices:

  • Use a secure password: Use a secure password for your database user, and consider using a password manager to store the password securely.
  • Limit database permissions: Only grant the necessary permissions to the database user, and consider using role-based access control to manage database permissions.
  • Monitor database connections: Monitor database connections to detect potential security issues, such as brute-force attacks or unauthorized access.

When to escalate

If you've followed the steps above and the error persists, it may be necessary to escalate the issue to your database administrator or IT team. They can help you investigate the issue further and provide additional support to resolve the problem.
