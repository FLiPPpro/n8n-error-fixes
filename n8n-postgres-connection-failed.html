n8n Postgres connection failed to database

Error: Connection failed · Node: Postgres

What this error actually means

When you encounter the "Connection failed" error in n8n while connecting to Postgres, it means that n8n was unable to establish a connection to your Postgres database. This error can occur due to various reasons such as incorrect database credentials, network issues, or problems with the Postgres server itself.

The three most common causes

Based on our experience and user reports, the three most common causes of the "Connection failed" error in n8n are:

  1. Incorrect database credentials: Make sure that you have entered the correct username, password, and host for your Postgres database.
  2. Network issues: Check your network connection and ensure that it is stable and functioning properly.
  3. Postgres server issues: Verify that your Postgres server is running and accessible from the n8n instance.

Step-by-step fix

To troubleshoot and fix the "Connection failed" error, follow these steps:

  1. Check database credentials: Double-check that you have entered the correct database credentials in the Postgres node. Ensure that the username, password, and host are correct.
  2. Verify network connection: Check your network connection and ensure that it is stable and functioning properly.
  3. Check Postgres server status: Verify that your Postgres server is running and accessible from the n8n instance.
  4. Increase retry attempts: Go to the Postgres node's Settings tab and increase the "Max Tries" value to 5 or more. This will allow n8n to retry the connection multiple times before giving up.
  5. Add a delay between retries: Go to the Postgres node's Settings tab and increase the "Wait Between Tries (ms)" value to 5000 or more. This will introduce a delay between each retry attempt, giving the Postgres server time to recover.

Here's an example code block that you can use in a Code node to implement a retry mechanism:

const retry = 5;
const waitBetweenTries = 5000;

for (let i = 0; i < retry; i++) {
  try {
    // Your Postgres connection code here
    const conn = await pool.connect();
    // ...
  } catch (err) {
    if (i < retry - 1) {
      await new Promise(resolve => setTimeout(resolve, waitBetweenTries));
    } else {
      throw err;
    }
  }
}

This code will retry the Postgres connection up to 5 times with a 5-second delay between each attempt.

Prevent it from coming back

To prevent the "Connection failed" error from occurring in the future, make sure to:

  • Regularly back up your Postgres database to prevent data loss in case of a connection failure.
  • Monitor your Postgres server's performance and adjust its configuration as needed to prevent overload and connection failures.
  • Ensure that your n8n instance has the correct Postgres credentials and connection settings.

When to escalate

If you have tried the above steps and the "Connection failed" error persists, it may be necessary to escalate the issue to a Postgres administrator or a n8n support specialist. Provide them with the following information:

  • Your n8n instance version and configuration
  • Your Postgres database credentials and connection settings
  • Any relevant error logs or messages
  • Any troubleshooting steps you have taken so far
