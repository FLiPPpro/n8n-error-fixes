n8n Webhook node returns 400 Bad Request from API

Error: Invalid JSON payload · Node: Webhook

What this error actually means

The "Invalid JSON payload" error in n8n's Webhook node is a common issue that can be frustrating to resolve. This error occurs when the data being sent to the API is not in a valid JSON format. This can happen due to various reasons such as incorrect data formatting, missing required fields, or mismatched data types.

The three most common causes

Based on our experience, the three most common causes of the "Invalid JSON payload" error in n8n's Webhook node are:

  1. Incorrect data formatting: This is the most common cause of the error. When the data is not properly formatted in JSON, the API will reject it, resulting in a 400 error.
  2. Missing required fields: If the API requires specific fields to be present in the JSON payload, but they are missing, the API will reject the request.
  3. Mismatched data types: If the data types of the fields in the JSON payload do not match the expected data types of the API, the API will reject the request.

Step-by-step fix

To fix the "Invalid JSON payload" error, follow these steps:

  1. Check the data formatting: Ensure that the data is properly formatted in JSON. You can use online JSON validators to check the format.
  2. Verify required fields: Check the API documentation to ensure that all required fields are present in the JSON payload.
  3. Check data types: Ensure that the data types of the fields in the JSON payload match the expected data types of the API.

To validate the JSON payload, you can use a Code node with the following JavaScript code:

const payload = {
  "name": "John Doe",
  "age": 30,
  "city": "New York"
};

const jsonPayload = JSON.stringify(payload);
console.log(jsonPayload);

const isValid = jsonPayload.trim().startsWith('{') && jsonPayload.trim().endsWith('}');
console.log(isValid);

This code will validate the JSON payload and log the result to the console.

Prevent it from coming back

To prevent the "Invalid JSON payload" error from coming back, follow these best practices:

  1. Use a JSON validator: Use online JSON validators to check the format of the JSON payload before sending it to the API.
  2. Test thoroughly: Test the Webhook node thoroughly to ensure that it is sending the correct data in the correct format.
  3. Monitor API logs: Monitor the API logs to detect any issues with the JSON payload.

When to escalate

If you have tried the above steps and the issue persists, it's time to escalate the issue. Escalation means that you need to involve your team's senior engineers or the n8n support team to help resolve the issue. Provide as much detail as possible, including the error message, the API documentation, and any relevant logs. This will help the support team to better understand the issue and provide a solution.
