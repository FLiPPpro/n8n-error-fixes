Google Sheets Node Error - API Request Failed

Error: Google Sheets API request failed: invalid credentials · Node: Google Sheets

What this error actually means

The error message "Google Sheets API request failed: invalid credentials" is a common issue that occurs when the Google Sheets node is unable to authenticate with the Google Sheets API. This can happen for a variety of reasons, including expired or invalid credentials, incorrect API key, or issues with the Google Sheets API itself.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Expired or invalid credentials: This is the most common cause of the error. If your credentials are expired or invalid, the Google Sheets node will not be able to authenticate with the API.
  2. Incorrect API key: If you are using an API key instead of OAuth credentials, ensure that the API key is correct and not expired.
  3. Issues with the Google Sheets API: Occasionally, issues with the Google Sheets API itself can cause authentication failures.

Step-by-step fix

To fix the error, follow these steps:

  1. Check your credentials: Ensure that your credentials are valid and not expired. You can check the expiration date of your credentials in the Google Cloud Console.
  2. Update your credentials: If your credentials are expired or invalid, update them in the Google Cloud Console and then update the credentials in n8n.
  3. Verify your API key: If you are using an API key, ensure that it is correct and not expired. You can find your API key in the Google Cloud Console.
  4. Check the Google Sheets API: If you are still experiencing issues, check the status of the Google Sheets API in the Google Cloud Console. If there are any issues with the API, you will need to wait for the issue to be resolved.

Here is a concrete code block that you can use to update your credentials in n8n:

{
  "name": "Update Google Sheets Credentials",
  "parameters": {
    "credentials": {
      "type": "OAuth2",
      "clientId": "YOUR_CLIENT_ID",
      "clientSecret": "YOUR_CLIENT_SECRET",
      "redirectUri": "YOUR_REDIRECT_URI",
      "scopes": "https://www.googleapis.com/auth/spreadsheets"
    }
  }
}

You can paste this code into a Code node in n8n to update your credentials.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Regularly update your credentials to ensure they are not expired.
  • Monitor the status of the Google Sheets API to ensure it is not experiencing any issues.
  • Use a retry mechanism to handle temporary authentication failures.

You can configure a retry mechanism on the Google Sheets node by going to the Settings tab and enabling "Retry On Fail". You can also configure the "Max Tries" and "Wait Between Tries (ms)" settings to control the retry behavior.

When to escalate

If you have tried the steps above and are still experiencing issues, it may be necessary to escalate the issue to the n8n support team. Be sure to provide as much detail as possible about the error, including any error messages and any steps you have taken to troubleshoot the issue.
