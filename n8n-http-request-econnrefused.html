n8n HTTP Request ECONNREFUSED — How to Fix

Error: ECONNREFUSED · Node: HTTP Request

What this error actually means

The ECONNREFUSED error is a common issue when working with the HTTP Request node in n8n. It occurs when the node is unable to establish a connection to the target service. This error is usually a sign that there's a problem with the service itself, the network configuration, or the way you're trying to connect to it.

The three most common causes

There are three primary reasons why you might encounter the ECONNREFUSED error:

  1. Target service unreachable: The service you're trying to connect to is down or not responding. This could be due to a variety of reasons, including server maintenance, network issues, or even a simple typo in the URL.
  2. Docker networking issues: If you're running n8n in a Docker container, you might encounter issues with the networking configuration. This can lead to the node being unable to connect to the target service.
  3. Firewalled port: The port you're trying to connect to might be firewalled, preventing the node from establishing a connection.

Step-by-step fix

To resolve the ECONNREFUSED error, follow these steps:

  1. Verify the target service: Check if the target service is up and running. You can do this by visiting the URL in a web browser or using a tool like curl from the command line.
  2. Check Docker networking: If you're running n8n in a Docker container, ensure that the networking configuration is correct. You can check the container's network settings by running docker inspect .
  3. Configure the HTTP Request node: Make sure the node is configured correctly. Check the following:

* The URL is correct and the port is open. * The node is trying to connect to the correct host (e.g., localhost vs host.docker.internal). * The node has the correct authentication credentials (if required).

  1. Configure retries: Configure the node to retry the connection. You can do this by setting the Retry On Fail option to true and adjusting the Max Tries and Wait Between Tries (ms) settings as needed.
  2. Add a delay: If the target service is experiencing high latency or is down temporarily, add a delay using the Wait node to retry the connection later.
  3. Code example: To add a delay, you can use the following code in a Code node:
const delay = 5000; // 5 seconds
return new Promise((resolve) => {
  setTimeout(() => {
    resolve({ statusCode: 200 });
  }, delay);
});

This code adds a 5-second delay before resolving the promise.

Prevent it from coming back

To prevent the ECONNREFUSED error from occurring again, make sure to:

  • Regularly verify the target service's status.
  • Monitor the node's logs for any errors or issues.
  • Adjust the node's configuration as needed to accommodate changes in the target service or network configuration.

When to escalate

If you've tried the above steps and the ECONNREFUSED error persists, it's likely that there's a more complex issue at play. In this case, you should:

  • Review the node's configuration and settings again.
  • Check the target service's documentation and support resources for any known issues or workarounds.
  • Reach out to the n8n community or support team for further assistance.
  • Consider escalating the issue to the target service's support team if it's a known issue on their end.
