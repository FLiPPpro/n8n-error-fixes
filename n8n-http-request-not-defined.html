Error ReferenceError not defined in n8n HTTP Request Node

Error: ReferenceError: require is not defined · Node: HTTP Request

What this error actually means

When you encounter the ReferenceError: require is not defined error in n8n, it's essential to understand what's happening behind the scenes. This error typically occurs when the HTTP Request node is trying to make an external request, but it's unable to do so due to a missing or misconfigured require statement.

In n8n, the require function is used to load external modules, such as libraries or dependencies, in Node.js. However, in this specific case, the error is not related to a missing module, but rather to the fact that the require function is not defined in the context of the HTTP Request node.

The three most common causes

Based on our experience and analysis, the three most common causes of this error are:

  1. Missing or incorrect url field: Make sure that the url field in the HTTP Request node is correctly configured. The URL should be a valid, fully qualified URL that points to the external resource you're trying to fetch.
  2. Incorrect method field: Ensure that the method field in the HTTP Request node is set to a valid HTTP method (e.g., GET, POST, PUT, etc.). If the method is not valid, the node will throw an error.
  3. Missing or incorrect headers field: Verify that the headers field in the HTTP Request node is correctly configured. If the headers are not properly set, the node may throw an error.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the url field: Ensure that the url field in the HTTP Request node is correctly configured. If the URL is missing or incorrect, update it to a valid, fully qualified URL.
  2. Verify the method field: Ensure that the method field in the HTTP Request node is set to a valid HTTP method (e.g., GET, POST, PUT, etc.).
  3. Configure the headers field: Verify that the headers field in the HTTP Request node is correctly configured. If the headers are not properly set, update them to match the requirements of the external resource you're trying to fetch.

Here's an example code block that you can use to test the HTTP Request node:

{
  "name": "HTTP Request",
  "params": {
    "url": "https://api.example.com/data",
    "method": "GET",
    "headers": {
      "Authorization": "Bearer YOUR_API_KEY"
    }
  }
}

Replace YOUR_API_KEY with your actual API key.

If the error persists after verifying the url, method, and headers fields, try adding a retry option to the HTTP Request node. You can configure this via the node's Settings tab.

Prevent it from coming back

To prevent this error from occurring in the future, make sure to:

  • Double-check the url field in the HTTP Request node to ensure it's correctly configured.
  • Verify the method field to ensure it's set to a valid HTTP method.
  • Configure the headers field correctly to match the requirements of the external resource you're trying to fetch.
