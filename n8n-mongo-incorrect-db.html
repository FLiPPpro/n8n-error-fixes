n8n MongoDB node returns 'no such collection'

Error: Error getting collection: no such collection · Node: MongoDB

What this error actually means

The "no such collection" error in n8n's MongoDB node indicates that the node is unable to find the specified collection in the MongoDB database. This error can occur due to various reasons such as incorrect collection name, missing collection, or issues with the database connection.

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Incorrect collection name: Double-check that the collection name specified in the MongoDB node is correct. Make sure to include the database name if it's not the default database.
  2. Missing collection: Verify that the collection exists in the MongoDB database. You can use the MongoDB Compass or MongoDB CLI to check the collections in your database.
  3. Database connection issues: Ensure that the MongoDB connection is stable and the credentials are correct. Check the MongoDB node's settings for any errors or warnings.

Step-by-step fix

To resolve the "no such collection" error, follow these steps:

  1. Verify the collection name: Check the collection name in the MongoDB node's settings. Make sure it matches the actual collection name in the database.
  2. Check the database connection: Verify that the MongoDB connection is stable and the credentials are correct. Check the MongoDB node's settings for any errors or warnings.
  3. Use a Code node to check the collection: Add a Code node to your workflow and use the following JavaScript code to check if the collection exists:
const n8n = require('n8n');
const db = new n8n.Database(n8n.credentials.mongodb);

db.getCollection('your_database_name', 'your_collection_name', (err, collection) => {
  if (err) {
    console.error(err);
  } else {
    console.log('Collection found');
  }
});

Replace 'your_database_name' and 'your_collection_name' with the actual database and collection names. This code uses the n8n Database class to check if the collection exists. If the collection is found, the code logs a success message.

  1. Update the MongoDB node: If the collection is found, update the MongoDB node with the correct collection name.

Prevent it from coming back

To prevent the "no such collection" error from occurring again, follow these best practices:

  1. Use a Code node to validate the collection: Use a Code node to validate the collection name before sending the data to the MongoDB node.
  2. Configure the MongoDB node to retry: Configure the MongoDB node to retry the operation if it fails due to a "no such collection" error. You can do this by setting the "Retry On Fail" option to true and configuring the "Max Tries" and "Wait Between Tries (ms)" options.
  3. Monitor the MongoDB connection: Monitor the MongoDB connection for any issues or errors. Use the MongoDB Compass or MongoDB CLI to check the database connection.

When to escalate

If you have followed the steps above and the "no such collection" error still occurs, it's likely due to a more complex issue such as a database schema change or a connection issue. In this case, escalate the issue to your n8n support team or MongoDB support team for further assistance. Provide as much detail as possible about the issue, including the error message, database schema, and any relevant configuration settings.
