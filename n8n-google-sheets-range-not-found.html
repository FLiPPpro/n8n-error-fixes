n8n Google Sheets "Range Not Found" — Fix

Error: Unable to parse range · Node: Google Sheets

What this error actually means

The error "Unable to parse range" in n8n's Google Sheets node is a generic message that can have multiple causes. However, it generally indicates that the node is unable to understand the range or sheet reference you provided. This can happen when the sheet name contains special characters or spaces, or when the range refers to a non-existent tab.

The three most common causes

  1. Unquoted sheet names: If the sheet name contains spaces or special characters, it's not properly quoted. Make sure to enclose the sheet name in double quotes (") when referencing it in the Google Sheets node.
  2. Non-existent tabs: If the range references a tab that doesn't exist in the Google Sheets document, the node will throw an error. Double-check that the tab exists and the range is correct.
  3. Invalid range syntax: Ensure that the range syntax is correct. A valid range should be in the format sheetName!range, where sheetName is the name of the sheet and range is the cell range (e.g., A1:B2).

Step-by-step fix

To fix the error, follow these steps:

  1. Check the sheet name: If the sheet name contains spaces or special characters, enclose it in double quotes (") in the Google Sheets node.
{
  "sheet": {
    "name": "\"My Sheet\"",
    "range": "A1:B2"
  }
}
  1. Verify the tab exists: Make sure the tab referenced by the range exists in the Google Sheets document. If not, create the tab or adjust the range to reference an existing tab.
  2. Validate the range syntax: Ensure the range syntax is correct. If you're unsure, try referencing a different range or sheet to isolate the issue.

Prevent it from coming back

To prevent this error from occurring in the future, consider the following:

  • Use a Code node to validate the range: Write a JavaScript function in a Code node to validate the range syntax and ensure it references an existing tab.
const spreadsheet = {
  "sheets": [
    {
      "name": "My Sheet",
      "range": "A1:B2"
    }
  ]
};

const range = spreadsheet.sheets[0].range;
const sheetName = spreadsheet.sheets[0].name;

if (!range || !sheetName) {
  return { error: "Invalid range or sheet name" };
}

// Validate range syntax
if (range.indexOf("!") === -1) {
  return { error: "Invalid range syntax" };
}

// Validate sheet existence
const sheet = spreadsheet.sheets.find((sheet) => sheet.name === sheetName);
if (!sheet) {
  return { error: "Sheet not found" };
}
