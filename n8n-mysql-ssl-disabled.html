n8n MySQL node returns SSL disabled error

Error: SSL connection is required · Node: MySQL

What this error actually means

When you encounter the "SSL connection is required" error in n8n while connecting to a MySQL database, it means that the MySQL node is unable to establish a secure connection to the database. This is typically due to the MySQL node's settings not being configured to use SSL/TLS encryption.

The three most common causes

There are three common reasons why you might encounter this error:

  1. MySQL node settings: The MySQL node's settings are not configured to use SSL/TLS encryption. This is the most common cause of the error.
  2. Database configuration: The MySQL database itself is not configured to allow SSL/TLS connections.
  3. Certificate or key issues: There are issues with the SSL/TLS certificate or key used by the MySQL node.

Step-by-step fix

To fix the error, follow these steps:

  1. Check the MySQL node settings: Go to the MySQL node's Settings tab and check the "Use SSL" setting. If it's not enabled, toggle it on.
  2. Configure the SSL/TLS settings: In the MySQL node's Settings tab, configure the SSL/TLS settings to match your database's requirements. This may include specifying the path to the certificate and key files.
  3. Test the connection: Save the changes and test the connection by running a workflow. If the connection fails, check the error message for more information.

Here's an example of how you can configure the SSL/TLS settings in a Code node:

{
  "name": "MySQL Node Settings",
  "settings": {
    "useSSL": true,
    "sslCa": "/path/to/ca.crt",
    "sslCert": "/path/to/client.crt",
    "sslKey": "/path/to/client.key"
  }
}

You can paste this code into a Code node and then use the {{ }} syntax to reference the settings in the MySQL node.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Regularly review and update the MySQL node's settings to match any changes to your database's configuration.
  • Ensure that the SSL/TLS certificate and key files are up-to-date and correctly configured.
  • Monitor the error logs for any issues related to SSL/TLS connections.

When to escalate

If you've followed the steps above and still encounter the "SSL connection is required" error, it may be worth escalating the issue to your database administrator or a senior developer. They can help you investigate and resolve any underlying issues related to the database configuration or certificate/key files.
