Google Drive node throws 'invalid_grant: Token has been expired or revoked' error

Error: invalid_grant: Token has been expired or revoked · Node: Google Drive

What this error actually means

The invalid_grant: Token has been expired or revoked error is a common issue that can occur when using the Google Drive node in n8n. This error is thrown when the access token used to authenticate with the Google Drive API has expired or been revoked. This can happen for a variety of reasons, including:

  • The access token has expired due to the time limit set by the Google Drive API (usually 1 hour)
  • The user has revoked the access token in the Google Cloud Console
  • The user has changed their Google account password, which invalidates the access token

The three most common causes

Based on our experience, the three most common causes of this error are:

  1. Expired access token: The access token has expired due to the time limit set by the Google Drive API.
  2. Token revocation: The user has revoked the access token in the Google Cloud Console.
  3. Password change: The user has changed their Google account password, which invalidates the access token.

Step-by-step fix

To fix this error, follow these steps:

  1. Check the access token expiration: Check the access token expiration time in the Google Cloud Console. If the token has expired, you can obtain a new one by following the steps in the [Google Cloud Console documentation](https://support.google.com/cloud/answer/6159651).
  2. Update the access token: Update the access token in the Google Drive node by clicking on the "Update" button next to the access token field.
  3. Configure retry options: Configure the Google Drive node to retry the request if it fails due to an expired access token. To do this, go to the node's Settings tab and set "Retry On Fail" to true, "Max Tries" to a value greater than 1, and "Wait Between Tries (ms)" to a value greater than 0.
  4. Add a delay: Add a delay between retries using the "Wait" node. This will give the access token time to refresh before retrying the request.
  5. Check for token revocation: Check the Google Cloud Console to see if the access token has been revoked. If it has, you will need to obtain a new one.

Here is an example code block that you can use to update the access token and configure retry options:

{
  "name": "Google Drive",
  "credentials": {
    "access_token": "YOUR_ACCESS_TOKEN",
    "refresh_token": "YOUR_REFRESH_TOKEN"
  },
  "settings": {
    "retry_on_fail": true,
    "max_tries": 3,
    "wait_between_tries": 30000
  }
}

This code block assumes that you have obtained a new access token and refresh token, and that you want to retry the request up to 3 times with a delay of 30 seconds between each retry.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Regularly update the access token to ensure it does not expire
  • Monitor the Google Cloud Console for any token revocation
  • Use a more robust authentication flow, such as OAuth 2.0 with refresh tokens

When to escalate

If you have tried the above steps and the error persists, it may be necessary to escalate the issue to the n8n support team. Please provide as much detail as possible about the error, including any error messages or logs, and any relevant configuration or code.
