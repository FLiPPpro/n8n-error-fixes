Gmail node reports API credentials are invalid in n8n

Error: API credentials are invalid · Node: Gmail

What this error actually means

When n8n encounters the error "API credentials are invalid" while authenticating with a Gmail account, it means that the credentials you've provided are not recognized by the Gmail API. This can happen for a few reasons, such as an incorrect API key, a mismatch between the API key and the project it's associated with, or a problem with the authentication process itself.

The three most common causes

There are three common causes for this error:

  1. Incorrect API key: Double-check that you've entered the correct API key for your Gmail account. Make sure it's a valid API key and not a client secret or access token.
  2. Mismatched API key and project: Ensure that the API key you're using is associated with the correct Google Cloud project. If you've created multiple projects, verify that you're using the correct API key for the project you're working with.
  3. Authentication issues: Check that you've enabled the Gmail API in the Google Cloud Console and that the authentication flow is set up correctly in n8n.

Step-by-step fix

To fix the "API credentials are invalid" error, follow these steps:

  1. Verify your API key: Open the Google Cloud Console and navigate to the API Library page. Find the Gmail API and ensure that it's enabled. Then, go to the API keys page and verify that the API key you're using is correct.
  2. Check your project settings: Make sure that the API key you're using is associated with the correct Google Cloud project. If you've created multiple projects, ensure that you're using the correct API key for the project you're working with.
  3. Update your n8n workflow: Open your n8n workflow and navigate to the Gmail node. Click on the "Settings" tab and update the API key to the correct one. If you're using a client secret or access token, update those as well.
  4. Test your workflow: Save your workflow and test it again. If the error persists, try updating the API key or client secret/access token to ensure that it's correct.

Here's an example of how to update the API key in a Gmail node using a Code node in n8n:

{
  "name": "Update API Key",
  "type": "n8n/flow",
  "version": "1.0.0",
  "nodes": [
    {
      "name": "Gmail",
      "parameters": {
        "apiKey": "YOUR_API_KEY_HERE"
      },
      "type": "n8n-nodes-base.gmail"
    }
  ]
}

Replace YOUR_API_KEY_HERE with your actual API key.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Regularly update your API key and client secret/access token to ensure that they're correct.
  • Verify that your project settings are correct and that the API key is associated with the correct project.
  • Test your workflow regularly to catch any authentication issues.

When to escalate

If you've tried the above steps and the error persists, it's likely that there's a more complex issue at play. In this case, consider escalating the issue to your team or the n8n support team for further assistance. Provide as much detail as possible about the error, including any relevant logs or screenshots, to help the support team diagnose and resolve the issue.
