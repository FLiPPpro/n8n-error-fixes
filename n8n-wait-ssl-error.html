n8n Wait node returns SSL connection required error

Error: SSL connection is required · Node: Wait

What this error actually means

When you encounter the "SSL connection is required" error in n8n, it means that the Wait node is trying to establish a connection to a resource that requires a Secure Sockets Layer (SSL) or Transport Layer Security (TLS) connection. This is a common issue when working with APIs or services that enforce SSL connections.

The three most common causes

Here are the three most common causes of this error:

  1. Incorrect node configuration: Make sure that the Wait node is configured to connect to the correct resource, and that the connection settings are set to use SSL or TLS.
  2. Missing SSL certificate: If the resource you're trying to connect to requires an SSL certificate, ensure that it's installed and configured correctly on the node.
  3. Incompatible node settings: Check that the node settings are compatible with the resource you're trying to connect to. For example, if the resource uses a self-signed certificate, you may need to configure the node to accept it.

Step-by-step fix

To fix the "SSL connection is required" error, follow these steps:

  1. Open the Wait node and navigate to the Settings tab.
  2. Ensure that the "Use SSL" option is enabled.
  3. If the resource requires a specific SSL certificate, upload it to the node by clicking on the "Upload Certificate" button.
  4. If the resource uses a self-signed certificate, you may need to configure the node to accept it. To do this, click on the "Advanced" tab and set the "Verify Certificate" option to "False".

Here's an example of how to configure the Wait node to use an SSL certificate:

{
  "name": "Wait",
  "type": "wait",
  "config": {
    "url": "https://example.com/api/resource",
    "method": "GET",
    "headers": {
      "Authorization": "Bearer {{token}}"
    },
    "useSSL": true,
    "verifyCertificate": false
  }
}

In this example, the Wait node is configured to use an SSL connection to connect to the https://example.com/api/resource endpoint. The verifyCertificate option is set to false to accept the self-signed certificate.

Prevent it from coming back

To prevent the "SSL connection is required" error from coming back, make sure to:

  • Regularly update your SSL certificates to ensure they're valid and trusted.
  • Monitor your node logs for any errors related to SSL connections.
  • Test your node configuration regularly to ensure it's working correctly.

When to escalate

If you've followed the steps above and still encounter the "SSL connection is required" error, it may be a sign of a more serious issue. In this case, you should:

  • Check the resource documentation to ensure that the SSL connection settings are correct.
  • Reach out to the resource provider to see if there are any known issues with SSL connections.
  • Consider escalating the issue to your n8n support team for further assistance.
