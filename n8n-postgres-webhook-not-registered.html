Postgres webhook not registered in n8n error

Error: The requested webhook is not registered · Node: Postgres

What this error actually means

The "The requested webhook is not registered" error in n8n occurs when the workflow is trying to send a request to a webhook that has not been registered in the Postgres database. This can happen when you're testing a Postgres webhook after the workflow has stopped listening.

When a workflow is stopped, it will not be able to send any new requests to webhooks. If you try to test a Postgres webhook in this state, you'll get this error. This is because the webhook is not registered in the database, and the workflow is unable to register it.

The three most common causes

  1. Workflow stopped listening: As mentioned earlier, if the workflow is stopped, it will not be able to send any new requests to webhooks. This is the most common cause of this error.
  2. Webhook not registered: If the webhook is not registered in the Postgres database, the workflow will not be able to send requests to it.
  3. Incorrect webhook URL: If the webhook URL is incorrect, the workflow will not be able to send requests to it, resulting in this error.

Step-by-step fix

To fix this error, follow these steps:

  1. Start the workflow: Make sure the workflow is started and listening for new requests.
  2. Register the webhook: In the Postgres database, register the webhook by running the following SQL query:
INSERT INTO webhooks (id, name, url, enabled) VALUES ('your-webhook-id', 'Your Webhook Name', 'your-webhook-url', true);

Replace 'your-webhook-id', 'Your Webhook Name', and 'your-webhook-url' with your actual webhook ID, name, and URL.

  1. Configure the HTTP Request node: In the HTTP Request node, make sure the Webhook URL field is set to the correct URL of the registered webhook.
  2. Test the workflow: Once the workflow is started and the webhook is registered, test the workflow by sending a new request to the webhook.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Always start the workflow before testing webhooks.
  • Register webhooks in the Postgres database before sending requests to them.
  • Double-check the webhook URL in the HTTP Request node.

When to escalate

If you're still experiencing issues with the "The requested webhook is not registered" error, it's possible that there's an issue with the Postgres database or the workflow configuration. In this case, it's best to:

  • Check the Postgres database logs for any errors related to webhook registration.
  • Verify that the workflow is configured correctly and that the HTTP Request node is set up to send requests to the correct webhook URL.
  • Reach out to the n8n community or the n8n support team for further assistance.
