n8n Webhook node fails with SSL/TLS error message

Error: SSL/TLS handshake failed · Node: Webhook

What this error actually means

When you see the "SSL/TLS handshake failed" error in n8n, it means that the Webhook node is unable to establish a secure connection with the target URL. This is usually due to a misconfiguration or an issue with the target server's SSL/TLS certificates.

The three most common causes

The three most common causes of this error are:

  1. Incorrect SSL/TLS settings: Make sure that the SSL/TLS settings in the Webhook node are correct. Check that the protocol (HTTPS) and port (443) are set correctly.
  2. Invalid SSL/TLS certificates: Ensure that the target server's SSL/TLS certificates are valid and trusted. You can check the certificate's validity and trustworthiness using online tools or by contacting the target server's administrator.
  3. Firewall or proxy issues: Firewalls or proxies can block or interfere with SSL/TLS connections. Check your firewall or proxy settings to ensure that they are not blocking the connection.

Step-by-step fix

To fix the "SSL/TLS handshake failed" error, follow these steps:

  1. Verify the target URL: Double-check that the target URL is correct and that you are using the correct protocol (HTTPS) and port (443).
  2. Check the SSL/TLS settings: In the Webhook node's Settings tab, ensure that the SSL/TLS settings are correct. You can configure the SSL/TLS settings via the node's Settings tab.
  3. Verify the SSL/TLS certificates: Check the target server's SSL/TLS certificates to ensure they are valid and trusted. You can use online tools or contact the target server's administrator for assistance.
  4. Add a delay: If you suspect that the issue is due to a firewall or proxy, try adding a delay using the "Wait" node. This can help determine if the issue is related to the connection timing out.

Here is an example code block that you can use to add a delay:

{
  "nodes": [
    {
      "parameters": {
        "timeoutSeconds": 10
      },
      "name": "Wait",
      "type": "n8n-nodes-base.wait",
      "typeVersion": 1,
      "position": [
        300,
        300
      ]
    }
  ]
}

This code block adds a 10-second delay to the workflow. You can adjust the timeout value as needed.

  1. Configure retries: If the issue persists, try configuring retries on the Webhook node. You can configure retries via the node's Settings tab. Set the "Retry On Fail" option to "true" and adjust the "Max Tries" and "Wait Between Tries (ms)" values as needed.

Prevent it from coming back

To prevent the "SSL/TLS handshake failed" error from coming back, make sure to:

  • Regularly check the target server's SSL/TLS certificates to ensure they are valid and trusted.
  • Verify the target URL and SSL/TLS settings in the Webhook node.
  • Configure retries on the Webhook node to handle any potential connection issues.

When to escalate

If you have tried the above steps and the issue persists, it may be necessary to escalate the issue to the target server's administrator or a network expert. Be sure to provide detailed information about the error, including the error message, the target URL, and any relevant configuration settings.
