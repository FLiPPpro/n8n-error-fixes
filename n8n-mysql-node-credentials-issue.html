MySQL node credentials issue error in n8n workflow

Error: Error: Incorrect MySQL credentials provided for node 'MySQL' · Node: MySQL

What this error actually means

The error message "Error: Incorrect MySQL credentials provided for node 'MySQL'" is quite self-explanatory. It indicates that the MySQL node in your n8n workflow is unable to connect to the MySQL database due to incorrect username, password, or both.

The three most common causes

Before diving into the fix, let's quickly cover the three most common causes of this error:

  1. Incorrect username or password: Double-check that the username and password you've entered in the MySQL node's settings are correct. Make sure to use the correct case and formatting.
  2. Database name or host: Ensure that the database name and host you've specified in the MySQL node's settings are correct. If you're using a remote database, verify that the host and port are correct.
  3. MySQL version or configuration: If you're using a recent version of MySQL, it's possible that the node's settings are not compatible. Check the MySQL documentation to ensure that the node's settings match the requirements of your MySQL version.

Step-by-step fix

To fix the error, follow these steps:

  1. Check the MySQL node's settings: Open the MySQL node's settings and verify that the username, password, database name, and host are correct. Make sure to double-check the formatting and case of the username and password.
  2. Use a Code node to test the connection: Create a new Code node and add the following JavaScript code to test the connection:
const mysql = require('mysql');

const db = mysql.createConnection({
  host: 'your_host',
  user: 'your_username',
  password: 'your_password',
  database: 'your_database'
});

db.connect((err) => {
  if (err) {
    console.error('error connecting:', err);
    return;
  }
  console.log('connected as id ' + db.threadId);
});

Replace your_host, your_username, your_password, and your_database with the actual values from your MySQL node's settings. Run the workflow and check the logs for any errors.

  1. Update the MySQL node's settings: If the Code node test fails, update the MySQL node's settings to match the correct values. If the test succeeds, proceed to the next step.

Prevent it from coming back

To prevent this error from coming back, make sure to:

  • Store your MySQL credentials securely using an environment variable or a secrets manager.
  • Use a Code node to test the connection before proceeding with the workflow.
  • Regularly review and update your MySQL node's settings to ensure they match the current database configuration.

When to escalate

If you've followed the steps above and still encounter the error, it's likely that there's an issue with your MySQL database or configuration. In this case, escalate the issue to your database administrator or MySQL support team for further assistance. Provide them with the error message, workflow logs, and any relevant configuration files for further investigation.
