What this error actually means

The "TypeError: Cannot read properties of null (reading 'X')" error in n8n's Code node is a common issue that occurs when you're trying to access a property of a null object. This error is thrown when the Code node attempts to execute a JavaScript or Python expression, and the expression tries to access a property of an object that is null.

In JavaScript, when you try to access a property of a null object, it throws a TypeError. This error is not specific to n8n, but it's a common issue that can occur when working with Code nodes in n8n.

There are three common causes of this error in n8n's Code node:

  1. Null input: The most common cause of this error is when the input to the Code node is null. This can happen when the previous node in the workflow returns null, or when the input is not properly configured.
  2. Incorrect expression: Another common cause of this error is when the expression in the Code node is incorrect. This can happen when the expression is trying to access a property that does not exist, or when the expression is trying to access a property of a null object.
  3. Node configuration: The third common cause of this error is when the node configuration is not properly set up. This can happen when the retry options are not configured correctly, or when the node is not properly configured to handle null inputs.
